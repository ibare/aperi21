# C1. 화면 문자 리소스

## When to Apply

- `packages/react/src/embed/**` · `packages/host/src/renderer/**` 가 화면에 문자를 그릴 때
- `sims/**/schema.ts` 의 라벨·설명 작성
- `packages/host/src/i18n/**` · `apps/catalog/src/i18n/**` 편집

## 왜

`BundleSchema` 는 장차 에디터로 불특정 다수가 만드는 선언이다. 시각화가 **무엇이라
말하는지도 저작 결정**이므로, 문안이 컴포넌트/렌더러 코드에 있으면 저작자가 손댈 수 없다.

문자열을 코드 안 카탈로그(모듈 상수 표)로 옮기는 것만으로는 부족하다 — **그것도 여전히
코드다.** 코드에는 키만 남아야 한다.

## 세 층

```
1. 선언의 문안        저작자가 정한 것        ← 언제나 이김
2. locale 번들        호스트가 주입
3. 코드의 en 원본     호출부 리터럴 fallback
```

3층이 반드시 있으므로 번역이 하나도 없고 저작자가 아무것도 쓰지 않아도 화면은 en 으로
온전히 동작한다.

## MUST

- 화면에 그리는 문자열은 **키로 조회한다.** 조회기는 **러너가 하나만 만들어** 렌더러와
  임베드 UI 양쪽에 주입한다. 각자 만들면 한 화면에서 문안 출처가 갈린다.
- **en 원본은 호출부에 리터럴로 둔다.** 추출기가 리터럴만 인식하므로 상수나 변수로 빼면
  번역 대상에서 누락된다.
- 값 삽입은 **`{name}` 플레이스홀더 + vars** 로 한다. 문자열 이어붙이기나 템플릿 리터럴
  보간을 쓰면 어순이 다른 언어에서 문장이 깨진다.
- sim 고유 키는 네임스페이스 없이 짧게(`label.energy`), 프레임워크 키는
  `ui.<component>.<name>`(`ui.cameraControls.reset`). 세그먼트는 lowerCamelCase.
- 선언의 `LocalizedText` 는 최소 `en` 을 갖는다.

## MUST NOT

- 컴포넌트·렌더러 코드에 화면 문자열을 리터럴로 박지 않는다.
  **`ko ? '카메라' : 'Camera'` 형태의 삼항식은 금지다** — 세 번째 언어를 받을 수 없고
  저작자가 문안을 바꿀 수도 없다.
- 모듈 상수 표에 `{ko, en}` 을 모아 두는 것으로 갈음하지 않는다 (원칙 5).
- **물리 계산 코드가 화면 문안을 상태에 담아 보내지 않는다.** physics 는 조회기를 갖지
  않고, 문안을 정하는 것은 표현 계층의 일이다 (원칙 1). 문구가 필요하면 **키를 담고**
  표현 계층이 해석한다.

## 표식이냐 문안이냐

번역하면 오히려 화면과 어긋나는 것이 있다. 위에서부터 내려오며 판정한다.

1. **도형에 새겨진 글자인가** — 계기판의 `V` / `A`, 배지의 각인. → **표식**, 키 없음
2. **그 분야에서 원어로 통용되는 용어인가** — `EMF` · `KE` · `PE`. → **표식**
3. **수식·기호·단위 표기인가** — `m/s²` · `y_max` · `t_f` · `θ` · `Ω`. → **표식**
4. 그 외 — 조사·어미가 붙거나 어순이 언어마다 달라지는 것. → **문안**, 키

경계: **소문자 도식 라벨 한 단어는 표식, 값이 끼어드는 조립문은 문안.**
`capacity` 는 표식이지만 `속도 {v} m/s` 는 문안이다.

> 우리 도메인은 3번이 압도적으로 많다. 판정표 없이 시작하면 수식까지 번역 키로 만들어
> 화면이 망가진다.

## 현재 위반 (AUDIT-v1 대상)

- `packages/react/src/embed/CameraControls.tsx` — 삼항식 4
- `packages/react/src/embed/EnergyHUD.tsx` — 삼항식 5
- `packages/react/src/embed/InfoPanel.tsx` — 모듈 상수 표 5키

## Exception

- 테스트 코드의 문자열 리터럴은 대상이 아니다.
- `apps/catalog` 은 카탈로그 사이트이며 자체 i18n(i18next)을 쓴다. 이 규칙은 **임베드
  런타임**(host · react/embed · sims)에 적용된다.
