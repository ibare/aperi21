# packages/

이 디렉토리는 aperi21 엔진 패키지를 담으며, Phase 1부터 실제 코드가 추가된다.

- `@aperi21/schema` (Phase 1) — Scene Graph 타입 정의
- `@aperi21/host` (Phase 1) — 플러그인 매니저, 렌더러, 컨트롤러 시스템
- `@aperi21/react` (Phase 1) — React 통합 레이어
- `@aperi21/bundle-projectile` (Phase 2)
- `@aperi21/plugin-optics` (Phase 3)
- `@aperi21/bundle-ray-tracing` (Phase 3)
- `@aperi21/plugin-circuit` (Phase 4)
- `@aperi21/bundle-dc-circuit` (Phase 4)

MVP 스코프와 Phase 구분은 `docs/08-mvp-scope.md`를 참고.
