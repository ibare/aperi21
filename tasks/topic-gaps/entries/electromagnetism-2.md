# 전자기 묶음 2 — 주제 ↔ 조각 간극

| 주제 | 주제가 약속한 것 | 화면이 하는 것 | 개념에서 처리한 방식 | 갈래 |
|---|---|---|---|---|
| electric-charge | desc 「두 종류의 전하와 **보존**」 | 보존이 없다. 세 쌍이 이미 대전된 채 매달려 있고 전하가 옮겨 가거나 세어지는 자리가 없다 (조각 NOTES (b) 「보존(주제 설명의 뒤 절반)은 다루지 않는다 — 지시서대로 『같은 종류는 밀고 다른 종류는 당긴다』 에 머문다」). visualNote 는 이미 밀고 당김만 약속한다 | definition 을 「종류가 둘뿐이라는 것을, 표식만 다른 세 쌍이 벌어지거나 붙는 것으로 보인다」로 좁히고, 보존·정량화를 다루는 글은 avoidWhen 으로 되돌렸다. 전하가 실제로 옮겨 가는 화면은 `charging-methods` 가 갖고 있어 contrastWith 로 이었다 | 설명 |
| coulombs-law | desc 「전하 **사이의 힘**」 — 법칙 전체는 전하량 곱에도 비례한다 | 거리 하나만 바뀐다. 여섯 전하가 모두 같은 크기·같은 부호이고 바뀌는 것은 벌린 배수뿐이다 (조각 NOTES (b) 「한 부호로 통일해 바뀌는 것이 거리 하나뿐이게 했다」). visualNote 「거리를 늘리면 힘이 제곱으로 준다」 쪽은 화면과 맞는다 | definition 을 「벌린 배수의 제곱만큼 약해진다」로 쓰고, 전하량 의존·끌림·수치를 기대하는 글은 avoidWhen 으로 되돌렸다. 「왜 하필 제곱인가」 는 `inverse-square-law`, 여럿이 한꺼번에 미는 쪽은 `superposition-of-forces` 로 이었다 | 조각 |
| field-lines | desc 「장을 그리는 **규약**과 그 뜻」 | 규약은 지켜지되 주장되지 않는다. 전하량에 비례한 가닥 수·+에서 나와 −로 들어감이 화면에서 지켜지지만 (원본 NOTES (c) 「전하량 +2 와 −1, 선은 전하량 1당 12가닥 … 개수 규약도 화면에서 지켜진다」) 세어 보이거나 이름 붙는 자리가 없고, 고정 캡션은 「몰린 곳이 세다」 하나다. visualNote 도 그 뜻만 약속한다 | definition 을 「촘촘함 = 세기라는 규약이 참인가를 독립된 두 번째 표현으로 확인한다」로 쓰고, 가닥 수를 정하는 법·시작과 끝의 규칙을 묻는 글은 avoidWhen 으로 되돌렸다 | 설명 |
