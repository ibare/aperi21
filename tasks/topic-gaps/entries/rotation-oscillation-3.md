# 회전과 진동 묶음 3 — 주제 ↔ 조각 간극

| 주제 | 주제가 약속한 것 | 화면이 하는 것 | 개념에서 처리한 방식 | 갈래 |
|---|---|---|---|---|
| mass-spring-system | 「질량과 **탄성 계수**가 정하는 주기」 | 탄성 계수를 바꾸는 자리가 없다. 세 레인이 **모두 같은 용수철**이고 다른 것은 질량(4배)과 진폭(2배)뿐이라, 화면이 세우는 주장은 「질량이 정하고 진폭은 상관없다」 하나다 (조각 NOTES (a) 「같은 용수철 셋」 · 조작기 없음). visualNote 「질량을 늘리면 주기가 길어진다」 쪽은 화면과 맞는다 | definition 에 질량과 탄성 계수를 함께 두되 화면이 견주는 것은 질량·진폭임을 observable·useWhen 에 적었고, 탄성 계수를 바꿔 견주기를 기대하는 글은 avoidWhen 으로 되돌렸다. 용수철의 힘 자체는 `spring-force` 라 contrastWith 로 이었다 | 설명 |
| pendulum-amplitude-dependence | 「큰 진폭에서 **깨지는** 등시성」 · 「진폭을 키우면 주기가 조금씩 길어진다」 | 기본 상태에서는 그 반대를 말한다. 열리는 순간의 흔들림 폭(20°)에서 다섯 진자의 획이 한 세로줄로 서고 캡션도 「같은 순간 바닥을 지난다」 다 — 깨지는 장면은 독자가 슬라이더를 60° 쪽으로 밀어야 나오고, 그때에야 캡션이 「뒤처졌다」 로 바뀐다. 조각 이름도 `pendulum-amplitude-dependence` 이다 | definition 을 「넓히면 주기가 길어지고 등시성이 무너진다」 로 주제 쪽에 맞춰 쓰되, observable 에 「좁을 때는 한 줄로 선다 → 넓히면 기운다」 순서를 그대로 적고 affordances 에 「좁은 데서 시작하므로 넓혀야 드러난다」 를 명시했다. 등시성이 성립한다는 쪽만 필요한 글은 `simple-pendulum` 으로 contrastWith 하며 avoidWhen 으로 되돌렸다 | 조각 |
