# 중력과 천체 묶음 3 — 주제 ↔ 조각 간극

| 주제 | 주제가 약속한 것 | 화면이 하는 것 | 개념에서 처리한 방식 | 갈래 |
|---|---|---|---|---|
| keplers-third-law | 「주기와 **긴반지름**의 **관계**」 | 타원이 없다 — 원 궤도 둘이고 「긴반지름」 은 눈에 보이는 반지름으로 바뀌어 있다(조각 NOTES (b) 「타원 둘을 견주면 『무엇을 a 로 재는가』 라는 다른 질문이 끼어든다」). 관계를 잇는 곡선 · 표 · 식도 없고 정수 한 사례(4 → 8)를 바퀴 수로 세는 데까지다 | definition 을 「궤도 크기가 커질수록 한 바퀴 시간이 반지름보다 훨씬 빨리 길어진다」로 쓰고, 타원 · 긴반지름 · 식 · 실제 주기를 요구하는 글은 avoidWhen 으로 되돌렸다. T² ∝ a³ 과 긴반지름 검색어는 exemplarKeywords 에만 남겼고, 한 궤도 안의 빠르기 변화는 `keplers-second-law` 로 contrastWith 했다 | 설명 |
| lagrange-points | 「**두 중력이 만드는** 다섯 자리」 · 「두 천체 **사이**의 평형 위치」 | 지형은 두 중력만이 아니라 **함께 도는 틀의 유효 퍼텐셜**이다 — 돌지 않으면 L4 · L5 는 아예 서지 않는다. 다섯 중 둘 사이에 있는 것은 하나뿐이고 나머지 넷은 두 천체 바깥이다 | definition 에 「두 천체와 보조를 맞춰 도는 다섯 자리」 를 넣어 회전을 주어 안에 넣고, 「두 중력의 합이 0 인 자리」 로 읽는 글은 avoidWhen 으로 되돌렸다. 함께 도는 틀이 더하는 몫은 `coriolis-effect` · `fictitious-force` 로 contrastWith 했다 | 설명 |
| orbital-transfer | 「호만 전이와 **그 비용**」 | 비용이 수로 나오지 않는다. delta-v 값 · 연료 · 걸리는 시간 어느 것도 없고, 남는 것은 밀기 자국 두 개의 **길이**와 「든 것은 이 둘뿐」 이라는 캡션 한 줄이다 (조각 NOTES (b) 「수를 띄우지 않는다」) | observable 에 「짧은 두 자국이 남는다」 까지만 적고, delta-v 예산 · 전이 시간 · 연료량을 수로 원하는 글은 avoidWhen 으로 막았다. 검색어(`delta-v needed to move between orbits` · `the cost of getting to a higher orbit`)는 exemplarKeywords 에만 남겼다 | 설명 |
