# 전자기 묶음 8 — 주제 ↔ 조각 간극

| 주제 | 주제가 약속한 것 | 화면이 하는 것 | 개념에서 처리한 방식 | 갈래 |
|---|---|---|---|---|
| generator | desc 「회전이 만드는 **기전력**」 — 돌림의 산물로 기전력을 약속한다 | 기전력이 화면에 없다. 전압계·파형·수치가 하나도 없고, 전류는 도선 단면의 ⊙·⊗ 와 전구 빛으로만 보인다. 조각 NOTES (b) 는 「기전력이 열린 회로에도 있다는 것은 캡션·그림 어디에도 말하지 않는다」·「사인파·기전력 그래프를 두지 않았다 — 이웃 `ac-generation` 의 주장이다」 라고 못 박는다. 화면이 실제로 하는 주장은 「같은 빠르기로 돌려도 전구를 켜면 손잡이가 무거워진다」 = 에너지의 출처다. visualNote 「돌리면 전기가 나오는 과정이 보인다」 쪽은 화면과 맞는다 | definition 을 「전구 스위치를 닫으면 같은 빠르기에서 손잡이가 훨씬 무거워진다 — 손의 값이 빛으로 치러진다」로 쓰고, 출력 모양·기전력 크기·수치를 기대하는 글은 avoidWhen 으로 되돌렸다. 사인파는 `ac-generation`, 유도 전압의 크기는 `faradays-law` 로 contrastWith 를 이었다 | 설명 |
| maxwells-equations | desc 「전자기를 묶는 **네 식**」 · visualNote 「**네 식**이 어떻게 파동으로 이어지는지 그림으로 잇는다」 | 네 식 가운데 둘만, 그것도 식이 아니라 사슬의 한 마디씩으로 보인다. 조각 NOTES (b) 「네 식을 그림 넷으로 늘어놓지 않았다. 가우스 두 식(전하 → 발산, 자기 홀극 없음)은 이 사슬에 필요하지 않아 이름 없는 도식조차 두지 않았다 … 식은 캡션·문안 어디에도 없다」. 화면은 「바뀌는 한쪽 둘레에 다른 쪽 고리가 생기며 사슬이 번진다」 하나를 주장한다 | definition 을 그 사슬 하나로 좁혀 쓰고, 식을 쓰거나 이름을 부르거나 세는 글, 가우스 두 식·홀극을 다루는 글은 avoidWhen 으로 되돌렸다. 「네 식」 이 설명 과함인지 조각 부족인지는 이 주제를 어디까지 다룰지의 결정이라 판정하지 않았다 | 설명 |
| electromagnetic-wave | visualNote 「전기장과 자기장이 **서로를 낳으며** 나아간다」 | 서로를 낳는 것은 화면에 없다. 원본 NOTES (b) 는 「둘이 서로를 떠받치며 함께 이동하는 것이지 전하가 밀어 주는 것이 아님」 까지만 보인다고 적고, 자기장은 같은 자리에서 ⊙·⊗ 크기로 전기장과 **함께** 커지고 작아질 뿐이다. 화면이 하는 주장은 「흔들기를 멈춰도 이미 끊겨 나간 고리 묶음은 전하 없이 계속 간다」 = 원천에서 떨어져 나감이다. 「서로를 낳는다」 를 실제로 보이는 것은 같은 분과의 `maxwells-equations` 다 | definition 을 「선이 부풀어 고리로 끊겨 나가고, 멈추면 빈 영역이 넓어지는 동안 이미 떠난 고리는 계속 간다」로 쓰고, 한쪽이 다른 쪽을 낳는 짝을 다루는 글은 avoidWhen 으로 되돌려 `maxwells-equations` 에 넘겼다 | 설명 |
| poynting-vector | desc 「**전자기파가** 나르는 에너지 흐름」 | 전자기파가 없다. 화면은 전지–저항의 **정상 직류 회로**이고, 주장은 「에너지가 도선 속이 아니라 둘레 공간을 지나 전지에서 저항으로 간다」 다 (조각 NOTES (a)). 파동·복사는 한 번도 나오지 않는다. visualNote 「에너지가 어느 쪽으로 흐르는지 화살표가 가리킨다」 쪽은 화면과 맞는다 | definition 을 정상 회로의 「길」 로 쓰고, 자유 공간의 파동·복사·빛이 나르는 에너지를 다루는 글은 avoidWhen 으로 되돌렸다. 파동 쪽은 `electromagnetic-wave`, 도착한 빛이 하는 일은 `radiation-pressure` 로 갈랐다 | 설명 |
