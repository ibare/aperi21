# 파동과 음향 묶음 3 — 주제 ↔ 조각 간극

| 주제 | 주제가 약속한 것 | 화면이 하는 것 | 개념에서 처리한 방식 | 갈래 |
|---|---|---|---|---|
| string-vibration | 「양끝이 고정된 줄의 **모드**」(desc) — 모드가 여럿이라는 말 | 모드가 하나뿐이다. 줄은 처음부터 끝까지 **반파장 하나**로만 흔들리고, 오른쪽 끝은 줄받침이지만 왼쪽 끝은 손가락이라 「양끝 고정」 도 누르는 동안에는 아니다 (조각 NOTES (b) 「배음을 되풀이하지 않는다 — 모양이 거르는 것은 `harmonics` 의 몫이다. 여기서 바뀌는 것은 길이 하나다」). visualNote(「길이를 줄이면 더 높은 음이 난다」)는 화면과 맞는다 | definition 을 「누른 자리부터만 흔들려 짧아지는 만큼 더 빨리 흔들린다」 는 **길이 ↔ 음높이** 하나로 쓰고, 여러 모드 · 배음 · 정수배를 기대하는 글은 avoidWhen 으로 되돌렸다. 모드 쪽은 `harmonics` 가 맡으므로 contrastWith 로 「길이를 바꾼다 ↔ 진동수를 훑는다」 로 갈랐다. 장력 · 굵기도 화면에 없어 함께 막았다 | 설명 |
| air-column-resonance | 「관을 막으면 **울리는 길이**가 달라진다」(visualNote) — 한 관을 막고 울리는 기둥 길이를 찾는 쪽(물기둥을 올리내리는 교과서 실험) | 길이는 끝까지 고정이다. **같은 길이의 관 둘**을 나란히 두고 음원이 진동수를 계단으로 올리며, 달라지는 것은 「어느 진동수에서 울리는가」 다 — 막은 관이 절반에서 먼저, 홀수 배에서만 (조각 NOTES (b) 「관 하나를 막았다 열었다 하면 두 모양을 기억으로 비교해야 한다」). 여닫는 조작도 없다 | definition 을 「막은 관은 절반 진동수에서 먼저, 홀수 배에서만 울린다」 는 **진동수 모임**으로 쓰고, 공명하는 기둥 길이를 찾는 글 · 관 길이를 바꾸는 글은 avoidWhen 으로 되돌렸다(「관 길이를 바꿔 음을 바꾸는 글」 은 `string-vibration` 쪽으로 contrastWith 했다) | 설명 |
| doppler-effect | 「상대 운동에 따른 **진동수 변화**」(desc) | 진동수가 화면에 **없다**. 받는 쪽이 아예 없어서 — 관찰자도, 들리는 음높이도, 어떤 수치도 두지 않았다. 화면이 하는 것은 파면 **간격**의 앞뒤 비대칭과 그 원인(방출점만 밀렸다)이다 (조각 NOTES 「관측자와 진동수, v ≥ c 의 충격파를 두지 않았다」). visualNote(「다가오면 파면이 조밀해지고 멀어지면 성겨진다」)는 화면과 맞는다 | definition 을 「파면은 그대로 퍼지고 방출점만 밀려 앞이 촘촘 · 뒤가 성기다」 는 **원인**으로 쓰고, 들리는 음높이 · 진동수 값 · 지나갈 때의 높낮이 변화를 옮겨야 하는 글은 avoidWhen 으로 되돌렸다. 받는 쪽이 등장하는 자리는 `doppler-source-vs-observer` 가 맡으므로 contrastWith 로 이었다 | 조각 |
