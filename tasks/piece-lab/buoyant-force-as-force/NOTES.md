# buoyant-force-as-force — 부력(힘으로서)

## (a) 답하는 질문

"물에 담근 물체는 가벼워지는가? 무게가 줄어드는 것인가?"

답: 무게는 그대로다. 잠긴 만큼 물이 위로 떠받치는 힘이 더해져, 용수철이 들어야 할 몫이
줄어든다. 다 잠긴 뒤로는 더 깊이 가도 그 힘이 커지지 않는다.

이웃 조각 `archimedes-principle` 은 "왜 하필 밀려난 물의 무게와 같은가"를 다룬다. 이 조각은
크기의 기원을 묻지 않고, 부력을 **다른 힘과 더해지는 하나의 힘**으로 보여 준다. 밀려난 물,
수면 상승, 넘친 물은 일부러 두지 않았다.

## (b) 동사를 화면에서 어떻게 일어나게 했는가

동사: **떠받친다** — 화면에서는 **용수철이 짧아진다**.

- 손잡이가 일정한 흐름으로 내려가도, 물에 잠기기 시작하면 용수철이 줄어들어 물체가 손보다
  덜 내려온다. 숫자가 아니라 용수철 길이 자체가 변한다.
- 물체 오른쪽에는 위쪽 힘 두 개를 머리-꼬리로 이었다(물이 미는 힘 → 용수철이 당기는 힘).
  둘을 합친 끝은 늘 왼쪽 무게 화살표 길이와 같다. 주황 부분이 자랄수록 검은 부분이 줄어드는 것이
  "나눠 든다"를 보여 준다.
- 무게 화살표는 처음부터 끝까지 길이가 변하지 않는다. "무게가 줄어든다"는 오해를 화면이 직접 반박한다.
- 다 잠긴 구간(약 1.5~5.8초)에서 물체는 더 내려가지만 화살표와 용수철 길이는 멈춘다.

평형은 매 프레임 손잡이 높이에서 고정점 반복으로 푼다(잠긴 깊이 ↔ 용수철 늘어남이 서로 얽힘).
누적 상태가 없어서 `?t=` 로 연 화면이 실시간과 같다.

## (c) 화면 구성 결정

- **강조색(주황)은 "물이 미는 힘" 하나에만.** 무게와 용수철 힘은 같은 검정, 위치와 글자로 구분.
  물의 파란색은 물이라는 대상의 색이지 강조가 아니다.
- **잠긴 부피는 따로 칠하지 않았다.** 물 채움을 물체 위에 반투명으로 덧칠해, 수면 아래 부분이
  저절로 푸르게 보이게 했다. 강조색을 두 번째 뜻에 쓰지 않기 위해서다.
- **캡션은 세 문장 중 하나**를 잠긴 깊이 구간(0 / 사이 / 최대)으로 고른다. 방향(내려감·올라옴)에
  기대지 않는 문장이라 어느 순간에도 화면과 어긋나지 않는다.
- **힘의 수치·눈금·저울 눈금판을 두지 않았다.** 동사가 숫자로 대체되는 것을 막기 위해서다.
  화살표는 한 축척(무게 = 70px)을 공유하므로 길이 비교만으로 충분하다.
- **조작기 없음.** 자동으로 내려갔다 올라오는 한 주기(16초)가 물 밖·일부 잠김·다 잠김 세 상태를
  모두 지나며 주장을 마친다. t=0 에 이미 절반쯤 잠겨 내려가는 중이다.
- 그리드·축·범례·재생 버튼·제목 없음. 화살표 옆 글자는 범례가 아니라 화살표 이름이다(색으로
  설명하지 않기 위해 필요).
- 수면 상승 없음: 통을 넓게 보고 고정했다(이웃 조각의 영역).
- 용수철 진동 없음: 준정적 평형만. 흔들리면 합이 무게와 같다는 비교가 흐려진다.

## (d) 이 그림이 성립하려면 필요했던 것

다시 짜기 아까웠던 것
- 얽힌 평형을 푸는 작은 반복 풀이(손잡이 높이 → 잠긴 깊이·장력·용수철 길이)
- 힘 화살표: 공통 축척, 머리-꼬리 잇기, 길이 0 이면 숨김, 짧을 때 화살촉 축소, 이름 글자 배치
- 길이만 변하고 감은 수는 고정인 지그재그 용수철
- 물 층을 물체 위에 덧칠하는 그리기 순서

누가 강제하면 안 되는 것
- 화살표 배치(물체 중심에서 출발, 위쪽 힘은 한 줄에 머리-꼬리) — 이 주장에 맞춘 선택이다.
  다른 조각은 작용점에 그려야 할 수 있다.
- 캡션 구간의 경계(0.5px 여유) — 조각마다 "상태"의 정의가 다르다.
