# connected-bodies — 연결된 물체

## (a) 답하는 질문

앞 물체만 당기고 뒤 물체는 끈으로 끌려올 뿐인데, 이 계의 가속도는 **앞 물체만 보고**
정해지는가, **전체를 한 덩어리로 보고** 정해지는가? 그리고 어느 쪽을 앞에 두느냐(가벼운 쪽
/ 무거운 쪽)가 가속도를 바꾸는가?

답: 같은 힘이 같은 전체 질량을 끌면, 어떻게 나눠 이어도 한 덩어리와 똑같이 가속한다.

이웃 `atwood-machine` 은 전체 질량을 고정하고 **질량 차이**(구동력)를 바꿔 가속도가 달라지는
것을 보인다. 이 조각은 반대로 힘과 전체 질량을 고정하고 **나누는 방식**만 바꿔 가속도가
**달라지지 않는** 것을 보인다.

## (b) 동사 — 「나란히 빨라진다」

- **빨라진다**: 물체 위치는 x = x0 + ½·a·t² 로 움직이고, 0.5초마다 앞면 자리를 바닥 아래에
  눈금으로 남긴다. 눈금 간격이 오른쪽으로 갈수록 벌어진다.
- **나란히**: 세 줄(3 kg 한 덩어리 / 1 kg 앞 + 2 kg 뒤 / 2 kg 앞 + 1 kg 뒤)의 앞면이 언제나
  한 세로선 위에 있고, 세 줄의 눈금이 같은 x 에 찍힌다. 숫자 없이 눈금 겹침이 「같다」를 말한다.

## (c) 화면 구성 결정

- **세 줄을 세로로 쌓았다.** 기준(한 덩어리) 하나와, 가벼운 쪽을 앞에 둔 경우·무거운 쪽을 앞에
  둔 경우. 「앞 물체만 보고 정해진다」는 오해라면 두 연결 줄이 서로 달라야 하므로 둘 다 필요하다.
- **물체 가로 길이 ∝ 질량.** 글자 없이도 1+2 와 2+1 과 3 이 같은 합임이 보인다. 질량 글자는 함께 둔다.
- **맨 앞 면을 세 줄에서 같은 x 에 정렬.** 힘이 가해지는 점끼리 비교해야 눈금이 겹친다.
- **강조색은 「바깥에서 당기는 힘」 하나에만.** 물체는 모두 같은 색(같은 종류의 대상).
- **캡션은 고정 한 문장.** 주기 어느 시각에도 참인 말만 쓴다. 되감기 순간에도 거짓이 되지 않는다.
- **도착 시 이미 진행 중**: 주기를 1초 앞당겨(PHASE) t=0 에 이미 눈금 셋이 있다.
- 두지 않은 것:
  - **장력 화살표** — 줄마다 다른 장력(4 N / 2 N)은 「끈의 힘은 뒤 질량이 정한다」는 두 번째
    주장이 된다. 좁은 끈 틈에서 앞뒤 화살표가 겹치기도 한다.
  - 가속도·속도 숫자, 축, 그리드, 재생 버튼, 범례 — 동사를 숫자로 대신하지 않기 위해.
  - 조작기 — 세 줄이 이미 가능한 나눔(통째 / 가벼운 앞 / 무거운 앞)을 다 보여 주므로 직접 해 볼
    일이 남지 않는다.

## (d) 성립 조건

- 다시 짜기 아까웠던 것
  - 같은 시간 간격 위치 눈금(스트로보)을 여러 계에 공통 척도로 찍기
  - 조건 하나만 다른 계를 줄로 쌓는 비교 배치
  - N 당 px 척도를 가진 힘 화살표 + 라벨
  - 주기 반복과 도착 위상 앞당김
- 누가 강제하면 안 되는 것
  - 줄 수와 줄 순서(기준을 맨 위에 두는 결정)
  - 물체 크기를 질량에 비례시킬지 여부
  - 장력처럼 계산은 되지만 일부러 숨기는 양 — 보이는 힘을 엔진이 자동으로 다 그리면 주장이 둘이 된다
