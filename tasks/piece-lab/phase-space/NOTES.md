# phase-space — 위상 공간

## (a) 답하는 질문

"위상 평면에서 진동은 닫힌 고리라는데, 마찰이 있으면 그 고리는 어떻게 되나?"
독자는 '닫힌 고리 = 진동'까지 읽고 나서, 실제 진자는 결국 멈춘다는 사실과 부딪혀 멈춘다.

답의 동사: **감겨 든다** — 상태점이 제 고리에 머물지 못하고 안쪽 고리를 차례로 가로질러 바닥 한 점으로 나선을 그리며 들어간다.

이웃 조각 `pendulum-isochronism` 은 진폭과 주기를 다룬다. 여기서는 주기를 말하지 않는다.

## (b) 동사를 화면에서 어떻게 일어나게 했나

- 옅은 **에너지 고리**(마찰이 없을 때 상태가 머무는 선)를 배경에 깔았다. 이것이 있어야 "고리를 가로지른다"가 눈에 보인다. 선이 없으면 그냥 점이 가운데로 가는 것일 뿐이다.
- 초기 조건이 제각각인 진자 520개를 **상태점 무리**로 평면 전체에 흩뿌리고 같은 감쇠 진자 식으로 적분한다. 무리 전체가 소용돌이치며 좁혀져 바닥 한 점에 뭉친다 — 분포가 감겨 드는 것 자체가 화면에서 일어난다.
- **추적 상태** 하나만 지나온 길을 전부 남긴다. 무리는 "모두가 그렇다"를, 추적 나선은 "한 상태가 어떤 길로 그렇게 되는지"를 보인다. 시작은 넘어감 경계 바깥(꼭대기를 넘을 에너지)이지만 꼭대기 앞에서 붙잡혀 눈 모양 안으로 들어온 뒤 감긴다.
- 숫자는 하나도 줄어들지 않는다. 에너지 값·그래프를 두지 않았다.

## (c) 화면 구성 결정

- **가로 = 각도, 세로 = 각속도**, 각도는 -π~π 로 감았다. 좌우 가장자리가 같은 "거꾸로 선 자리"라 넘어가는 운동도 평면 안에 남는다. 가장자리를 건너는 선은 끊는다.
- **축 이름을 둔 이유**: 이 표현은 낯설다. 가로·세로가 무엇인지 모르면 고리가 운동이라는 것부터 읽히지 않는다. 그래서 '각도 →', '각속도 →' 와 가로축의 두 자리('바닥', '거꾸로 섬')만 둔다. 눈금·수치·격자는 두지 않았다 — 주장은 모양이다.
- **넘어감 경계**를 점선으로 조금 진하게 두었다. 주제 설명의 "닫히거나"를 가르는 선이고, 추적 상태가 그 문턱 앞에서 붙잡히는 장면이 이 선 없이는 안 읽힌다.
- **왼쪽의 진자**: 위상 평면의 점이 실제로 무엇인지 잇는 다리. 추적 상태 하나만 그렸다. 무리 520개의 진자는 그리지 않았다.
- **강조색은 "추적하는 한 진자"라는 한 가지 뜻**에만 쓴다 (진자 추, 위상 점, 그 궤적). 무리는 검정, 고리는 회색.
- **마찰 조절기** 하나. 0 으로 두면 상태점이 제 고리를 돌기만 한다는 대조를 독자가 직접 확인할 수 있다. 자동 진행은 기본 0.40 으로 이미 주장을 마친다. `PieceKit.frozen` 이면 기본값으로 계산.
- **캡션**은 세 경우 중 하나: 마찰 0 → "고리를 따라 돌 뿐", 마찰 있음 → "고리를 가로질러 감겨 든다", 추적 상태가 바닥 근처에서 거의 멈춤 → "감겨 들어 멈췄다". 조작값과 상태에서 바로 판정하므로 화면과 어긋나지 않는다.
- 16 초마다 무리를 다시 흩뿌린다 (끝 0.8 초 흐려짐, 시작 0.5 초 나타남). 도착 순간 이미 움직이도록 1.5 초 앞당겨 흘려 둔 상태에서 시작한다.
- 두지 않은 것: 제목, 범례, 재생 버튼, 툴팁, 에너지 그래프, 격자, 눈금, 끌개 표시(바닥 점은 무리가 뭉쳐서 스스로 드러난다).

## (d) 이 그림이 성립하려면 필요했던 것

다시 짜기 아까웠던 것
- 위상 평면 좌표 매핑 + 감기는 축에서 선 끊기
- H(q,p)=상수 윤곽 그리기 (닫힌 고리와 열린 물결의 제곱근 가지 처리)
- 입자 무리의 초기 조건 흩뿌리기·적분·잔상 고리 버퍼
- 주기적 재시드와 페이드, 앞당겨 흘려 두기
- 상태 하나를 실물 그림과 위상 점에 동시에 묶기

누가 강제하면 안 되는 것
- 축 이름을 둘지, 어떤 자리 이름을 붙일지 — 이 조각은 '바닥/거꾸로 섬'이 필요했지만 다른 위상 조각은 다를 수 있다
- 어떤 에너지 값의 고리를 몇 개 그릴지, 경계선을 구분할지
- 무리 점 개수와 잔상 길이 — 밀도가 주장(분포가 뭉친다)의 가독성을 정한다
- 적분법: 여기서는 마찰 0 에서 고리가 번지지 않도록 부분 단계 4번의 심플렉틱 오일러를 썼다
