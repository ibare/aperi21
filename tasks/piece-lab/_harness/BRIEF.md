빌드 도구 없이 `index.html` 하나. 캔버스든 SVG 든 DOM 이든 무엇으로 그려도 된다.

## 먼저 할 것 — 질문과 동사

주제에서 **독자가 글을 읽다 멈추는 지점**을 하나 고른다. 그 질문을 한 문장으로 쓰고,
답의 **동사**를 정한다. "빨라진다" · "쌓인다" · "방향만 바뀐다" 처럼.

그 동사가 **화면에서 실제로 일어나야** 한다. 숫자가 커지는 것으로 대신하지 않는다.

## 조각의 규범

- **한 주장.** 캡션이 둘이면 조각이 둘이다.
- **아무것도 누르지 않아도 할 말을 마친다.** 자동 진행이 본체이고 조작기는 덤이다 (0~1개).
- **도착한 순간 이미 진행 중이다.** 빈 화면이 채워지길 기다리게 하지 않는다.
- **캡션은 슬롯 하나.** 지금 화면에서 벌어지는 일만 말한다. 정의·공식은 문단의 몫이다.
- 그리드 · 축 · 카메라 · 재생 버튼 · 제목 · 범례 · 툴팁을 기본으로 두지 않는다.
  둔다면 **그것이 주장에 필요하기 때문**이어야 하고, 이유를 NOTES 에 쓴다.
- **색으로 설명하지 않는다.** 같은 대상은 같은 색. 강조색은 한 가지 뜻에만.
- 유효숫자를 자동으로 줄이지 않는다. 표에 쓴 값과 화면의 값이 어긋나지 않게 한다.
- 가로 720~900px 컨테이너에 놓인다고 가정한다. 세로는 비싸다.
- 화면에 뜨는 문자는 한국어로.

## 계측 약속 — 반드시 지킨다

분석하는 쪽은 코드를 읽기 전에 계측 보고서를 먼저 본다. 그러려면 셋을 지켜야 한다.

```html
<script src="../_harness/piece-kit.js"></script>
```

1. **시간은 `PieceKit.loop` 로만 흐른다.**
   ```js
   PieceKit.loop({
     step(dt, t) { /* 상태를 dt 만큼 전진. dt 는 언제나 1/60 */ },
     draw(t)     { /* 지금 상태를 그린다 */ },
   });
   ```
   `requestAnimationFrame` · `performance.now` · `Date.now` · `setInterval` 을 직접 쓰지 않는다.
   **모든 시간 의존은 `t` 또는 누적된 상태에서 나와야 한다** — 그래야 `?t=6.5` 로 연 화면이
   실시간으로 6.5 초 본 화면과 같다.
2. **난수는 `PieceKit.random()` 만.** `Math.random` 금지.
3. **그리는 코드를 이름 붙인 묶음으로 감싼다.**
   ```js
   PieceKit.mark('물줄기', () => { ...그리기... });
   ```
   화면 요소 하나 = 묶음 하나. 이름은 그것이 **무엇인지**로 짓는다 (`'물줄기'` ○, `'draw2'` ✕).

조작기가 있다면 `PieceKit.frozen` 이 참일 때(= `?t=` 로 찍는 중) 자동 진행 상태 그대로 그린다.

### `inventory.json` — 화면에 있는 것의 자기 신고

```json
{
  "id": "{{id}}",
  "claim": "이 조각의 주장 한 문장",
  "verb": "화면에서 일어나는 동사",
  "probeTimes": [0, 1.5, 4, 8],
  "elements": [
    {
      "mark": "mark 에 쓴 이름과 똑같이",
      "what": "화면에서 무엇인가",
      "physical": "어떤 물리량·대상을 나타내는가",
      "drawing": "어떻게 그렸는가 (선·채움·입자·잔상·텍스트…)",
      "motion": "static | time-function | integrated",
      "state": "none | 프레임 사이에 쌓이는 것이 있으면 무엇인지",
      "interaction": null
    }
  ],
  "controls": [],
  "hidden": ["계산은 되지만 일부러 화면에 두지 않은 것과 그 이유"],
  "timeline": [{ "t": 0, "what": "이 시각에 화면에서 벌어지는 일" }],
  "engineWish": ["만들면서 '이건 매번 다시 짤 일이 아닌데' 싶었던 것"]
}
```

`probeTimes` 는 **주장이 가장 잘 드러나는 시각들**로 고른다. 분석하는 쪽은 그 시각의
스크린샷을 본다.
