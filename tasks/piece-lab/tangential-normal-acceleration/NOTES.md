# 접선·법선 가속도 — NOTES

## (a) 답하는 질문

> 가속도가 속도와 비스듬하게 걸리면, 물체는 빨라지는가 도는가?

답: **둘 다, 따로따로.** 가속도는 속도 방향 몫과 수직 몫으로 **갈리고**, 앞의 것은 속도 화살을
**늘이거나 줄이기만**, 뒤의 것은 길이를 그대로 둔 채 **돌리기만** 한다.

동사: 속도 화살이 **늘어난다 / 돈다 / 늘어나면서 돈다**.

## (b) 동사를 화면에서 어떻게 일어나게 했는가

- 가속도를 방향부터 정하지 않고 **두 몫(속력 몫 aT, 방향 몫 aN)을 대본으로 정해** 속력·방향·위치를
  적분한다. 그래서 화면의 움직임은 두 몫이 실제로 만든 결과다.
- 대본은 여섯 구간이다: 곧게 빨라짐(속력 몫만) → 같은 빠르기로 45° 돎(방향 몫만) → 느려지며 45° 돎(둘 다)
  → 빨라지며 45° 돎(둘 다) → 같은 빠르기로 45° 돎(방향 몫만) → 곧게 느려짐(속력 몫만). 다섯 경우가 모두
  나오고, 가속도 0 인 구간은 없다.
- 두 몫 화살을 **속도 화살 끝**에 붙였다. 속력 몫은 화살과 같은 줄에서 앞/뒤를 가리키니 "늘인다/줄인다"로,
  방향 몫은 옆을 가리키니 "옆으로 민다(돌린다)"로 읽힌다.
- 길 위의 화살은 물체와 함께 움직여서 늘어남과 돎이 섞여 보인다. 그래서 오른쪽에 **꼬리를 한 점에 고정한
  같은 속도 화살**을 둔다. 여기서 동사가 가장 깨끗하게 일어난다:
  - 방향 몫만일 때 화살 끝은 **점선 원 위를 미끄러진다** (길이 그대로 돎).
  - 속력 몫만일 때 화살 끝은 **반지름 방향으로만** 나가거나 들어온다 (늘어나기만).
  - 둘 다일 때 화살 끝은 **원을 가로지르며 돈다**.

## (c) 화면 구성 결정

- **두 판(길 / 모은 화살)**: 한 주장을 두 번 말하는 것이 아니라, 길 위에서는 "무엇이 움직이는가",
  모음판에서는 "속도 화살이 무엇을 당하는가"를 보인다. 모음판 없이는 늘어남과 돎을 눈으로 가르기 어렵다.
- **모음판 이름 한 줄** ("속도 화살을 한 점에 모아 보면"): 이것이 없으면 오른쪽 판이 무엇인지 알 수 없다. 제목 대신 최소한의 이름.
- **점선 원(같은 길이 원)**: "길이가 그대로"를 눈으로 판정하는 기준선. 방향 몫만일 때 화살 끝이 원에 붙어 있고,
  속력 몫이 있으면 원을 벗어난다. 원 자체는 지금 속력을 따라 커지고 작아진다.
- **'속력 몫'·'방향 몫' 글자**: 두 화살을 색만으로 구별하지 않으려고 길 위 화살에 직접 붙였다(범례 대신).
  모음판에는 같은 색·같은 배율이라 다시 붙이지 않았다.
- **색**: 물체·속도 = 먹색, 속력 몫 = 주황, 방향 몫 = 청록, 전체 가속도·보조선 = 회색. 주황·청록은 각각 한 뜻에만.
- **전체 가속도(회색 얇은 화살 + 평행사변형 점선)**: "하나의 가속도가 갈린다"를 보이려고 두 몫이 모두 있을 때만 그린다.
  한 몫뿐이면 합이 그 몫과 겹치므로 생략.
- **캡션**: 구간마다 지금 벌어지는 일 한 문장. 구간이 약 2초라 읽을 시간을 준다. 공식·용어 정의는 없다.
- **닫힌 경로**: 뒤 반 바퀴를 앞 반 바퀴의 180° 회전으로 만들어 저절로 닫힌다. 되감기·순간이동·카메라 추적이 필요 없다.
- **두지 않은 것**: 격자·축·숫자·재생 버튼·조작기·범례·툴팁·곡률 중심. 조작기는 없다 — 다섯 경우를 대본이 모두 돌며
  보여 주므로 독자가 만들어 볼 필요가 없다고 판단했다.
- **도착 순간**: t=0 은 첫 구간(곧게 빨라짐)의 한가운데. 자취도 표의 지난 칸에서 읽으므로 처음부터 꼬리가 있다.
- **배율**: 속도 화살과 가속도 화살은 서로 다른 양이라 배율이 다르지만, 두 몫과 합은 같은 배율이고 가속도 배율은 두 판이 같다. 속도 화살은 모음판에서 조금 더 크게 그렸다(원을 판에 채우려고).

## (d) 이 그림이 성립하려면 필요했던 것

다시 짜기 아까웠던 것:
- 구간 대본(aT, ω, 길이)을 받아 프레임 표로 적분하고 닫힘 오차를 나눠 없애는 적분기.
- 벡터를 다른 벡터 끝에 붙여 두 성분·합·평행사변형으로 분해해 그리는 그리기.
- 같은 벡터를 "물체 위"와 "한 점에 모은 판" 두 곳에 같은 배율로 그리는 연결.
- 경로 경계 상자에 맞춘 자동 배치, t 로 읽는 흐려지는 자취, 구간이 바뀔 때만 바뀌는 캡션 슬롯.

누가 강제하면 안 되는 것:
- 성분을 어디에 붙이는지(물체 중심 / 속도 화살 끝). 이 조각은 "화살 끝을 민다"는 읽기가 주장이라 끝에 붙였다.
- 모음판을 둘지 말지 — 주제에 따라 오히려 군더더기다.
- 대본 구간의 종류와 순서 — 어떤 경우를 보이고 어떤 경우(가속도 0)를 뺄지는 주장이 정한다.
