# moment-of-inertia — 이관 노트

원본: `tasks/piece-lab/moment-of-inertia/` (자유 구현). 주장·배치·상수는 원본 `NOTES.md` · `index.html` 그대로다.
자유 렌더(`Bundle.renderers`)는 쓰지 않았다.

## 쓴 어휘

- `trajectory` — 바퀴 테(closed) · 돌림힘 원호 · 돈 각 곡선 두 개(먹색 6 px 아래, 강조색 2.5 px 위)
- `lineSet` — 바퀴 살 · 잔상 원호(굵기 단계마다 하나, 토막별 `opacities`) · 그래프 기준선과 1·2·3바퀴 눈금
- `particleSystem` — 질량 알갱이 12개(바퀴마다 하나)
- `body` — 축 원 · 곡선 머리 점
- `region` — 돌림힘 화살표 머리(삼각형)
- `readout` — 바퀴 아래 자리 표시 · 그래프 글자(눈금 · 「돈 각」 · 「시간 →」)
- `slider` 조작기(`restart` · `heldPath`)
- 선언 — `timeline`(시행 셋 × 돌림 · 멈춤 · 옮김 = 아홉 단계, 옮김은 `smooth`) · `startAt: 2` · `caption`(단계 캡션 + 수동 시행 `cases` + `vars`) · `drawOrder: 'scene'` · `canvas` · `boundsHint`

## (a) 원본과 달라진 점과 이유

- **슬라이더 모양 · 자리.** 원본은 캔버스 아래 오른쪽에 「이름표 · 트랙 · 값」 한 줄이었고, 엔진 슬라이더는 오른쪽 아래 상자(이름표 위, 값 오른쪽 위)다. 크롬이라 주장과 무관하다.
- **옮기는 동안 슬라이더 값 글자.** 원본은 `0.68R` 처럼 표시 반지름을 그대로 쓰고 손잡이만 0.05 에 붙였다. 엔진 슬라이더는 `step` 이 값 글자까지 붙여 `0.70 R` 로 보인다(장부 G46). 바퀴 아래 자리 표시는 원본과 같이 `0.68R`.
- **바퀴 아래 글자 · 그래프 글자의 세로 자리.** 원본 `fillText` 는 기준선이 좌표에 오고 readout 은 가운데라 4 px 올려 맞췄다(장부 G16).
- **잔상 굵기.** 원본은 원호를 10 토막으로 나눠 토막마다 굵기와 투명도를 줄였다. `lineSet` 은 인스턴스 하나에 굵기 하나라 두 토막씩 묶어 5 단계 굵기로 줄였다. 투명도는 토막마다 원본 값 그대로(장부 G74).
- **크기 단위가 섞인다.** 알갱이 점(`particleSystem`)과 선 굵기는 화면 px, 축 원 · 곡선 머리 점(`body`)은 월드 단위다. 대조 폭(약 850 px, 1R ≈ 85 px)에서는 원본과 거의 같지만 폭이 크게 달라지면 알갱이와 머리 점의 비가 달라진다(장부 G79 · G25).
- **캡션 문안 템플릿이 세 벌.** 거리 비 · 각 비 캡션이 시행마다(먼 · 중간 · 수동) 같은 문장을 다른 변수 이름으로 따로 적었다 — 단계에 값을 실을 수 없어서다(장부 G13). 0.30R 시행이 「나란히 돈다」 인 것도 원본은 거리 비교로 골랐고 여기서는 `run-near` 단계 캡션 키로 적었다.
- **수동 시행.** 원본과 같이 만지는 순간 두 바퀴가 멈추고, 지금까지 돈 각을 이어 받아 같은 돌림힘으로 돌림 + 멈춤을 반복한다. 시간표는 자동 진행 한 벌뿐이라 수동 반복(6.8 초)은 scene 이 `tl.t` 를 `run-far` + `hold-far` 길이로 나눠 읽는다. 잡는 순간의 바퀴 각은 `step` 이 시계 사본으로 다시 계산한다(장부 G01). 캡션은 `cases`(`manualLag` · `manualSame`)로 넘어간다(장부 G44 — `cases` 로 됐다).
- 대조 스크린샷은 운영체제 설정으로 다크 테마. 빛 채널은 쓰지 않았다 — 밝기가 주장인 곳이 없다.

## (b) 화면에 두지 않은 것

원본과 같다 — 관성 모멘트 수치, 각속도 · 각가속도 값, 알갱이별 mr² 막대, 돌림힘 크기, 제목 · 범례 · 재생 버튼. 이유는 원본 NOTES (c).

## 어휘 부족

### 장부에 있는 것

| id | 이 조각에서 |
|---|---|
| G01 | `step` 이 시간표 프레임을 받지 못해 조각 시계 사본(`clock`)을 따로 세고, 잡는 순간의 바퀴 각 · 자동 진행 중 슬라이더 값을 위해 선언된 단계 목록을 직접 훑는다(`autoMomentFromClock`) |
| G13 | 단계에 시행 반지름을 실을 수 없어 단계 id(`run-far`)를 갈라 시행을 찾고, 시행마다 캡션 키를 따로 둔다 |
| G16 | readout 을 글자 기준선에 맞출 수 없어 −4 px 로 옮겼다 |
| G24 | 캡션 줄 · 슬라이더 줄이 프레이밍 여백으로 잡히지 않아 `SCENE_BOUNDS` 위아래에 px 여백을 직접 더했다 |
| G25 · G79 | 알갱이 점 크기를 월드 단위로 줄 수 없어 축 · 머리 점(월드)과 단위가 섞인다 |
| G46 | 슬라이더 `step` 이 값 글자까지 붙여 옮기는 동안 `0.68` 이 `0.70` 으로 보인다 |
| G47 | 그래프 축 어휘가 없어 기준선 · 눈금은 `lineSet`, 눈금 글자는 `readout` 으로 월드에 직접 놓았다 |
| G74 | `lineSet` 에 선마다 다른 굵기가 없어 잔상을 굵기 5 단계 인스턴스로 나눴다 |

| 부족 | 영향 |

| 굽은 화살표(원호 + 머리) 어휘가 없다 — 돌림힘을 `trajectory` 원호와 `region` 삼각형 머리로 따로 선언하고 머리 꼭짓점을 조각이 접선에서 계산한다 (G57 은 곧은 화살표 묶음) | 근사 |

### 주장 판정

「뒤처진다」 는 원본과 같은 모양으로 일어난다 — 바퀴 살 · 알갱이 · 잔상의 회전 차이, 벌어지는 두 곡선, 0.30R 에서 겹치는 곡선이 다섯 시각 모두 원본과 같은 자리 · 같은 각으로 선다. 근사 때문에 주장이 약해진 곳은 없다.
