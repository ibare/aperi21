# resonance — 이관 기록

원본: `tasks/piece-lab/resonance/` (자유 구현). 자유 렌더 없이 선언만으로 옮겼다.

## 쓴 어휘

| 원본 묶음 | 어휘 | 선언 |
|---|---|---|
| 흔들림 폭 | `lineSet` | 열마다 세로 선분 하나(길이 = 진폭 × 2), `ink` · `opacity` 0.10 · 굵기 `max(2, pitch·0.55)` px |
| 진동자 막대 | `lineSet` | 61 가닥, `ink` · `opacity` 0.28 · 굵기 1 px |
| 진동자 추 | `particleSystem` | 61 점, `ink` · 반지름 `max(2, min(3.2, pitch·0.32))` px |
| 구동대 | `trajectory` | `accent` · 굵기 3 px |
| 구동 진동수 표시 | `region` 삼각형 + `readout` | `accent`, 글자 12 px 월드 앵커 · 오른쪽 9 px |
| 진폭 이력 무늬 | `scalarField` 순차형 (`high: 'ink'`) | 61 × 110 칸, 값 = 진폭 / 공명 정상 진폭(1 로 자름), 범위 `[0, 1]` |
| 무늬 테두리 | `trajectory` closed | `ink` · `opacity` 0.12 · 굵기 1 px |
| 무늬 읽는 법 | `readout` 셋 | `muted` · 11 px · 왼쪽 / 가운데 / 오른쪽 정렬 |
| 캡션 | `caption` 슬롯 | 아래 왼쪽 15 px `ink`, 고정 한 문장 |
| 구동 진동수 | `slider` | 0.52~1.48 Hz, step 0.02, 기본 1.00, 아래 오른쪽 |
| 도착 즉시 진행 중 | `preroll: 1` | 원본 1 초 미리 돌림을 고정 걸음으로 |
| 겹침 | `drawOrder: 'scene'` | 원본 그리기 순서 그대로 |

상태: 진동자별 `z` · `v`, 구동 위상, 걸음 수, 진폭 이력(행 우선 · 첫 행이 지금). 감쇠 강제 진동은
적분이라 `step` 이 쌓는다. 시각의 함수가 아니어서 `timeline` · `startAt` 은 선언하지 않았다 — 원본에도
연출 시간표가 없다. 물리 상수(61 개 · 0.4 + 0.02 i Hz · γ 0.12 · B 2 · 8 분할 · 110 줄 · 10 걸음마다 한 줄)와
배치(구동대 140 · 정지 높이 70 · 무늬 166~276 · 좌우 24)는 원본 값 그대로다. 월드 단위 = 원본 px (y 반전).

## (a) 원본과 달라진 점과 이유

- **슬라이더 값.** 원본은 진동자 번호(6~54)를 값으로 삼고 숫자를 보이지 않았다. 엔진 슬라이더는 값 표시를
  끌 수 없어(G22) 뜻 없는 번호 대신 구동 진동수 Hz(`1.00 Hz`)를 보인다. `step` 이 가장 가까운 진동자 번호로 붙인다.
  원본이 감춘 「진동수 숫자」 하나가 조작기 안에 드러난다. 그림 안에는 여전히 숫자가 없다.
- **고정 촬영 중 비활성.** 원본은 `?t=` 촬영에서 슬라이더를 끄고 기본값을 지켰다. 엔진은 검사 시각에 조작기를
  끄는 규약을 이 조각이 선언할 자리가 없고, 기본값은 state 초기값이 지킨다.
- **폭포 무늬의 칸 경계.** 원본은 61 × 110 화소를 계단식(보간 없이) 확대해 열이 또렷한 기둥이다. `scalarField` 는
  보간해 늘려 열 경계가 번진다(G81).
- **폭포 무늬의 명암 사상.** 원본은 종이색 → 먹색을 sRGB 로 선형 섞었다. 엔진은 빛의 양(선형광)으로 섞는다(G62).
  다크 테마 대조에서 공명 열 둘레의 중간 값이 원본보다 밝게 올라 진한 줄기가 원본(약 3 열)보다 넓게(약 6 열) 보인다.
  라이트 테마에서는 반대로 중간 값이 옅어질 것으로 보이나 **미확인**(빛 채널을 쓰지 않는 조각이라 라이트 촬영은 하지 않았다).
- **흔들림 폭 띠 끝.** 원본은 네모 끝 사각형, `lineSet` 은 둥근 끝이라 띠마다 위아래로 반폭(약 3.8 px)씩 길다.
  진폭이 작은 열은 원본의 납작한 사각형 대신 짧은 알약 모양이다(G04 · G73).
- **치수가 배율을 따른다/안 따른다.** 월드 단위(열 간격 · 높이 · 삼각형)는 프레이밍 배율(대조 폭에서 약 0.9)을 따르고,
  화면 px 선언(띠 굵기 · 추 반지름 · 선 굵기 · 글자)은 따르지 않는다. 원본은 한 배율이다(G25 · G63 · G79).
- **캡션 · 조작기 자리.** 원본은 캔버스 **밖** 아래 줄이다. 엔진에서는 캔버스 안에 얹히므로 `boundsHint` 에 캡션 줄
  34 px 를 더했다(G24). 러너가 네 변에 여백 36 px 를 두어 원본 캔버스 여백(좌우 24)은 프레이밍에서 뺐다.
- **구동 진동수 글자 좌우 뒤집기.** 원본은 글자가 오른쪽 끝을 넘으면 삼각형 왼쪽으로 돌렸다. 조작 범위(54 번까지)에서는
  한 번도 넘지 않아 오른쪽 고정으로 두었다.
- 두지 않은 것은 원본 그대로 — 진동수 · 진폭 숫자, 공명 곡선 이론선, 위상차, 에너지 막대, 재생 버튼, 범례, 제목, 그리드.

대조(`pnpm piece:report --sims`, 다크 테마, t = 0 · 5 · 12 · 24): 네 시각 모두 추의 위상 곡선 모양 · 흔들림 폭 띠의
봉우리 자리와 길이 · 무늬가 채워진 줄 수 · 맥놀이 줄무늬의 비스듬한 방향이 원본과 같다. t = 12 에서 가운데 띠가
구동대 흔들림의 스무 배 가까이, t = 24 에서 무늬 가운데 곧은 줄기와 옅어진 양옆 줄무늬가 원본과 같다.

## (b) 어휘 부족

### 장부에 있는 것

| 장부 | 여기서 겪은 것 |
|---|---|
| G81 | `scalarField` 를 보간 없이 칸 그대로 칠할 수 없다 — 폭포 무늬의 열 경계가 번진다 |
| G62 | 값→색 사상이 선형광 고정 — 원본의 sRGB 선형 명암과 달라 다크에서 공명 줄기가 넓어 보인다. 원본 NOTES 가 「감마 보정을 넣으면 어긋난 열도 진해져 봉우리가 넓어 보였다」 고 피한 바로 그 모양이다 |
| G73 | 떨어진 면(흔들림 폭 사각형 61 개)을 한 선언으로 칠하는 면 묶음이 없다 — `lineSet` 굵은 선으로 근사 |
| G04 | 선 끝 모양을 고를 수 없다 — 띠 끝이 둥글고 반폭만큼 길다 |
| G22 | 슬라이더 값 표시를 끌 수 없다 — 원본이 감춘 진동수 숫자가 드러난다 |
| G39 | 실시간 dt 가변 — 고정 걸음 누적기를 조각이 둔다 |
| G24 | 캔버스 밖이던 캡션 · 조작기 줄이 프레이밍 여백으로 잡히지 않아 `boundsHint` 에 손으로 더했다 |
| G25 · G63 · G79 | 화면 px 굵기 · 반지름과 월드 간격이 서로 다른 배율을 따른다 — 좁은 임베드에서 띠 · 추가 열 간격보다 상대적으로 굵어진다 |
| G51 (일부 해결) | 폭포 무늬 6 710 칸을 매 프레임 새 값 배열로 넘기고 새로 칠한다. 이력은 1/6 초에 한 번만 바뀐다. 실시간 프레임률 미측정 |

### 새 부족

| 부족 | 영향 |
|---|---|
| **시간 이력 폭포 무늬(묶음 원소 × 시간)** 어휘가 없다 — 줄 밀기 · 이력 버퍼를 조각이 state 에 쌓고 매 프레임 전체를 `scalarField` 로 넘긴다. 원본 engineWish 둘째. 모양은 `scalarField` 로 서므로 칠 자체는 되지만 「일정 주기로 한 줄씩 밀리는 이력」 은 선언이 아니라 코드다 | 근사 |
| **검사 시각(고정 촬영) 동안 조작기를 비활성으로 그리는 선언**이 없다 — 원본 engineWish 넷째. G27 은 `button` 의 비활성 모양, 여기는 러너의 검사 모드와 슬라이더 | 근사 |

묶음 원소 i → 가로 열 x 공유 좌표(원본 engineWish 셋째)는 부족으로 올리지 않았다 — 월드 좌표 하나를 위아래가
같이 쓰는 것으로 충분했다. 진동자 묶음 적분(engineWish 첫째)은 조각의 물리 계산이라 올리지 않았다.

## (c) 근사가 주장을 약하게 했는가

약해지지 않았다(다크 테마 기준). 「쌓인다」 는 흔들림 폭 띠가 원본과 같은 식 · 같은 걸음으로 같은 열에서 길어지고,
무늬에 아래가 옅고 위가 진한 쐐기와 양옆 맥놀이 줄무늬가 원본과 같은 자리에 선다. 다만 G62 · G81 때문에 무늬의
공명 줄기가 원본보다 넓고 번져 「맞는 **것만**」 의 좁음은 무늬보다 위의 띠가 더 또렷이 말한다. 라이트 테마는 미확인.
