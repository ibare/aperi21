# second-law-of-thermodynamics — 열역학 제2법칙

자유 구현 원본이 없다. 엔진 어휘로 곧바로 지었다.
쓴 어휘: `particleSystem`(꼬리) · `trajectory`(닫힌 사각 · 점선 · 이력 곡선) · `trace`(dot) · `readout`
+ `timeline` · 캡션 슬롯(`vars`). 자유 렌더 없음, 조작기 없음.

## (a) 답하는 질문과 동사

**질문** — 섞인 것은 왜 저절로 다시 갈라지지 않나.

**동사** — *퍼지고, 되돌아오지 않는다.*

왼쪽 칸에만 있던 분자 N(50)개가 칸막이를 걷자 오른쪽 칸으로 퍼진다. 오른쪽 그래프가 **왼쪽 칸의
분자 수**를 시간에 따라 긋는다 — 맨 위 N 줄에 붙어 있다가 내려와 N/2 점선 둘레에서 작게 오르내리고,
기다림 단계 10 초 동안 곡선이 N 줄 가까이 다시 오르지 않는다. 「되돌아오지 않는다」 는 수가 아니라
**가로축 끝까지 비어 있는 N 줄 아래 공간**으로 보인다.

- 분자는 벽에서만 튄다(자유 팽창). 자리는 처음 자리 · 속도와 시각의 닫힌 식이라 `step` 에 쌓지 않는다.
  칸막이를 걷기 전에는 가로가 왼쪽 칸 안에서, `open` 단계 끝(`tl.end('open')`)부터는 상자 전체에서 튄다.
- 곡선은 매 프레임 주기 첫머리부터 지금까지 0.1 초 간격으로 왼쪽 수를 다시 센다 — 같은 시각은 같은 곡선이다.
- 주기가 끝날 때 분자를 왼쪽으로 **모아 되돌리지 않는다.** 흐려짐(`fade`) 단계에서 분자 · 곡선이 옅어지고
  다음 주기의 나타남(`appear`)에서 새로 뜬다. 되돌아가는 움직임을 보이면 주장과 반대 그림이 된다.

## (b) 화면 구성의 결정 — 두지 않은 것 포함

- **상자 + 그래프를 가로로.** 상자만으로는 「고르게 퍼졌다」 까지만 보이고 「다시 모이지 않는다」 는
  시간이 필요하다. 시간을 한 화면에 접어 두는 것이 그래프다. 그래프의 N 줄은 상자 윗벽과 같은 높이다.
- **가운데 점선을 칸막이를 걷은 뒤에도 남긴다.** 그래프가 세는 「왼쪽 칸」 이 어디까지인지가 화면에 있어야 한다.
- **세로 눈금은 기호 `N` · `N/2` 뿐.** 수 눈금을 달면 독자가 25 · 27 같은 값을 읽기 시작한다. 주장은 「N 에서
  N/2 로, 다시 N 으로는 안 간다」 라는 높이의 관계다. N 이 몇인지는 첫 캡션이 `{n}`(스테이지 상수)으로 한 번 말한다.
- **지금 왼쪽 수 글자를 띄우지 않는다.** 곡선 끝 점(강조색)의 높이가 그 값이다. 전부 왼쪽일 확률(2⁻ᴺ)도 두지 않는다
  — 문단의 몫이다 (지시).
- **분자는 한 색.** 왼쪽 · 오른쪽 분자를 색으로 가르면 색이 「어느 칸 출신인가」 를 설명하게 된다 (S-piece).
  강조색은 그래프의 지금 점 한 뜻에만 쓴다.
- **분자끼리 부딪히지 않는다.** 주장(퍼지고 되돌아오지 않는다)은 충돌 없이도 서고, 닫힌 식이면 시각만으로
  같은 화면이 보장된다. 충돌을 넣으려면 `initialState` 에서 한 주기를 미리 적분해야 한다.
- **되감기(irreversibility 몫) · 도깨비(maxwells-demon 몫)는 하지 않는다.**
- **조작기 없음.** 분자 수를 끌게 하면 작은 N 에서는 곡선이 N 에 다시 닿을 수 있어 캡션이 틀려진다. 이 조각의
  질문은 「기체 규모에서 되돌아오는가」 하나다.
- **캡션 참 보장** — 시드 8 · 속도 척도 0.5 에서 기다림 단계 내내 왼쪽 수는 22~29 다(모의 확인). 결과가 시드로
  고정이라 모든 주기에서 「N 줄 가까이 다시 오르지 않는다」 가 참이다. 시드를 바꾸면 촬영으로 다시 본다(schema 주석).
- `startAt: 0.6` — 도착한 순간 분자가 이미 왼쪽 칸에서 튄다. 쌓는 상태가 없어 `preroll` 은 쓰지 않는다.
- `WALL_MARGIN`(0.03) 은 점이 벽선에 반쯤 걸치지 않게 하는 그림 여백이라 스테이지 상수가 아니라 physics 머리 상수다.
- 그래프 자리(`GRAPH.origin`)와 경계(`SCENE_BOUNDS`)는 기본 상자 크기(2 × 1.2)에 맞춘 고정값이다. 저작자가
  `boxWidth` 를 크게 바꾸면 상자가 그래프 쪽으로 넘어간다 — 원칙 6 에 따라 경계를 상태 · 상수로 계산하지 않았다.

## (c) 어휘 부족

**주장 부족 없음.** 근사한 곳은 모두 모양의 문제다.

| 장부 | 이 조각에서 |
| --- | --- |
| G203 | 월드에 놓이는 x–y 선 그래프가 없다 — 축 · N 줄 · N/2 점선 · 이력 곡선 · 지금 점을 `trajectory` · `trace` 로 조립하고 좌표 사상을 scene 이 한다 |
| G47 | 축 어휘가 없다 — 세로 눈금 표식 `N` · `N/2` 와 축 이름을 `readout` 넷으로 손수 붙였다 |
| G181 | `particleSystem` 꼬리가 속도 반대 방향의 곧은 획이라, 벽에서 막 튄 분자의 꼬리가 벽 밖으로 삐진다. 꼬리 시간을 0.1 초로 줄여 눈에 덜 띄게 했다 |
| G133 | 캡션 `{n}` 을 스테이지 상수에서 끼우려고 `initialState` 가 `countText` 를 state 에 둔다 |
| G24 | 캡션 슬롯 자리가 프레이밍 여백에 잡히지 않아 `SCENE_BOUNDS` 아래(−0.5)를 손으로 비웠다 |

새 부족은 나오지 않았다. 벽 반사 닫힌 식 · 왼쪽 수 세기 · 시간 → 그래프 가로 사상은 조각의 물리 · 배치 계산이다.

직접 열어 확인했다 (2026-09-19). `?t=` 는 `startAt`(0.6) 에서부터 흐른 시간이다.

| t(초) | 라이트 · 다크 |
| --- | --- |
| 0.4 | 분자 50개가 칸막이 왼쪽에서만 튄다. 곡선이 N 줄 위를 수평으로 자란다. 캡션 「분자 50개(N)」 |
| 3.2 | 칸막이가 걷혔고 분자 몇 개가 가운데 점선을 넘었다. 곡선이 N 에서 막 꺾여 내려온다 |
| 4.6 | 오른쪽 칸 곳곳에 분자가 퍼졌고 곡선은 N/2 점선에 닿았다 |
| 9 | 양쪽이 고르게 섞였다. 곡선은 N/2 둘레에서 작게 오르내린다 |
| 15 | 가로축 끝 무렵까지 곡선이 N/2 둘레에만 있었고 N 줄 아래가 비어 있다 |

- **다크** — 상자 · 칸막이 · 곡선이 밝은 먹색으로 뒤집히고 분자는 붉은 `primary`, 지금 점은 금빛 강조색으로 남는다.
  N 실선 · N/2 점선이 바탕에서 갈린다.
- **라이트** — 글자 · 표식 겹침, 화면 밖으로 나간 것 없음.
- 1차 촬영에서 고친 것 — 꼬리 0.18 초는 벽 밖으로 길게 삐져 0.1 초로 줄였고, `t = 2.7` 은 퍼짐 단계 0.3 초째라 아직
  아무 분자도 가운데를 넘지 않아 검사 시각을 3.2 로 옮겼다.
