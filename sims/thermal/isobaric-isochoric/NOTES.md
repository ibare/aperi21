# isobaric-isochoric — 제작 기록

자유 구현 원본 없이 엔진 어휘 위에서 바로 지었다.

## (a) 답하는 질문과 동사

**질문** — 같은 처음 상태의 기체에 같은 열을 넣을 때, 압력을 붙드는 것과 부피를 붙드는 것은 무엇이 다른가.

**주장 한 문장** — 같은 열을 넣어도 압력을 붙들면 P-V 그림에서 가로로, 부피를 붙들면 세로로 가고, 부피를 붙든
쪽은 일을 하지 않는 대신 온도가 더 오른다.

**동사** — (두 점의 경로가) *가로와 세로로 갈린다.*

화면에서 일어나는 방법: 왼쪽 P-V 그림의 처음 상태 A 에서 두 점이 같은 시각에 떠난다. 「압력 고정」 점은 오른쪽으로
가며 그 아래가 강조색으로 칠해지고, 「부피 고정」 점은 위로 올라가며 아래 넓이가 생기지 않는다. 오른쪽에는 두 실린더가
나란히 있다 — 추를 얹은 자유 피스톤은 오르고, 핀 두 개에 박힌 피스톤은 그대로다. 두 가열판이 같은 시간 같이 켜지고
(`Q` 표식이 둘 다에 붙는다), 두 온도 막대가 같은 처음 눈금에서 같은 눈금 척도로 오른다. 가열이 끝나면 가로선 아래 넓이에
`W`, 세로선 옆에 `W = 0`, 온도 막대 끝에 `+180 K` · `+300 K` 가 선다.

## (b) 화면 구성의 결정

- **나란히, 같은 시각에.** 이웃 `first-law-of-thermodynamics` 는 자유 → 고정을 차례로 보이고 열의 분배(알갱이)를,
  `pv-diagram` 은 같은 A → B 의 두 길 넓이를 보인다. 이 조각은 **한 점에서 동시에 갈라지는 방향** 이 주장이라
  두 통을 나란히 두고 P-V 그림 한 장에 두 점을 함께 움직였다. 판은 하나다.
- **두 과정을 색으로 가르지 않는다.** 두 길 · 두 점은 같은 먹색이고, 「압력 고정」 · 「부피 고정」 이름표가 실린더 위와
  P-V 점 옆에 같은 말로 붙어 둘을 잇는다. 무엇이 붙드는지는 장치의 모양(추 · 핀)이 보인다.
- **강조색은 넓이(기체가 한 일) 한 뜻에만.** 가열판 · 추 · 핀 · 온도 채움은 먹색, 축 · 피스톤 · 관은 `muted`.
- **온도는 한 역할의 막대 높이.** 두 막대가 같은 처음 눈금 · 같은 척도(가장 큰 상승이 관 끝 근처)라 높이 비가
  곧 3 : 5 다. 비 글자(「3 : 5」 · 「5/3 배」)는 띄우지 않고, 오른 값 `+180 K` · `+300 K` 만 스테이지 상수
  `dTp` · `dTv` 의 `String(값)` 으로 끼운다. 캡션의 300 · 180 · 300 도 state 경유(G133 우회).
- **수를 더 띄우지 않는다.** P · V 눈금 숫자, J 값, 넣은 열의 양, 몰수, 끝 부피 · 끝 압력은 두지 않았다. 주장은
  「방향과 넓이, 어느 쪽이 더 오르나」 라서 선의 방향 · 넓이 유무 · 막대 높이로 충분하다. 끝 부피(1.6 L) · 끝 압력
  (2 칸)은 이상 기체의 배치 계산(V = v0·T/t0, P = p0·T/t0)이고 화면에 식은 없다.
- **`W = 0` 표식을 세로선 옆에 둔다.** 「넓이가 0」 은 칠해지지 않은 것만으로는 「아직 안 칠해졌다」 와 구별되지 않아,
  가열이 끝난 hold 단계에서 표식 한 조각으로 못 박았다(식이 아니라 도식 옆 기호 — S-piece 허용 범위).
- **분자는 두지 않았다.** 온도는 막대가 맡는다 — 분자 자취까지 두 통에 두면 오른쪽이 붐벼 P-V 그림이 작아진다.
- 두지 않은 것 — 등온선, 그리드, 조작기, 제목 · 범례, 처음 온도 눈금 글자(캡션이 한 번 말한다). 조작기로 열의 양을
  바꾸게 해도 주장(방향 · 넓이 · 비)은 달라지지 않는다.
- `startAt` 3.0 — 도착하면 가열이 1/4 쯤 진행되어 두 점이 이미 갈라지는 중이다.
- 첫 촬영에서 P-V 그림이 작아 가로선 · 세로선이 짧아 배율을 키웠다(1 L = 2.4, 압력 한 칸 = 1.35).
