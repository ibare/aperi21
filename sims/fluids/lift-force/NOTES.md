# lift-force — 이관 기록

원본: `tasks/piece-lab/lift-force/` (자유 구현). 자유 렌더 없이 선언만으로 옮겼다.

## 쓴 어휘

| 원본 묶음 | 어휘 | 선언 |
|---|---|---|
| 압력장 | `scalarField` 순차형 (`secondary`) | 430 × 155 칸 (원본 2 px 표본 그대로), 값은 Cp 를 0.25 계단으로 끊어 원본 색 한 줄의 어둡기로 옮긴 것, 범위 `[0, high − low]` |
| 연기 줄 | `lineSet` | `ink` · `opacity` 0.42 · 굵기 1.1 px · 원본 캔버스 사각형 `clip` |
| 추적 연기 줄 | `lineSet` | `accent` · 굵기 2.4 px · 같은 `clip` |
| 날개 | `region` | 240 점 다각형, `fillOpacity` 1, `ink` medium (원본 짙은 회색에 가장 가깝다) |
| 캡션 | `caption` 슬롯 | 아래 왼쪽 15 px, `cases: [{ when: 'flat' }]` — 받음각 0° 일 때만 문장이 바뀐다 |
| 받음각 | `slider` | 0~12, step 1, 기본 8, 아래 오른쪽 |
| 도착 즉시 진행 중 | `preroll: 7` | 원본 `WARM = 7` 초를 고정 걸음으로 |
| 겹침 | `drawOrder: 'scene'` | 압력장 · 연기 줄 · 추적 줄 · 날개 (원본 순서) |

시간표(`timeline`)는 선언하지 않았다. 원본에 연출 시간표가 없다 — 0.8 초마다 뿌리는 방출은
시각의 함수가 아니라 적분 상태(표지 위치)의 일이라 `step` 이 한다. `startAt` 도 쓰지 않았다 —
시계를 앞당겨도 표지는 쌓이지 않는다.

## (a) 원본과 달라진 점과 이유

- **압력장 색.** 원본은 색 한 줄(밝음 = 고압 · 옅은 회색 = 먼 흐름 · 짙은 회청 = 저압)을 sRGB 로
  섞었다. 조각은 테마 색을 알지 않으므로(C2) 원본 색의 **명도 순서와 간격**만 값(고압 끝에서의 어둡기)으로
  넘기고, 색은 렌더러의 순차형 사상(바탕 → `secondary`, 빛의 양으로 섞음)에 맡긴다. 결과 —
  - 명도 순서(고압 > 먼 흐름 > 저압)는 원본과 같다. 정체점 둘레가 먼 흐름보다 밝고 윗면 앞쪽이 가장 짙다.
  - 빛의 양으로 섞어 중간 띠가 원본보다 옅고, 저압 끝은 원본의 탁한 회청보다 채도 높은 파랑이다.
  - 고압 끝은 원본이 종이보다 조금 밝았는데 여기서는 바탕 그대로다.
- **추적 줄 강조색.** 원본 주황 대신 테마 `accent`(호박색). 뜻은 같다(한 줄을 끝까지 따라가라).
- **캡션 · 조작기 자리.** 원본은 캔버스 **밖** 아래 줄이다. 엔진의 캡션 슬롯 · 조작기는 캔버스 안에
  얹히므로, 프레이밍(`boundsHint`)에 원본 캔버스 아래 56 px 한 줄을 더하고 캔버스를 400 px 로 두었다.
- **연기 줄 자르기.** 원본은 캔버스 가장자리가 자연히 잘랐다. 여기서는 캔버스가 원본 캔버스보다 넓어
  (프레이밍 여백) 방출 줄의 위아래 끝(±1.05 × 반폭)과 오른쪽 끝에 쌓인 표지가 보였다 → 원본 캔버스
  사각형으로 `clip`.
- **받음각을 바꾸면 새로 흘리기.** 원본은 입력 이벤트에서 `resetFlow()` 를 불렀다. 엔진은 조작값이 state 에
  적힐 뿐이라 `step` 이 `aoaDeg ≠ flowAoaDeg` 를 보고 첫 줄을 뿌린 뒤 7 초를 스스로 다시 걷는다(약 60 ms).
- **고정 걸음.** 원본 `PieceKit.loop` 는 1/60 초 고정 걸음이다. 실시간 dt 가 가변이라 `step` 이 누적기(`acc`)로
  나눠 걷는다. 한 프레임 최대 6 걸음.
- **슬라이더 값 표시** 가 `8 °` (숫자와 단위 사이 공백). 원본은 `8°`.
- 두지 않은 것은 원본 그대로 — 양력 화살표 · 양력 계수 · 순환 · 속력 숫자 · 유선 · 경계층 · 그리드 · 카메라 버튼.

대조(`pnpm piece:report --sims`, t = 0 · 1 · 1.5 · 2): 네 시각 모두 추적 줄 · 연기 줄의 자리와
갈라진 모양이 원본과 같다. t = 1.5 에서 새 추적 줄 위쪽 절반이 윗면 앞을 넘고 아래쪽 절반이 앞전
아래에 붙어 있는 것, t = 2 에서 위쪽이 윗면 중간 · 아래쪽이 아랫면 앞쪽에 뒤처진 것이 원본과 같다.

## (b) 어휘 부족

### 장부에 있는 것

| 장부 | 여기서 겪은 것 |
|---|---|
| G30 (일부 해결) | 값→색 척도가 테마 바탕에서 시작하는 한 줄뿐이다. 원본의 고압 끝은 바탕보다 밝았는데 바탕을 넘을 수 없다. 탁한 회청 같은 역할도 없다(G08 과 같은 뿌리) |
| G62 | 값→색 사상 곡선 · 섞기 공간을 고를 수 없다 — 원본은 sRGB 로 섞은 명도 한 줄이고 엔진은 빛의 양으로 섞어 중간 띠의 명도 대비가 원본과 다르다. 조각이 이를 되풀어 맞추려면 테마 명도를 들고 있어야 해 C2 위반이 된다(처음 이관에서 그렇게 했다가 지웠다). 근사 |
| G23 | 조작값이 바뀌면 누적 상태를 새로 미리 진행하는 규약이 없다. `preroll` 은 마운트 때 한 번뿐이라 `step` 이 7 초 재워밍을 직접 한다 (원본 engineWish 넷째) |
| G39 | 실시간 dt 가 가변이라 고정 걸음 누적기를 조각이 둔다 |
| G24 | 캡션 · 조작기 줄이 프레이밍 여백으로 잡히지 않아 `boundsHint` 에 한 줄을 손으로 더했다 |
| G51 (일부 해결) | 압력장은 받음각이 바뀔 때만 달라지는데 `scalarField` 는 매 프레임 66 650 칸을 다시 칠한다. 정적인 장을 한 번만 굽는 선언이 없다. 실시간 프레임률은 미측정 |
| G22 | 슬라이더 값과 단위 사이에 공백이 고정이다(`8 °`). 단위 표기를 고를 수 없다 |

### 새 부족

없다. 처음 새 부족으로 적었던 「테마 명도를 들고 섞음 비를 되푼다」는 C2 위반으로 코드에서 지우고 장부 G62 로 옮겼다.

엔진에 물체 모양 + 받음각으로 속도장을 주는 흐름장 · 타임라인(동시 방출 표지) 적분기가 없는 것은
원본 engineWish 에 있으나, 조각의 물리 계산이라 부족으로 올리지 않았다 (`physics.ts` 에 원본 식 그대로).

## (c) 근사가 주장을 약하게 했는가

약해지지 않았다. 동사 「앞질러 간다」는 표지 적분이 원본과 같은 식 · 걸음이라 같은 자리에서 일어난다.
「위쪽 압력이 낮다」는 윗면 쪽이 짙은 명도 순서로 그대로 읽힌다(C2 수정 뒤 네 시각 다시 확인).
달라진 것은 중간 띠의 명도 대비와 저압 끝의 채도이고, 주장 문장에 들어 있지 않다.
