# 관 속의 층류 — 이관 NOTES

원본: `tasks/piece-lab/poiseuille-flow/` (자유 구현). 주장·화면 구성 결정은 원본 `NOTES.md` 를 그대로 따른다.
이 문서는 엔진 선언으로 옮기며 **달라진 점**과 **어휘 부족**만 적는다.

## 쓴 어휘

| 원본 표지 | 어휘 |
|---|---|
| 관 속 물 · 단면 원의 물 · 받는 칸의 물 | `region` (`opaque`, `secondary` · `medium`, 기본 채움 불투명도) — 같은 물은 같은 선언 |
| 단면 원 테두리 · 입구 / 출구 타원 | `trajectory` `closed` (`ink`, 굵기 3 · 1.5) — 점 64 개로 표본 |
| 위아래 벽 | `surface` `wall` |
| 흐름 점 | `particleSystem` (관마다 하나, 원본과 같은 mulberry32 시드 1 수열) |
| 염료 전선 | `lineSet` (관마다 하나, 선별 `opacities` = 1 − 나이/수명, `clip` 으로 관 안만) |
| 칸 테두리 | `lineSet` (관마다 하나, `muted`, 굵기 1) |
| 채움 → 머묾 주기 | `timeline` (`fill` 8 초 · `hold` 2 초) + `startAt: 1` — 칸 채움 = `at('fill')` |
| 고정 캡션 | `caption` 슬롯 (`text` 키 하나) |
| 그리기 순서 | `drawOrder: 'scene'` (단면 → 물 → 점 → 염료 → 벽 → 칸) |

상태는 비어 있다. 흐름 점 · 염료는 시계의 함수, 칸은 시간표의 함수다. 자유 렌더 없음. 조작기 없음. 크롬 없음.

## (a) 원본과 달라진 점

- **색이 테마 역할이다.** 원본의 물색(`#b9d4ea`) · 염료색(`#2c5d85`) · 벽색(`#3a3a3a`) · 칸 테두리(`#8a8a8a`) 대신
  `secondary` 옅게 · `secondary` 짙게 · 먹 · `muted`. 다크 테마에서는 물이 어두운 파랑, 벽이 밝은 먹이 된다.
- **흐름 점의 색.** 원본은 물 위의 흰 점(0.85)이다. 바탕색 역할이 없어 `luminance: 0`(= 테마 바탕색)으로 칠했다.
  라이트 테마에서는 물보다 밝은 점이지만, **다크 테마에서는 물보다 어두운 점**이 된다 (「어휘 부족」 1).
- **흐름 시계.** 원본은 칸의 위상만 1 초 앞당기고 점 · 염료는 0 초에서 출발한다. 같게 하려고 `startAt: 1` 을 선언하고,
  점 · 염료는 `timeline.t − schema.startAt` 을 읽는다. 대조 화면의 점 배치 · 전선 위치가 원본과 같은 시각에 맞는다.
- **캡션이 캔버스 안에 있다.** 원본은 캔버스 밖 문단이다. 프레이밍 아래에 한 줄 자리(월드 34)를 더하고 캔버스 높이를
  400 으로 잡았다. 카탈로그 폭에서 배율이 원본의 약 0.9 배다 — 화면 px 로 선언한 점 크기 · 선 굵기는 원본 값 그대로라
  그만큼 상대적으로 조금 굵다.
- **염료 전선의 옅어짐이 8 단계다.** `lineSet.opacities` 반올림으로 나이 약 5.8 초 넘은 전선(1/16 미만)이 원본보다 일찍
  사라진다 (G53).
- 원 · 타원을 점 64 개 다각형으로 그린다 (G28). 확대하지 않으면 구별되지 않는다.

## (c) 어휘 부족

조각의 물리 · 배치 계산(염료 전선을 x = 입구 + u(s)·나이 로 짓는 것, 점을 관 길이로 되감는 것, 칸을 아래 줄부터 채우는
배치)은 부족으로 세지 않았다. 원본 `engineWish` 의 「물질선」 「흐름 입자」 「칸 격자 채우기」 는 그 계산이라 여기 넣지 않았다.

| 부족 | 영향 | 근거 |

## (d) 판정 — 근사로 주장이 약해졌는가

약해지지 않았다. 주장은 「칸 개수 1 : 16」 · 「포물선 끝 앞섬 4 배」 · 「단면 원 넓이 4 배」 로 서는데, 셋 모두 원본과
같은 좌표 · 같은 시각에 같은 모양으로 일어난다. 근사는 모두 색조 · 곡선 매끄러움 · 옅어지는 끝에 머문다.
