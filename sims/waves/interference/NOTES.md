# interference — 간섭 (이관 기록)

원본: `tasks/piece-lab/interference/` (자유 구현). 주장·결정의 근거는 원본 `NOTES.md` 를 본다.

주장: 두 파원의 물결이 겹치면 어떤 자리는 두 물결이 서로를 지워 줄지어 **잠잠해진다**.

## 쓴 어휘

- `scalarField` — 수면 높이장 하나. 원본과 같은 2 월드 칸 격자(430 × 170 = 73100 값)를 발산형
  (`low` · `high` 모두 `secondary`, 범위 −1 ~ 1)으로 칠해 부드럽게 늘려 그린다
- `body` circle — 두 파원. 켜짐은 `fill: 'solid'`, 멈춤은 `fill: 'none'` + `outline: 'role'`, `glow: false`
- `BundleSchema.timeline` — `solo` · `spread` · `hold` · `withdraw` · `rest` 다섯 단계, 단계마다 캡션 키
- `BundleSchema.caption` — 수면 아래 왼쪽 한 줄, `fade: 0`
- `BundleSchema.drawOrder: 'scene'` — 수면 위에 파원을 쓴 순서대로 그린다
- `BundleSchema.canvas` · `boundsHint` (고정 경계)

상태는 비어 있다. 수면·파원·캡션이 모두 시계의 함수다. `startAt` 은 0 — 원본도 시계 0 에서
열리고, 그 순간 이미 첫째 파원의 물결이 수면 전체를 덮고 있다.

### 수면 색 — 색 역할 판단

원본 결정은 「한 가지 물빛의 명암」 이다. 발산형은 두 끝에 역할을 하나씩 받는데, 물빛으로 읽히는 역할은
`secondary` 하나뿐이다. 두 가지를 찍어 비교했다.

- `low: 'ink'` · `high: 'secondary'` — 마루 · 골이 갈리지만, 선형광 섞기에서 `ink` 골이 회갈색으로 보여
  **파랑 마루 · 회색 골의 두 색**이 되었다. 부호를 색으로 가르는 셈이고 「한 가지 물빛」 을 깬다.
- `low: 'secondary'` · `high: 'secondary'` (채택) — 한 가지 물빛만 쓴다. 마루 · 골의 명암은 잃는다.

「색으로 설명하지 않는다 · 강조색은 한 뜻」: 수면은 한 역할(`secondary`)의 짙기만 쓰고 두 물결 · 마루 · 골을
색으로 가르지 않는다. 강조색(`accent`)은 파원 한 뜻에만 쓴다. 캡션의 `ink` 는 글자다.

## (b) 어휘 부족

### 장부에 있는 것

- **G03** — `body` 둘레 굵기를 고를 수 없어 멈춘 둘째 파원의 테두리가 가늘다.
- **G13** — 「다 덮음」·「다 빠짐」 단계 길이가 파원 배치·물결 속력에서 나오는데 시간표가 그 계산을 받지 못해
  `schema.ts` 가 모듈 상수로 계산한다. 저작자가 파원을 옮기면 단계 길이가 따라오지 않는다.
- **G24** — 캡션 자리가 프레이밍 여백으로 잡히지 않아 경계 아래에 빈 띠를 손으로 둔다.
- **G25** — 파원 점 크기를 화면 px 로 고정할 수 없다.

- **G29** — 해결됨 (2026-09-17 묶음 그리기). 수면을 `scalarField` 하나로 선언한다. 원본과 같은 2 칸 해상도로
  부드럽게 늘려 그려 계단 무늬가 없어졌다.
- **G30** — 일부 해결 (2026-09-17 묶음 그리기) — 발산형이 생겨 다크 테마에서 뒤집히지 않고 잠잠한 곳이 바탕이 된다.
  다만 이 조각이 바라는 「한 역할의 명암」 은 아직 없다 → 아래 새 부족.
- **G51** — 일부 해결 (2026-09-17 묶음 그리기) — 선언 수는 풀렸다. 이 조각의 한 프레임 선언은 8210 → 3 이다. 다만 매 프레임 값 73100 개를
  scene 에서 계산해 배열로 넘기므로 실시간 프레임률은 여전히 **확인하지 못했다**(스크린샷은 가상 시간).

### 새 부족

- **한 역할 안에서 음 · 양을 명암으로 가르는 색 사상이 없다** — 영향 `근사`.
  발산형 `scalarField` 는 가운데가 바탕이고 두 끝이 역할 색이라, 한 가지 물빛으로 칠하면 마루와 골이 같은 짙기가
  된다(두 역할을 쓰면 두 색이 된다). 원본은 가만 = 중간 톤, 마루 = 옅게, 골 = 짙게였다. 잠잠한 줄은 오히려
  또렷해졌지만 물결의 오르내림(마루 · 골)이 정지 화면에서 읽히지 않고, 띠가 반 파장 간격으로 보인다.
  원본이 바란 것: 한 색 역할의 세 점(짙게 · 중간 · 옅게) 사상. G30 에 대 둔다.
