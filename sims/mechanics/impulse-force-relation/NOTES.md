# impulse-force-relation — 이관 NOTES

원본: `tasks/piece-lab/impulse-force-relation/` (딱딱한 벽 줄 · 푹신한 방석 줄을 나란히, 방석 멈춤 시간
슬라이더). 자유 렌더 없이 선언만으로 옮겼다. 좌표는 원본 876×300 px 캔버스를 y 만 뒤집어 월드 단위로 쓴다.

시계를 0 으로 되돌리는 것만으로 처음이 된다.

## (a) 원본과 달라진 점과 이유

- **캡션 · 조절기가 캔버스 안에 들어왔다.** 원본은 300 px 캔버스 아래 DOM 한 줄이었다. 캔버스를 350 px 로
  두고 경계 아래 44 단위를 캡션 · 조절기 자리로 잡았다. 엔진의 맞춤 여백 때문에 같은 900 px 창에서 그림이
  원본의 약 0.8 배로 작다.
- **방석 색이 베이지가 아니라 옅은 회색이다.** 테마에 「물체의 옅은 바탕색」 역할이 없다. `accent` 를 옅게 쓰면
  베이지에 가깝지만 이 조각에서 `accent` 는 힘(화살표 · 곡선 · 넓이) 한 가지 뜻이라 쓰지 않았다(S-piece).
  원본 주황 · 파랑은 테마 `accent` · `secondary` 로 톤이 조금 다르다.
- **짧은 화살표의 머리가 작다.** 원본 머리는 min(9, 길이·0.6), 엔진은 min(9, 길이·0.35). 방석 쪽 힘 화살표
  (최대 18 px)는 머리가 거의 안 보이고 공 안의 짧은 주황 선으로 읽힌다.
- **조절기 값 단위가 「초」가 아니라 `s` 이다.** `slider.unit` 은 문자열 표식이라 언어별 문안을 줄 수 없다.
- **캡션은 원본과 같은 판정으로 고른다** — 접촉 여부를 state 에 두고 `cases` 로. 조절기 8 값(0.25~2) 모두
  1/60 s 걸음으로 두 주기를 돌려 원본 `captionFor` 와 견줬다. 어긋난 걸음은 전환 경계의 한 걸음씩 6 개뿐이다
  (부동소수 누적).

  | 방석 시간 | 캡션 전환 (주기 안 시각 → 문장) |
  |---|---|
  | 0.25 | 0 날아간다 → 1.00 「같은 짧은 시간」 → 1.25 「같은 시간이면 힘도 같다」 |
  | 0.5 | 0 날아간다 → 1.00 「벽이 순식간에」 → 1.25 「방석은 아직」 → 1.50 「둘 다 멈췄다」 |
  | 1.5 | 0 날아간다 → 1.00 「벽이 순식간에」 → 1.25 「방석은 아직」 → 2.50 「둘 다 멈췄다」 |
  | 2.0 | 0 날아간다 → 1.00 「벽이 순식간에」 → 1.25 「방석은 아직」 → 3.00 「둘 다 멈췄다」 |

- 원본의 `PieceKit.frozen` 이면 기본값으로 그리는 분기는 옮기지 않았다 — 검사 시각은 초기 상태(1.5 초)로 연다.

## (b) 어휘 부족

1. **시간표 단계 경계가 상태(조작기 값)를 따라갈 수 없다.** 방석 쪽이 멈추는 시각은 1 + 조절기 값인데
   `TimelinePhase.duration` 이 상수라 「방석이 멈추는 중」 단계를 선언할 수 없다. 그래서 단계에 캡션을 걸지 못하고
   전부 `caption.cases` 로 골랐다. 후보: 단계 길이를 state 경로로 가리키기.
2. **`step` 이 `TimelineFrame` 을 받지 못해 시계를 둘 센다.** `cases` 는 state 경로만 보므로 `step` 이 주기 안
   시각 `u` 를 따로 적분하고 주기 · `restart`(잡는 동안 0)를 손으로 맞췄다(`atwood-machine` 과 같은 우회).
   두 시계가 어긋나면 캡션이 그림과 한 걸음 어긋날 수 있다. 후보: `step` 에 `timeline` 을 넘기거나 `cases` 가
   시각 조건을 state 와 함께 보게 하기.
3. **옅은 물체 바탕색 역할이 없다.** 방석 같은 무채 아닌 옅은 물체 면을 낼 색 역할이 없어 `muted subtle` +
   `opacity` 로 근사했다.
4. **`vector` 화살촉의 길이 대비 최대 비율이 0.35 로 고정이다.** 짧은 힘 화살표에서 머리가 사라져 방향이 약하게
   읽힌다. 원본은 0.6 이었다.
5. **`slider.unit` 이 `LocalizedText` 가 아니다.** 「1.50초」 를 낼 수 없어 `s` 로 두었다.
6. **`body` custom 의 테두리 굵기를 줄 수 없다.** 원본 방석 윤곽 1.5 px 이 테마 thin(1 px)이 됐다.
