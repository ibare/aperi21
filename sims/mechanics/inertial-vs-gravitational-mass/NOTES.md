## (a) 원본과 달라진 점과 이유

- **저울 기울기가 모자란 몫에 비례한다 (사용자 승인).** 원본은 되돌리는 돌림힘이 없어 추 2 개(7.2 초)에서도
  저울이 멈춤 각 0.2 rad 까지 가 추 1 개(3.2 초)와 기울기가 같았다 — 「모자람이 줄어든다」가 저울에서 보이지
  않았다. 각가속도에 되돌리는 항 `−(G_TORQUE / TILT_PER_UNIT)·θ / (m+n+0.5)` 를 더해 평형각이
  `0.055 × (물체 질량 − 추)` 가 되게 했다. 나머지 상수(G_TORQUE 2 · 감쇠 3 · 버팀 0.5 · 멈춤 각 0.2)는 원본 그대로다.
  1/60 초 걸음으로 세 물체 두 바퀴를 돌려 확인한 최대 각: 돌 0.125 · 쇠공 0.182 · 나무토막 0.065 — 모두 멈춤 각에
  닿지 않는다. 돌은 추 1 개 ≈ 0.11, 2 개 ≈ 0.055, 3 개 0 으로 줄어든다.
- **물체 색이 흙빛 셋이 아니라 먹의 짙기 셋이다.** 색 역할에 회갈 · 청회 · 황갈이 없다. 쇠공(가장 짙음) · 돌 · 나무토막
  (가장 옅음) 순서만 `luminance` 로 지켰다. 같은 물체는 두 칸에서 같은 색이라 주장은 그대로다.
- **물체 모서리가 둥글지 않다.** `body` rect 에 모서리 둥글림이 없다. 물체 테두리(원본 옅은 검정 선)도 없다.
- **추의 테두리가 없다.** 원본은 채움보다 짙은 테두리였는데 `body.outline` 은 테마 선색 · 바탕색 · 제 색뿐이라 짙은
  테두리를 낼 수 없다. 칸 사이 1 px 틈으로 개수를 읽히게 했다.
- **용수철 모양** — 엔진 코일은 목(양 끝 곧은 부분)이 있고 벌어짐이 7 px(원본 6 px)이다. 5 물결은 같다.
- **캡션 · 물체 고르기 줄이 캔버스 안에 들어왔다.** 원본은 260 px 캔버스 아래 DOM 이었다. 캔버스를 360 px 로 두고
  경계 아래 85 만큼 자리를 잡았다. 칩 줄은 엔진 칩 모양(누른 칩이 채워짐)이다.
- **캡션 문안은 물체마다 한 문장씩 셋이다.** 원본은 `${o.name}` 을 끼웠지만 이름은 번역 대상이고 조사와 붙어 있어
  값으로 끼우지 않았다 (C1). 판정은 원본과 같다 — 놓기 전 / 놓은 뒤 추 < 질량 / 놓은 뒤 추 = 질량.
  위 두 바퀴 걸음에서 캡션 경우와 화면 상태가 어긋난 걸음은 0 이다(놓기 전에는 각 · 변위 0, 모자람이면 θ ≥ 0 이고
  추 변위 ≥ 물체 변위, 맞음이면 θ = 0 이고 두 변위 크기 같음).
- **물체를 다시 고르는 신호가 둘이다.** 원본은 단추를 누르면(같은 물체여도) 시계를 0.5 초로 되돌렸다. 여기서는
  `heldPath` 가 true 인 동안과 `obj ≠ shownObj` 일 때 step 이 시계 0.5 초 · 저울 · 얼음을 되돌린다. 누르고 떼기가
  한 프레임 안에 끝나면 같은 물체 다시 누르기는 놓칠 수 있다(미확인 — 실시간 화면에서 재현해 보지 않았다).
- 원본의 `PieceKit.frozen` 이면 입력을 무시하는 분기는 옮기지 않았다 — 검사 시각은 조작 없이 연다.

## (b) 어휘 부족

1. **시간표 단계 길이가 상태를 따라갈 수 없다.** 원본의 연출 시간표(잡기 0.8 → 관찰 3.4, 맞으면 5.2)는 분명한
   단계인데, 시험 **수**가 고른 물체의 질량(2 · 3 · 4)이다. `TimelinePhase` 는 상수 길이 목록이라 물체마다 다른
   주기를 적을 수 없어, 시간표를 선언하지 않고 `step` 이 시험 시계를 따로 센다. 저자가 「잡기를 0.3 초 더 길게」를
   선언에서 할 수 없다 (원칙 2). 후보: 단계 목록을 state 값으로 고르는 여러 시간표, 또는 되풀이 횟수를 state
   경로로 가리키는 단계 묶음(`repeat: 'mass'`).
2. **`step` 이 `TimelineFrame` 을 받지 못한다.** 위와 겹친다 — 시험 경계에서 적분 상태(저울 각 · 변위)를 비워야
   하는데 step 은 단계 전환을 모른다. 시간표를 쓸 수 있었더라도 step 이 제 시계를 따로 세야 했다.
3. **`restart` 는 엔진 시계만 되돌린다.** 이 조각은 엔진 시계를 읽지 않아 `restart` 자체로는 아무 일도 일어나지
   않고, 실제 되돌리기는 `heldPath` · 값 변화로 step 이 한다. 누르고 떼기가 한 프레임 안에 끝나면 step 이 `held` 를
   보지 못한다. 후보: 조작기가 state 를 건넬 때 **조각 상태도 `initialState` 로 다시 만드는** 선택지(값만 유지).
4. **`body` rect 에 모서리 둥글림이 없다** (engine-fit 이 이미 적음). 돌 · 나무토막 · 쇠공의 모양 차이가 줄었다.
5. **`body.outline` 에 「제 색보다 짙게」가 없다.** 추처럼 옅은 채움 + 짙은 테두리를 낼 수 없어 틈으로 근사했다.
6. **색 역할에 무채가 아닌 물질색(흙빛 · 나무색)이 없다.** 강조 없이 물체끼리 구별되는 중립 색 몇 가지가 있으면
   원본의 물체색을 옮길 수 있다. 지금은 짙기만으로 가른다.
