# atwood-machine — 이관 NOTES

원본: `tasks/piece-lab/atwood-machine/` (사용자 검토 뒤 다시 만든 판 — 합 5 kg 기계 두 대,
왼쪽 차이 0.5 고정 / 오른쪽 차이 슬라이더). 자유 렌더 없이 선언만으로 옮겼다.

## 쓴 어휘

| 원본 요소 | 어휘 |
|---|---|
| 바닥 · 출발 높이 점선 | `trajectory` (width 1.5 / width 1 · dashed · opacity 0.5) |
| 차이 이름표 | `readout` (world 앵커 · chip 없음 · font text · 13 px) |
| 0.1 초 자취 ×2 | `trace` (dot · size 3 · opacity 0.45 · age 없음) — 자리는 주기 안 시각의 닫힌 식 |
| 줄 · 도르래 원 · 매단 줄 · 바큇살 | `trajectory` (원은 closed 64 각형, 굵기 2 / 줄 1.5) |
| 도르래 축 | `body` point |
| 무거운 추 · 가벼운 추 | `body` rect (outline none) + `readout` (질량 소수 둘째 자리) |
| 차이 조절기 | `slider` (range [0,2] · step 0.1 · digits 1 · **`restart: true`**) |
| 차이 조절기 잡는 동안 | `heldPath: 'held'` |
| 주기 · 앞당김 | `timeline` 두 단계(fall 1.807 · hold 1.8, 캡션 없음) + `startAt: 0.2` |
| 캡션 | `caption` 슬롯 (`text` 기본 + 착지 상태 `cases` + `vars`) |
| 겹침 순서 | `drawOrder: 'scene'` |

추 · 자취 · 바큇살은 모두 `timeline.u` 의 닫힌 식이라, 조절기를 바꾸면 러너가 시계를 0 으로
되돌리는 것만으로 두 기계가 출발 높이에서 다시 놓인다.

캡션은 **실제 착지**로 문장을 고른다. `step` 이 주기 안 시각 `tau` 를 state 에 따로 적분하고
(`startAt` 과 같은 0.2 s 에서 출발 · 주기 3.607 s 에서 되감기 · 조절기를 잡는 동안 0), 원본과 같은
비교(`tau ≥ 착지 시각`)로 `bothLanded` · `rightOnlyLanded` · `leftOnlyLanded` 를 계산한다. 슬롯은
`still → bothLanded → rightOnlyLanded → leftOnlyLanded → equal` 순으로 참인 첫 문장, 없으면 배수 문장.

## (a) 원본과 달라진 점과 이유

- **캡션 · 조절기가 캔버스 안에 들어왔다.** 원본은 360 px 캔버스 아래 DOM 이었다. 엔진은 캡션
  슬롯과 조작기가 캔버스 위에 놓이므로, 캔버스를 480 px 로 두고 경계 아래에 이름표 · 캡션 · 조절기
  자리(월드 −0.95 m 까지)를 잡았다. 그래서 같은 가로에서 그림이 원본보다 조금 작다.
- **줄 · 도르래를 `constraint` · `body circle` 이 아니라 `trajectory` 로 그었다.** `constraint string`
  은 굵기 1 · 알파 0.55 고정이고 끝이 물체 중심에 붙어 추 윗변에 매달 수 없다. `body circle` 의 둘레는
  테마 thin(1 px)이다. 원본은 줄 1.5 px · 도르래 2 px 실선이라 선 어휘가 원본과 같다.
- **추 안 질량 글자가 흰색이 아니라 먹색(`ink`)이다.** 파란 추 위의 흰 글자를 낼 색 역할이 없다.
- **색 톤** — 파랑은 테마 `secondary`, 회색 추는 `muted subtle`, 선은 `muted strong` 이다. 원본 hex 와
  톤이 조금 다르나 "무거운 쪽은 두 기계 모두 같은 파랑, 가벼운 쪽은 같은 회색" 은 그대로다.
- **캡션 문장은 원본과 같은 판정으로 고른다** — 착지 여부를 state 에 두고 `cases` 로. 차이 0~2 (0.1 간격)
  21 값 모두 1/60 s 걸음으로 두 주기를 돌려, 캡션이 닫힌 식 위치의 착지와 어긋나는 걸음이 0 임을 확인했다
  (한 걸음 경계 허용).

  | 차이 | 왼쪽 착지 | 오른쪽 착지 | 캡션 전환 (주기 안 시각 → 문장) |
  |---|---|---|---|
  | 0.0 | 1.807 | 없음 | 내내 「움직이지 않는다」 |
  | 0.3 | 1.807 | 2.333 | 배수 → 1.82 왼쪽 먼저 → 2.33 도착 시각 |
  | 0.7 | 1.807 | 1.527 | 배수 → 1.53 오른쪽 먼저 → 1.82 도착 시각 |
  | 1.0 | 1.807 | 1.278 | 배수 → 1.28 오른쪽 먼저 → 1.82 도착 시각 |
  | 2.0 | 1.807 | 0.904 | 배수 → 0.92 오른쪽 먼저 → 1.82 도착 시각 |

- **주기 길이가 3.607 s 로 고정이다.** 원본은 `max(왼쪽 착지, 오른쪽 착지) + 1.8` 이라 차이 0.1~0.4 에서
  주기가 길어졌다. 여기서는 차이 0.2 는 착지 뒤 0.75 s 만 멈추고, 차이 0.1(착지 4.04 s)은 **닿기 전에
  주기가 끝나 처음으로 돌아간다** — 그동안 캡션은 「왼쪽 추가 먼저 닿았다 — 오른쪽은 … 내려오는 중」 을
  유지해 거짓이 되지 않는다. 원본에 없던 「왼쪽 먼저」 문장의 en 문안을 함께 두었다.
- 원본의 `PieceKit.frozen` 이면 기본값으로 그리는 분기는 옮기지 않았다 — 검사 시각은 초기 상태(1.0 kg)로 연다.

## (b) 어휘 부족

1. **시간표 단계 길이가 상태(조작기 값)를 따라갈 수 없다.** 애트우드 기계의 주기는 "가장 늦은 착지 + 멈춤"
   인데 착지 시각이 조절기 값의 함수다. `TimelinePhase.duration` 이 상수라 기본값 기준으로 선언하고
   차이 0.1~0.4 의 주기 어긋남을 받아들였다. 후보: 단계 길이를 state 경로로 가리키기
   (`cases.when` · `vars` 와 같은 경로 규약).
2. **`step` 이 `TimelineFrame` 을 받지 못해 시계를 둘 센다.** 캡션을 실제 착지로 고르려면 주기 안 시각이
   필요한데 `caption.cases` 는 state 경로만 보고 `step` 은 시각을 모른다. 그래서 `step` 이 `tau` 를 따로
   적분하고 `startAt` · 주기 · `restart` 를 손으로 맞췄다(03 `river-crossing` 과 같은 우회). 후보:
   `step` 에 `timeline` 을 넘기거나, `cases` 가 단계 진행·시각 조건(`after: 초`)을 state 와 함께 보게 하기.
3. **`restart` 가 놓는 순간에는 시계를 되돌리지 않는다.** 슬라이더 `onPointerUp` 이 patch 를 돌려주지 않아
   값을 바꾸지 않고 잡고만 있으면 러너 시계는 흐르고 state `tau` 는 0 에 머문다. 놓은 뒤 캡션 판정이 잡고
   있던 시간만큼 그림보다 늦는다(미확인 — 실시간 화면에서 재현해 보지 않았다). `restart` 가 놓는 순간에도
   0 으로 되돌리거나, 되돌린 사실을 state 에 알려 주면 없어진다.
4. **짙은 물체 위 글자에 바탕색(반전) 역할이 없다.** `readout` 의 색은 `ColorRole` 뿐이라 파란 추 위에
   흰 글자를 낼 수 없어 먹색으로 근사했다. `body.outline` · `vector.outline` 의 `'background'` 처럼
   글자에도 바탕색 선택지가 있으면 된다.
5. **`constraint string` 의 굵기 · 알파 · 끝점이 고정이다.** 굵기(`width`)가 없고, 끝이 물체 **중심**에
   붙어 추 윗변에 매달 수 없다. 그래서 줄을 `trajectory` 로 그었다 — 줄이 추를 따라가는 참조는 잃었다
   (scene 이 매 프레임 같은 식으로 두 끝을 계산하므로 화면은 같다).
6. **`body circle` 둘레 굵기를 줄 수 없다.** 도르래 윤곽 2 px 를 내려고 원을 64 각형 `trajectory` 로 그었다.

## 화면에 두지 않은 것 (원본 결정 유지)

가속도 수치와 공식 · 장력 · 줄 없는 비교 추 · 속도 화살표 · 그래프 · 경과 시간 계수기 · 그리드 · 카메라
버튼. 자취 점의 개수가 시간이고 간격이 속력이다 (원본 `inventory.json` 「hidden」).
