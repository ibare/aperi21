# 알짜힘 (net-force) — 이관 기록

원본: `tasks/piece-lab/net-force/`. 자유 렌더 없이 선언만으로 옮겼다.

## 쓴 어휘

- `body` (circle · `ink` · `glow: false` · `outline: 'none'`) — 물체
- `vector` ×3 (`secondary` · `width` 3 · `headSize` 10 · `opacity` 로 물러남) — 작용하는 세 힘
- `vector` (`accent` · `width` 4.5 · `delta` 를 grow 진행도로 늘림) — 알짜힘
- `trace` (dot · `age` 없음 · 3 px · `muted`) — 같은 시간 간격 자리 점
- `BundleSchema.timeline` (slide2 1.1 · slide3 1.1 · grow 0.8 smooth · move 4.8 · fade 0.6 smooth)
- `BundleSchema.caption` 슬롯 (아래 가운데 · 15 px · 단계마다 문안 키)
- `BundleSchema.drawOrder: 'scene'` · `canvas` · `boundsHint`

## (a) 원본과 달라진 점과 이유

- **상태를 비웠다.** 원본은 위치·속도를 매 프레임 적분하고 점 목록을 쌓았다. 주기 안에서
  알짜힘이 일정하므로 위치는 `start + ½·a·τ²`(τ = 풀려난 뒤 시간), 점은 τ = 0.3k 의 같은
  식이다. 주기마다 초기화하던 일은 주기 안 시각이 대신한다. 원본의 반암시적 오일러
  적분과는 프레임 간격만큼의 미세한 차이가 있다(대조 7.7 초에서 점 개수·간격 같음).
- **조합 선택은 `timeline.cycle`** 로 한다(주기 0·1·2 → 조합 0·1·2).
- **미끄러짐 이징이 `linear` 다.** 원본은 `sin(u·π/2)` — 시작 속도가 가장 큰 감속 곡선 —
  였고 어휘에 없다. `linear` 도 첫 순간부터 움직이므로 "도착한 순간 이미 진행 중" 은
  지켜지지만, 같은 시각에 사슬이 원본보다 덜 이어져 있다(0.4 초: 둘째 힘 꼬리가 첫째
  길이의 0.36 지점, 원본 0.54 · 1.8 초: 셋째 힘 0.64 지점, 원본 0.84).
- **grow · fade 이징이 `smooth`(smoothstep)** 다. 원본은 코사인 곡선이었다. 두 곡선은
  거의 겹친다.
- **캔버스 400 px.** 원본은 그림 360 px 아래에 DOM 캡션 줄이 따로 있었다. 캡션 슬롯은
  캔버스 안에 그리므로 40 px 를 더했고, 경계의 세로 중심을 그만큼 내려 그림 영역이
  원본 ±112.5 에 맞게 했다.
- **경계는 엔진 여백 36 px 를 빼고 잡았다.** 1 N = 1.6 px (폭 860 기준)가 되도록
  가로 반폭 246.25, 세로 반폭 102.5.
- **색은 역할로.** 힘 청회색 → `secondary`, 알짜힘 주황 → `accent`(강조색은 이것
  하나에만), 물체 먹색 → `ink`, 점 회색 → `muted`. 색상값은 테마가 정한다.
- **화살촉 모양이 조금 다르다.** 엔진은 짧은 화살표에서 촉을 길이의 0.35 로 줄이고
  (원본 0.45), 촉 폭에 선 굵기를 더하지 않는다(원본 `head·0.5 + width·0.2`).
- **자리 점·선 굵기는 화면 px 고정이다.** 원본은 캔버스 전체가 CSS 로 늘고 줄어
  점·굵기도 함께 변했다. 좁은 임베드에서 점이 상대적으로 크게 보일 수 있다.

## (b) 어휘 부족

- **시간표 이징에 "감속으로 시작하는" 곡선(easeOut, `sin(u·π/2)`)이 없다.** 원본은
  "도착한 순간 이미 미끄러지는 중" 을 시작 속도가 가장 큰 곡선으로 만들었다.
  `TimelineEase` 는 `linear` · `smooth` · `inOutCubic` 뿐이라 `linear` 로 근사했다.
  사슬이 이어지는 동작(이 조각의 동사 "모인다")의 속도감이 원본보다 밋밋하다.
- (참고) 벡터를 끝과 끝으로 잇는 과정 자체는 어휘가 아니라 sim 이 `at(id)` 로 꼬리
  자리를 보간해 선언한다. 힘의 합성·속도 합성·변위 합 조각이 늘면 같은 보간을
  조각마다 다시 쓴다 — 지금은 한 줄짜리라 승격 대상으로 보지 않는다.
