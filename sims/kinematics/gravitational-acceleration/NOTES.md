# 중력 가속도 — 이관 NOTES

원본: `tasks/piece-lab/gravitational-acceleration/` (주장 · 화면 결정의 이유는 원본 NOTES).
자유 렌더 없이 선언만으로 옮겼다.

## 쓴 어휘

- `body` — 공(원 r 10, 후광 없음) · 속도 0 을 뜻하는 먹색 점(r 3)
- `vector` — 속도 화살표(먹색) · 0.2 초 동안의 속도 변화(강조색), 둘 다 `width` 3 · `headSize` 6
- `trajectory` — 땅 선 · 속도 0 기준선(옅게, `opacity`)
- 선언 — `timeline`(rise · top · fall 은 `timeScale` 0.5, hold 2 초) · `startAt` 0.45 ·
  `caption` 슬롯 · `drawOrder: 'scene'` · `canvas` · 고정 `boundsHint`

월드 한 단위 = 원본 캔버스의 화면 px 하나(세로만 뒤집어 땅을 0 에). 850px 폭 임베드에서
배율이 1 이 되도록 경계를 잡아 화살표 척도(9 px per m/s)와 강조색 조각 길이(17.6 px)를
원본 그대로 옮겼다.

## (a) 원본과 달라진 점

- **반복이 던지는 순간(비행 0 초)부터 다시 시작한다.** 원본은 한 바퀴 뒤에도 비행 0.45 초로
  돌아가 주기가 5.1 초였다. 시간표는 주기 첫머리로 돌아가고 앞당김(`startAt`)은 처음
  도착할 때만 걸리므로, 둘째 바퀴부터 땅에서 떠나는 0.9 초(화면)가 더해져 주기 6.0 초다.
  도착 화면은 같다.
- **캡션 경계를 시간표 단계로 옮겼다** — 원본 `s < 0.85` · `s <= 1.15` · 착지가 rise 0.85 ·
  top 0.3 · fall 0.85 · hold 2.0 의 길이가 됐다.
- **속도를 점으로 바꾸는 문턱 1.5 → 2 px.** `vector` 가 2px 아래를 그리지 않아 그 사이가
  빈 화면이 된다.
- **화살촉이 원본보다 좁고 선 끝이 둥글다.** 원본 머리는 길이 6 · 폭 9 · 각진 끝, 어휘는
  폭 = 길이(6) · 둥근 끝이다.
- 색은 역할로 — 속도·캡션 `ink`, 변화량 `accent`, 공 `muted`, 안내선 `muted` 에 `opacity` 0.35.
  원본의 주황(#d9641e)이 테마 강조색(갈색 기운)으로 바뀌었다.
- 영문 문안을 더했다 (C1).
- 주제 설명과 `label.operation` 을 조각의 주장에 맞춰 「속도가 0인 순간에도 멈추지 않는 가속」으로
  바꿨다(2026-09-17 사용자 결정). 스텁의 「질량과 무관한 낙하 가속도」는 free-fall 의 주장이라
  이 조각과 어긋났다.

## (b) 어휘 부족

- **느린 재생 구간의 검사 시각.** `?t=` 는 조각 시계에 그대로 더해져 `timeScale` 을 모른다.
  원본 `?t=` 는 화면 초라, 1.1 · 2.3 · 4 의 sims 스크린샷이 다른 장면(비행 1.55 · 착지 뒤 0.75 · 다음 바퀴 비행 0.45)을
  찍는다. 대조는 조각 시계로 환산한 0.55 · 1.15 · 2.45 로 따로 찍어 확인했다(같은 장면).
- **화살촉 모양.** `headSize` 는 길이만 정하고 폭은 길이와 같게 고정이다. 짧은 화살표(17.6px)는
  길이 상한(0.35 배)에 걸려 폭을 키울 방법이 없다 — 폭 비율(또는 폭) 선언이 없다. 선 끝 모양도 고를 수 없다.
- **길이 0 벡터의 점 대체.** 속도가 0 근처일 때 점으로 바꾸는 것을 조각이 `body` 로 따로 판정한다
  (원본 engineWish 「0 일 때 점으로 바꾸기」).
- **일정 간격 스트로보.** 시각 k·Δt 칸 목록과 부동소수 경계(1e-6)를 조각이 계산한다
  (`shownSamples` · `sampleVelocity`). 원본 engineWish 그대로 남는다.
- **벡터 끝에 변화량 벡터 붙이기.** 두 화살표의 이음을 좌표로 손수 맞춘다. 조합으로 되므로
  승격 사유인지는 미확인.
- **반복 시작점.** 주기 반복이 늘 0 으로 돌아가 "매 바퀴 비행 0.45 초에서 다시" 를 선언할 수 없다
  (위 (a) 첫 항목).
