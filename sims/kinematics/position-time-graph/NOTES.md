# 위치-시간 그래프 — 엔진 이관 기록

원본: `tasks/piece-lab/position-time-graph/index.html` (자유 구현)

주장은 그대로다 — **더 빨리 오르는 구슬일수록 위치-시간 그래프에 더 가파른 선을 남긴다.**
동사는 「기운다」이고, 왼쪽 통로의 세로와 오른쪽 그래프의 세로축이 **같은 눈금**인 것이
그 동사가 화면에서 일어나는 방식이다.

## 쓴 어휘

| 원본이 그리던 것 | 옮긴 어휘 |
| --- | --- |
| 오르는 두 길 (옅은 채움 사각형) | `region` × 2 (`opaque`, `fillOpacity 0.1`) |
| ㄴ 자 축 두 줄 | `trajectory` 하나 (꺾은 세 점) |
| 화살촉 삼각형 둘 | `region` × 2 (`fillOpacity 1`) |
| '높이' · '시간' | `readout` × 2 (월드 앵커, `chip: false`, `font: 'text'`) |
| 높이를 잇는 안내선 | `trajectory` + **`style.lineStyle: 'dashed'`** |
| 구슬이 남긴 선 | `trajectory` (`width 2.6`) |
| 펜 끝점 | `body` circle (`outline: 'none'`) |
| 통로를 가로지르는 1초 금 | **`trace` (`shape: 'tick'`, `direction: [1, 0]`)** |
| 그래프 위 1초 자국의 점 | `body` circle + **`outline: 'background'`** |
| 구슬 | `body` circle + **`outline: 'background'`**, `glow: false` |
| 캡션 한 줄 | `BundleSchema.caption` 슬롯 (`cases` 로 수동 문구) |
| 주기 · 판 · 페이드 | `BundleSchema.timeline` 8단계 |
| 도착 즉시 진행 중 | `startAt: 2.4` + `preroll: 2.4` |
| 빠르기 손잡이 둘 | `slider` × 2 + `ControllerInstance.heldPath` |

## `graph` 를 쓰지 않았다

`graph`(`style: 'line'`)는 **화면 우상단 HUD 카드**에 고정으로 뜬다
(`packages/host/src/renderer/primitives/graph.ts` — `CARD.line`, `x = viewport.width - w - margin`).
카드로 떠 버리면 그래프의 세로축이 왼쪽 통로와 **다른 눈금**을 갖는다. 이 조각은
구슬이 있는 높이와 펜이 있는 높이가 화면에서 같은 줄에 놓이는 것이 주장의 전제라,
그 순간 조각이 성립하지 않는다. 눈금 수와 범례도 함께 나오는데 원본은 둘 다 두지
않기로 한 조각이다(「두 선을 서로 견주는 데 절대값이 필요 없다」).

`sims/kinematics/velocity-time-graph` 가 같은 이유로 `graph` 를 쓰지 않고
`trajectory` + `region` + `readout` 조합으로 그래프를 그렸다. 그 선례를 따랐다.

`graph` 가 이 조각을 담으려면 **월드 좌표에 놓이는 축**이 있어야 한다. 그때 필요한 것은
「그래프 어휘」가 아니라 *물리량 → 월드 매핑을 여러 뷰가 공유하는 것*인데, 이 조각은
그것을 **월드 y = 높이 그 자체**로 두어 풀었다 (`scene.ts` 머리말). 통로와 그래프가 같은
y 를 쓰므로 어긋날 자리가 없다 — 원본이 `yTop`/`yBot` 상수를 두 그리기 코드에서 손으로
공유하던 자리이고, `inventory.json` 의 첫째 `engineWish` 다.

그리고 **눈금 숫자 · 격자 · 결승선 · 속도 수치를 두지 않는다**는 결정.

## 어휘 부족

이관하며 어휘로 되지 않아 근사하거나 코드에 남긴 것들이다. 다음 엔진 작업의 입력이다.

### 1. `step` 이 `TimelineFrame` 을 받지 못한다

`Bundle.step` 의 인자는 `{ state, dt, stage, environments }` 뿐이다. `scene` 만
`timeline` 을 받는다. 그런데 이 조각은 **판이 바뀌는 순간 자취와 자국을 비우고 빠르기를
맞바꾸어야** 한다 — 시간표 단계가 바뀌었다는 사실을 `step` 이 알아야 하는 일이다.

그래서 조각 시계(`state.t`)를 상태에 따로 쌓고, 선언한 단계 길이에서 판의 경계를
`physics.ts` 가 다시 센다(`mod(t, CYCLE)`). 선언과 코드가 같은 경계를 두 번 갖는다.
지금은 `startAt` 과 `preroll` 을 같은 값으로 두어 둘이 어긋나지 않지만, 저작자가
시간표에서 단계 길이만 고치면 `step` 의 판 경계는 따라오지 않는다 — S-piece 가 막으려던
바로 그 상태다.

`step` 에도 `timeline?: TimelineFrame` 을 넘기면 사라진다. 누적 적분이 있는 조각은
전부 이 자리를 밟는다.

### 2. 슬라이더가 값을 숨길 수 없다

`controller/slider.ts` 가 `value.toFixed(2)` 를 **늘** 쓴다. 이 조각은 「빠르기의 수치를
화면에 쓰지 않는다 — 숫자를 띄우면 독자가 그래프 대신 숫자를 읽는다」가 명시된 결정이고
(`inventory.json` 의 `hidden` 첫 항목), 대신 1초 자국 사이 간격을 눈으로 재게 했다.
지금은 `0.08` · `0.15` 가 손잡이에 뜬다.

값을 읽히게 하는 것이 슬라이더의 기본이라는 것은 맞다. 다만 **숫자를 두지 않는 것도
저작 결정**이라 선언이 끌 수 있어야 한다.

### 3. 슬라이더에 색 자리가 없다

원본은 라벨 앞에 구슬 색 점을 찍어 「이 손잡이가 저 구슬」을 색 하나로 이었다. 범례를
두지 않고 짝을 짓는 유일한 장치다. `slider` 선언에는 `colorRole` 을 받을 자리가 없다.

조작기 축(`ui`)과 그림 축(`scene`)을 가르는 C2 때문에 조작기가 역할색을 그냥 빌려 쓰면
안 된다는 것은 안다. 다만 *어느 대상을 만지는 손잡이인가*는 조작기의 꾸밈이 아니라
그림 쪽의 사실이다.

### 4. `Trace.size` 가 화면 픽셀이라 월드 폭에 맬 수 없다

통로를 가로지르는 1초 금은 **통로 너비에서 양쪽 4 px 씩 물러선 길이**다. 통로는 월드
도형이라 배율을 따라가는데 `trace` 의 `size` 는 화면 픽셀이라 따라가지 않는다. 기준
폭(860 px)에서는 정확히 맞지만, 좁은 임베드에서는 금이 통로 밖으로 삐져나온다.

굵기·글자처럼 「배율을 따라가면 안 되는 것」이라는 판단은 옳지만, 이 금은 *길이 자체가
월드의 폭*이다. 획 굵기는 화면 픽셀, 길이는 월드 — 둘이 갈라져야 하는 자리로 보인다.

### 5. 시각이 아니라 **값**으로 갈리는 것 둘

- **캡션** — 손잡이가 주도권을 가져가면 셋째 문구로 바뀐다. 이것은 `caption.cases` 로
  선언됐다 (`when: 'manual'`). 어휘가 있었다.
- **장면의 투명도** — 수동 진행 중에는 지우지 않는다. 독자가 만들고 있는 그래프가
  주기가 돌았다고 저 혼자 사라지면 안 되기 때문이다. 이것은 선언할 자리가 없어
  `scene.ts` 가 `state.manual` 을 보고 가른다. 1번이 풀리면 이것도 `step` 쪽으로 간다.

### 6. 쓸 자리가 없던 새 필드

- `Body.fill: 'none'` — 이 조각의 구슬은 전부 속이 찬 원이다. 「같은 크기의 두 물체를
  채움으로 가른다」는 쓰임이 여기엔 없어 선언하지 않았다 (원칙 4 — 쓰지 않는 필드를
  써 두면 그 선언이 거짓말이 된다).
- `Trace.marks[].direction` — 이 조각의 금은 모두 같은 쪽(가로)을 본다. 인스턴스의
  `direction` 하나로 끝나서 자국마다 방향을 주지 않았다.

## 화면에 두지 않은 것 (S-piece — 「화면에 없는 것도 결정이다」)

원본의 결정을 그대로 가져왔다.

- **속도 수치** — 주장이 「가파름」이라 숫자를 띄우면 독자가 그래프 대신 숫자를 읽는다.
  (손잡이의 값 표시는 위 「어휘 부족」 2번대로 아직 못 껐다.)
- **눈금 숫자와 격자** — 두 선을 서로 견주는 데 절대값이 필요 없다.
- **꼭대기의 결승선** — 두면 「먼저 도착」 서사가 생겨 주장이 기울기에서 순위로 옮겨간다.
  6초 주행이 끝날 때 빠른 구슬이 꼭대기 *가까이* 가도록 빠르기를 잡았다 (0.152 × 6 = 0.91).
- **기울기 값** — 매 프레임 결정되지만 수치로 띄우지 않는다.
- **제목 · 범례 · 재생 버튼 · 툴팁** — 자동으로 돌고, 제목은 문단이 준다.
