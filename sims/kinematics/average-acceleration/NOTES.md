# average-acceleration — 이관 NOTES

원본: `tasks/piece-lab/average-acceleration/` (자유 구현, 캔버스 직접 그리기).
이관본은 **자유 렌더 없이** 표준 어휘 넷으로 선언한다 — `trajectory` · `body` · `vector` · `readout`.

| 원본 묶음 | 어휘 |
|---|---|
| 도로 (차로 둘 · 출발선) | `trajectory` (width 1, `muted` subtle) |
| 차 가 · 나 | `body` custom — 둥근 사각(34 × 18, 모서리 5) SVG 경로 |
| 이름표 '가' · '나' | `readout` (world, 칩 없음, `text` 글꼴 14px) |
| 속도 화살표 | `vector` (width 3, headSize 10) + `readout` 속력 (소수 한 자리) |
| 속도-시간 축 · 눈금 | `trajectory` (축 1.2 `ink`, 눈금 1 `muted`) + `readout` (10 · 20 · 속도 · 0 · 5 s · 시간) |
| 속도 곡선 | `trajectory` (width 2.5, 0.02 s 간격 표본) |
| 처음-지금 기울기선 | `trajectory` dashed (width 6, 차 색 subtle) — **곡선 아래** |
| 평균 가속도 기울기선 | `trajectory` (width 3.5, `accent`) + `readout` '기울기 2 m/s²' |
| 속도 변화와 걸린 시간 | `trajectory` dashed (width 1, `ink`) + `readout` 둘 |
| 캡션 | `caption` 슬롯 — 단계마다 키 |

월드는 **원본 캔버스 1px = 1** 이고 y 만 위로 뒤집었다. 도로 칸과 그래프 칸은 원본에서도
각자 축척(1 m = 3.6 px, 1 s = 60 px, 1 m/s = 9.5 px)이고 서로에게서 유도되는 약속이 없어서,
원본 배치 상수를 한 글자도 바꾸지 않고 옮기는 쪽을 골랐다. 고정 경계는 880 × 270 에 캡션
자리 34 를 더한 것이다.

시간표 — `run` 5 → `join` 0.3 → `measure` 0.4 → `hold` 2.8 (주기 8.5 s, 원본과 같음).
운동 시각은 `at('run') · RUN`, 끝남은 `phase !== 'run'`, 겹친 기울기선의 나타남은
`at('join')`, 직각 표시의 나타남은 `at('measure')`. 캡션은 `run` 이 `caption.run`, 나머지가
`caption.done`. 원본은 시계를 앞당기지 않았으므로 `startAt` 은 두지 않았다. 상태는 비었다.

## (a) 원본과 달라진 점과 이유

1. **처음-지금 기울기선을 곡선 아래의 넓고 옅은 점선 띠로 바꿨다 (원본 결함 수정).**
   원본은 1.5 px 점선을 곡선 **위**에 그었다. 가는 등가속도라 곡선이 곧 직선이고, 가의
   기울기선이 곡선에 통째로 포개져 달리는 내내 보이지 않았다. 그러면 "두 기울기선이 하나로
   겹친다" 에서 둘 중 하나가 처음부터 없어 겹치는 순간이 약하다. 이제 기울기선은 6 px
   점선(차 색 `subtle`)으로 곡선(2.5 px 실선) **아래**에 깔려(`drawOrder: 'scene'`), 가의
   곡선 양옆으로 점선이 비어져 나온다. 굵기(넓은 띠 ↔ 가는 선)와 모양(점선 ↔ 실선)으로
   가른다. 주장은 그대로다 — 끝 시각에 두 띠가 강조색 실선 하나로 바뀐다.
2. **나타남 시간.** 원본은 겹친 기울기선이 끝난 뒤 0 ~ 0.4 s 에, 직각 표시가 0.3 ~ 0.7 s 에
   나타나 0.1 s 겹쳤다. 시간표 단계는 겹칠 수 없어 기울기선 0.3 s(`join`) → 직각 표시 0.4 s
   (`measure`)로 이었다. 직각 표시가 끝나는 시각(0.7 s)은 같다.
3. **직각 표시의 점선 무늬.** 원본 [3, 3] px, 여기서는 `trajectory` dashed 의 고정 무늬
   [6, 5] px 라 대시가 조금 길다.
4. **화살촉.** 원본은 길이 10 · 반폭 6, `vector` 는 길이 10 · 반폭 5.
5. **색조.** 파랑 · 초록 · 주황 · 먹 · 옅은 선을 `secondary` · `positive` · `accent` · `ink` ·
   `muted` subtle 로 옮겼다. 테마 팔레트라 원본 hex 와 한 톤씩 다르다.
6. **캡션이 캔버스 안이다.** 원본은 캔버스 밖 DOM 한 줄. 캡션 슬롯은 화면 고정 `readout`
   이라 캔버스 아래 왼쪽에 붙고, 경계에 그 자리를 더 잡았다.

대조 (`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ average-acceleration`):
t = 1.2 · 3 · 4.6 · 6.5 에서 차 위치 · 화살표 길이 · 속력 값 · 곡선 모양 · 겹친 기울기선 ·
직각 표시와 글자 자리가 원본과 같은 장면이다. 이관본은 캔버스 폭이 좁아 전체가 약 0.85 배로
줄어 있다. `ⓘ 비교 한계` 는 뜨지 않았다.

## (b) 어휘 부족

동사(두 기울기선이 끝 시각에 하나로 겹친다)는 지금 어휘로 화면에서 일어난다. 모자란 것은
표현의 정확도 쪽이다.

| 부족 | 지금 한 근사 | 필요한 것 |
|---|---|---|
| 점선 무늬 크기 | `trajectory` dashed 의 고정 [6, 5] (굵기 비례) | 선언이 대시 길이·간격을 고를 수 있어야 원본의 촘촘한 [3, 3] 보조선이 나온다 |
| 겹치는 등장 곡선 | 단계를 이어 붙임 (0.4/0.3 겹침을 0.3 → 0.4 로) | 시간표 단계는 한 줄로만 이어진다. "끝난 뒤 0.3 s 부터 0.4 s 동안" 같은 겹치는 구간은 `span(start('join') + 0.3, …)` 처럼 코드 상수가 된다 |
| 화살촉 반폭 | `vector` 고정 비율(길이의 0.5) | 원본 10 × 12 처럼 머리 폭을 선언할 자리 |
| 원본 px 배치의 월드 옮김 | 월드 = 원본 캔버스 px (y 뒤집기) 를 scene 이 직접 | 두 칸이 각자 축척을 갖는 그림(도로 칸 · 그래프 칸)의 "칸" 어휘. 원본 engineWish 1번(속도-시간 평면 좌표계·최소 눈금·축 이름)도 같은 자리다 — 지금은 `trajectory` + `readout` 으로 축과 눈금을 손으로 선언한다 |
| 자라는 곡선 · 할선 | `trajectory` 에 표본 점을 scene 이 계산 | 원본 engineWish 2번. 조합으로 되므로 승격 판단은 보류 |
| 기울기 삼각형(Δt · Δv) | `trajectory` 꺾은선 + `readout` 둘 | 원본 engineWish 5번. `dimension` 은 ㄴ자 하나에 문안 하나라 두 변에 따로 값을 달 수 없다 |

## 화면에 없는 것

원본의 결정을 그대로 따른다 — 차의 위치 값(이동 거리는 이 주장과 무관, 도로 위 자리로만
보인다), 순간 가속도(접선 — 다른 조각의 주장), 끝나기 전의 기울기 숫자(동사를 숫자로 대신하게
됨), 격자 · 범례 · 제목 · 조작기.
