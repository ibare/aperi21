# 라그랑주 점 — NOTES

원본: `tasks/piece-lab/lagrange-points` (자유 구현). 이 sim 은 그것을 표준 어휘 선언만으로 옮긴 것이다.
자유 렌더(`Bundle.renderers`)는 쓰지 않는다.

## 쓴 어휘

| 원본 묶음 | 어휘 |
|---|---|
| 유효 퍼텐셜 명암 | `scalarField` 순차형 하나 (`high: 'muted'`, 인스턴스 `opacity`) |
| 등고선 | `lineSet` 하나 (선분은 physics 가 마칭 스퀘어로 뽑는다) |
| 지구 · 달 | `body` 원 둘 + 이름 `readout` 둘 |
| 평형점 십자 · 이름 | `lineSet` 하나 + `readout` 다섯 |
| 시험 물체 자취 | `lineSet` 하나 — 표본 8개 구간마다 `opacities` 로 나이 · 떠남 흐려짐 |
| 시험 물체 머리 | `particleSystem` 하나 |
| 캡션 | `BundleSchema.caption` 슬롯 (고정 문장) |
| 미리 돌리기 20초 | `BundleSchema.preroll` |

상태는 누적이다(물체마다 RK4 적분). 그래서 시간표 · `startAt` 이 아니라 `step` + `preroll` 이다.
난수는 원본 `PieceKit.random`(mulberry32, 시드 1)과 같은 수열을 상태에 두어, 같은 시각의 물체 배치가
원본 촬영과 점 하나까지 같다(t = 0 · 3 · 8 · 14 대조로 확인).

## (a) 원본과 달라진 점과 이유

- **지형 색조.** 원본은 짙은 남색 → 옅은 푸른 회색 사상이었다. 색 역할에 그 톤이 없어 `muted` 순차형으로
  칠했다 — 회색이다. 높은 끝이 역할 색 끝까지 가서 원본보다 훨씬 밝았고(자취 · 이름이 묻힘), 인스턴스
  `opacity` 0.45 로 눌렀다. 명암의 제곱 사상(t²)은 physics 가 값에 구워 넘긴다.
- **배율.** 원본은 900px 캔버스에서 191.5 px/단위, 카탈로그 임베드는 약 163 px/단위다. 세로 ±1.175 를
  그대로 프레이밍했고, 화면 px 로 그리던 치수(지구 반지름 9 · 달 4.5 · 십자 5)는 163 으로 나눠 월드로 옮겼다.
  넓은 임베드에서는 조금 커진다.
- **캡션 자리.** 원본은 캔버스 밖 문단이었다. 슬롯이 캔버스 안이라 그림 아래 0.34 단위 띠를 비웠다.
- **지형 가로 폭.** 원본은 캔버스 폭만큼 계산했다. 임베드 폭이 정해져 있지 않아 ±2.6 단위로 넓게 깔았다.
- **이름 자리.** 원본은 글자 기준선 기준 오프셋, `readout` 은 글자 가운데 기준이라 4px 안팎 옮겨 적었다.
- **실시간 걸음.** 원본 루프는 고정 1/60 초 걸음이다. 엔진 dt 는 가변이라 `step` 이 누적기로 고정 걸음을 걷는다.

화면에 두지 않은 것(원본 결정 그대로): 관성 틀 운동, 떠난 뒤의 행로, 퍼텐셜 수치 · 범례, 질량비 조작기,
그리드 · 카메라 단추.

## (b) 어휘 부족

장부(`tasks/engine-requirements/gap-ledger.md`)에 댄 것:

- **G66** 스칼라 장에서 등고선을 뽑는 어휘가 없다 — physics 가 마칭 스퀘어로 선분을 만들어 `lineSet` 에
  넘긴다. 원본 engineWish 에서 「가장 길게 손으로 짠 부분」 이었던 자리가 그대로 조각에 남았다. 근사.
- **G62** `scalarField` 사상 곡선을 고를 수 없다 — t² 를 값에 구워 넘겼고, 높은 끝 세기를 줄일 자리가 없어
  인스턴스 `opacity` 로 눌렀다. 근사.
- **G08** 옅은 면 톤(푸른 회색 지형)에 맞는 색 역할이 없다 — `muted` 회색. 근사.
- **G25** 화면 px 로 고정되는 크기가 없다 — 지구 · 달 반지름과 십자 길이를 배율 상수(163)로 환산. 근사.
- **G24** 캡션 자리가 프레이밍 여백으로 잡히지 않는다 — `boundsHint` 에 캡션 띠를 손으로 더했다. 근사.
- **G16** `readout` 을 글자 기준선에 맞출 수 없다 — 오프셋을 가운데 기준으로 옮겨 적었다. 근사.
- **G39** 실시간 dt 가 가변이라 고정 걸음 누적기를 조각이 둔다. 근사.
- **G53** `opacities` 8 단계 반올림 — 12초 자취의 가장 오래된 끝(나이 11초 넘어 알파 1/16 미만)이 원본보다 일찍 끊긴다(계산상, 화면에서 따로 재지 않음). 근사.

새 부족:

- **장이 화면 전체를 덮는다는 선언이 없다.** `scalarField` 는 월드 사각형뿐이라, 원본의 「화면 전체를 덮는
  지형」 을 임베드 폭과 무관하게 선언할 수 없다. 좁게 깔면 넓은 임베드에서 사각형 끝이 비친다(첫 대조에서
  실제로 비쳤다). 넓게 깔아 우회. 영향: **근사** (모양만 다름).

## 근사로 주장이 약해졌는가

약해지지 않았다. 안장 셋에서 흘러나가는 자취와 꼭대기 둘을 감싸는 고리 자취가 원본과 같은 자리 · 같은
모양으로 일어나고, 지형의 초승달 꼭대기 · 안장 교차 등고선이 읽힌다. 지형이 푸른 톤이 아니라 회색인 것은
모양 차이다.
