# expanding-universe — 우주의 팽창

자유 구현 원본 없이 엔진 어휘 위에서 바로 지었다. 자유 렌더(`Bundle.renderers`) 0.

쓴 어휘: `lineSet` × 2(공간 격자 · 지나온 자취) · `particleSystem` × 2(흩뿌린 은하 · 늘기 전 자리) ·
`body`(줄 선 세 은하 · 관찰 고리) · `vector`(v · 2v) · `dimension`(d · 2d) · `readout`(「여기서 본다」),
`timeline` 9단계 · `caption` 슬롯 · `drawOrder: 'scene'` · `startAt`. 쌓는 상태 없음 — `step` 항등, state 비어 있음.

## (a) 답하는 질문과 동사

**질문** — 은하들이 모두 우리에게서 멀어진다면, 우리가 우주의 가운데인가.

**주장 한 문장** — 공간이 고르게 늘어나면 어느 은하에 서서 보아도 나머지가 모두 나에게서 멀어지고,
두 배 먼 은하는 같은 시간에 두 배 멀리 가 두 배 빨리 멀어진다 — 가운데가 따로 없다.

**동사** — *모두 나에게서 멀어진다 — 서 있는 은하를 바꿔도 똑같이.*

화면에서 일어나게 한 방법 —

- 은하는 제자리에 있고 **공간이 늘어난다.** 늘기 전 자리 q 인 은하는 관찰 은하 o 를 기준으로
  o + a·(q − o) 에 있다(a = e^(H·τ), H 는 스테이지 상수). 관찰 은하는 제자리이고 나머지는 모두 그에게서
  곧게 멀어진다. 속도는 H·(지금 자리 − o) 라 허블 법칙이 식 하나에서 나온다.
- **공간 격자**(옅은 선)가 은하와 함께 늘어난다 — 시각 메모 「격자를 늘리면 모든 점이 서로 멀어진다」.
  은하가 격자 위를 달려가는 것이 아니라 격자째 벌어지는 것이 보인다.
- 늘이는 동안 **늘기 전 자리**(작은 회색 점)와 거기서 지금 자리까지의 **자취**가 남는다. 자취가 모두
  관찰 은하에서 방사형으로 뻗고 먼 은하일수록 길다 — 「같은 시간에 몇 배 멀리 갔는가」 가 자취 길이다.
- 가운데 줄에 은하 셋이 d 간격으로 선다(늘기 전 자리를 선언, 흩뿌린 은하는 시드 난수). 왼쪽 끝에 서면
  가운데 은하가 d, 오른쪽 끝 은하가 2d — 둘에 속도 화살표 v · 2v 와 치수선 d · 2d 가 붙는다. 2v 화살표가
  v 의 두 배, 2d 자취가 d 자취의 두 배다.
- 흐려졌다가 늘기 전 공간이 다시 나타나고 **관찰 고리가 줄을 따라 오른쪽 끝 은하로 옮겨 간다.** 같은
  공간을 다시 늘이면 이번에는 모든 자취가 오른쪽 끝 은하에서 뻗고, 방금 「나」 였던 왼쪽 끝 은하가 2v 로
  멀어진다. 그림이 좌우만 바뀐 같은 모양이다 — 가운데가 따로 없다.

| 단계 | 화면 |
| --- | --- |
| `appearLeft` | 늘기 전 공간이 나타난다. 왼쪽 끝 은하에 관찰 고리 |
| `stretchLeft` | 격자째 늘어난다. 자취가 왼쪽 끝 은하에서 방사형으로 자라고, v · 2v 화살표 · d · 2d 치수선이 함께 자란다 |
| `holdLeft` | 멈춘다. 캡션이 「두 배 먼 은하는 같은 시간에 두 배 멀리 갔다」 |
| `fadeLeft` | 흐려진다 — 늘어난 공간을 되감지 않는다 |
| `appearRight` | 늘기 전 공간이 다시 나타난다 |
| `move` | 관찰 고리가 왼쪽 끝에서 오른쪽 끝 은하로 옮겨 간다. 이동 중엔 줄 선 셋이 모두 강조색 |
| `stretchRight` | 같은 늘임. 자취가 오른쪽 끝 은하에서 뻗고, 왼쪽 끝 은하가 2v |
| `holdRight` | 멈춘다. 「같은 그림이다 — 가운데는 따로 없다」 |
| `fadeRight` | 흐려지고 처음으로 |

## (b) 화면 구성의 결정 — 두지 않은 것 포함

- **늘어난 공간을 되감지 않는다.** a 를 1 로 줄여 되돌리면 수축으로 읽혀 주장과 반대 그림이 한 주기에
  들어간다. 흐려졌다가 늘기 전 공간으로 다시 나타난다.
- **관찰 은하를 바꿀 때 카메라 · 그림을 옮기지 않는다.** 관찰 은하를 화면 가운데로 끌어오면 우주 전체가
  옆으로 미끄러져 그 자체가 운동으로 읽힌다. 대신 「관찰 은하는 제 자리에 머물고 나머지가 그에게서
  멀어진다」 는 기준만 바꾼다. 늘기 전(a = 1)에는 어느 은하를 기준으로 잡아도 자리가 같아 바꾸는 순간
  그림이 튀지 않는다.
- **관찰 은하를 줄의 양 끝으로 골랐다.** 가운데 은하에 서면 d · 2d 쌍이 생기지 않는다. 양 끝이면 두 번 다
  같은 세 은하로 d · 2d 가 서고, 역할이 뒤바뀌는 것(방금 「나」 가 2v 로 멀어짐)이 「가운데가 없다」 를 말한다.
- **적색 이동 색을 쓰지 않는다.** package.json 에 `@aperi21/plugin-optics` 의존이 있으나 쓰지 않았다. 이
  조각은 공간이 늘어나는 운동학에 머물고, 은하마다 색을 바꾸면 색이 거리 · 속도를 설명하게 되어(S-piece
  「색으로 설명하지 않는다」) 자취 길이라는 기하 증거와 경쟁한다. 적색 이동은 이웃 조각의 몫이다.
- **흩뿌린 은하에는 속도 화살표를 달지 않는다.** 34 개 모두에 달면 화살표 숲이 되어 d · 2d 쌍이 묻힌다.
  모든 은하가 멀어진다는 것은 자취가, 빠르기의 비는 줄 선 두 은하의 화살표가 맡는다.
- **수를 띄우지 않는다.** H 값 · 척도 인자 · 거리 수치는 화면에 없다. 주장은 「두 배」 라는 비이고 그것은
  d · 2d, v · 2v 기호와 화살표 · 자취 길이로 선다. 「2」 는 가운데 은하가 양 끝의 한가운데라는 배치 정의에서
  나오며 문안 키(`label.far` · `label.farSpeed`)에 있다.
- **격자는 장식이 아니라 공간 자체다.** 크롬 그리드(미터 눈금)는 끄고, 은하와 함께 늘어나는 공변 격자만
  둔다. 가운데 은하를 지나는 선에 맞춰 d 의 절반 간격이라 줄 선 은하가 격자 교점에 앉는다.
- **캡션 자리를 비워 둔다.** 흩뿌린 은하는 늘기 전에 캡션 줄(화면 아래 0.7 월드)에 두지 않는다. 늘어나며
  아래쪽 은하 · 자취가 그 줄을 지나가는 것은 그대로 둔다 — 경계를 상태로 계산하지 않는다.
- **조작기 없음.** 독자가 해 볼 것은 「다른 은하에 서 보기」 인데 조각이 스스로 한 번 해 보인다. 아무
  은하나 고르게 하면 d · 2d 쌍이 흩어져 비를 읽을 줄이 사라진다.

## (c) 어휘 부족

| 장부 id | 이 조각에서 겪은 것 | 영향 |
| --- | --- | --- |
| G24 | 캡션 슬롯 자리가 프레이밍 여백으로 잡히지 않는다 — 흩뿌리는 영역에서 캡션 줄 높이(0.7 월드)를 손으로 뺐다. 늘어나며 들어오는 자취는 막지 못한다 | 근사 |
| G50 | 글자 둘레 바탕색 테두리가 없다 — 멈춘 단계에서 아래쪽 자취가 캡션 글자를 가로지른다(읽히기는 한다) | 근사 |
| G123 | `dimension` 글자의 크기 · 글꼴 · 굵기를 고를 수 없다 — d · 2d 가 v · 2v(벡터 이름, 굵은 모노)와 모양이 갈린다 | 근사 |

새 부족 — 없다. 척도 인자로 모든 자리를 o + a·(q − o) 로 옮기는 계산은 조각의 물리이지 어휘 부족이 아니다.

## (d) 주장이 화면에서 서는가

`?t=` 는 `startAt`(1.4 초)부터 흐른 시간이다. 라이트 · 다크 모두 찍어 보았다.

| t | 라이트 | 다크 | 판정 |
| --- | --- | --- | --- |
| 0.4 | 선다 — 왼쪽 끝 은하에 고리와 「여기서 본다」, 짧은 자취가 모두 그 은하 반대쪽으로 났다. v · 2v 화살표와 d · 2d 치수선 | 선다 — 격자 · 자취가 옅은 회색, 은하 파랑 · 강조 금색이 바탕에서 뜬다 | 선다 |
| 3.5 | 선다 — 자취가 왼쪽 끝 은하에서 방사형, 먼 은하일수록 길다. 2v 화살표가 v 의 두 배, 줄 선 두 은하 자취도 1 : 2 | 선다 — 아래쪽 자취 둘이 캡션 글자를 가로지르나 읽힌다(G50) | 선다 |

| 9.5 | 선다 — 자취가 오른쪽 끝 은하에서 뻗고, 왼쪽 끝 은하가 2v 로 왼쪽으로 멀어진다 | 선다 | 선다 |
| 12.5 | 선다 — 3.5 의 좌우 거울 모양. d · 2d, v · 2v 가 다시 선다 | 선다 | 선다 |
