# nuclear-fission — 제작 기록

자유 구현 원본 없이 엔진 어휘 위에서 바로 지었다. 이웃 `nuclear-structure`(핵이 무엇으로 이루어졌나 ·
Z 가 원소를 정한다)와 겹치지 않게, 이 조각은 **한 번의 분열 사건**만 말한다. 연쇄는 `chain-reaction` 몫.

## (a) 답하는 질문과 동사

**질문** — 무거운 핵이 갈라질 때 무엇이 나오는가?

**주장 한 문장** — 느린 중성자 하나를 삼킨 우라늄-235 는 흔들리다 늘어나 바륨-141 · 크립톤-92 와 중성자 셋으로
갈라지고, 두 조각이 서로 밀어내며 약 200 MeV 를 싣고 날아간다 — 알갱이 수는 그대로다(235 + 1 = 141 + 92 + 3).

**동사** — *갈라지며 중성자를 내놓는다.*

화면에서 일어나게 한 방법(한 주기, 화면 12.0 초):

- `approach` — 가운데 ²³⁵U(먹색 원)로 왼쪽에서 회색 중성자 `n` 하나가 천천히 다가온다.
- `absorb` — 중성자가 핵 속으로 들어가며 사라지고 이름표가 ²³⁶U 로 바뀐다.
- `wobble` — 핵이 길쭉 ↔ 납작으로 점점 크게 흔들린다(세 번, 끝은 가로로 길어지는 쪽).
- `stretch` — 흔들림이 그대로 가로로 늘어나 캡슐 → 아령이 되고, 목이 잘록해져 두 덩이가 한 점에서 만날 때까지 간다.
  왼쪽 덩이(141)가 오른쪽(92)보다 크다 — 반지름이 A^⅓ 에 비례.
- `split` — 두 조각 ¹⁴¹Ba · ⁹²Kr 가 떨어져 **멈춘 데서 빨라지며** 좌우로 날아가고(강조색 속도 화살표가 자란다),
  갈라진 목에서 회색 중성자 셋이 비스듬히 튀어나간다.
- `reveal` · `tally` — 화면이 다섯 배 느려지고(시간표 `timeScale: 0.2`) 위에 「235 + 1 = 141 + 92 + 3」, 가운데에
  「약 200 MeV」 가 뜬다. **아무것도 멈추지 않는다** — 조각 · 중성자가 느린 화면 속에서 계속 나아간다.
- `clear` · `renew` — 조각 · 중성자 · 글자가 물러난 뒤 다음 U-235 와 느린 중성자가 제자리에 선다.

## (b) 화면 구성의 결정

- **핵은 먹색 덩어리 하나**(`region` + 같은 점의 `trajectory` closed 윤곽). 이웃처럼 핵자를 낱개로 두면 236 개를
  아령 모양 안에 배치해야 하고, 「갈라짐」 보다 「알갱이 무더기」 가 먼저 읽힌다. 알갱이 수는 장부 글자가 맡는다.
- **색 — 이웃과 같은 대상 같은 색.** 핵은 먹(`ink`), 중성자는 회색(`muted`) + 표식 `n`. 강조색(`accent`)은
  **「풀려난 에너지」 한 뜻에만** — 조각의 속도 화살표와 「약 200 MeV」. 화살표가 자라는 것이 곧 에너지가 운동으로
  나타나는 모습이라 둘을 같은 색으로 묶었다.
- **갈라지는 모양은 필렛 기하**로 지었다 — 두 원(장차 두 조각)에 바깥에서 접하는 원호 둘로 목을 만든다.
  필렛 반지름 ∞ 이면 캡슐, 0 이면 두 원이 한 점에서 만난다. 목 폭을 진행도로 줄이고 이분법으로 필렛 반지름을
  찾는다(`physics.dumbbellPoints`). 흔들림 끝(변형 0, 가로로 길어지는 중)과 늘어남 시작(원)이 이어지도록 흔들림
  횟수를 정수로 두었다.
- **두 조각의 운동은 반발로 빨라지는 꼴**: v(τ) = v∞(1 − e^(−τ/T)). 등속으로 두면 「밀어내며 빨라진다」 가 보이지 않는다.
  무거운 조각의 끝 속력은 운동량이 같도록 A_L / A_H 배(가벼운 Kr 가 더 빠르다 — 화살표 길이로 보인다).
- **화면 속력은 늦춘 배율**이다 — `fragmentSpeed` · `neutronSpeed` · `repulsionTime` 을 스테이지 상수로 이름 붙여
  선언했다. 실제 조각은 빛의 몇 % 로 날아간다. **화면에 알리지 않았다** — 캡션은 「빨라진다」 까지만 말하고
  속력 수치를 주장하지 않으며, 배율 표지를 두면 한 주장 옆에 두 번째 이야기가 붙는다.
- **느린 중성자와 빠른 중성자의 속력비는 참이 아니다.** 실제로는 약 1 만 배(열중성자 0.025 eV · 분열 중성자 2 MeV)지만
  화면에서는 약 1.9 배(0.7 : 1.3 월드/초)다. 들어오는 쪽을 참 비율로 늦추면 멈춘 점이다. 캡션의 「느린」 이 말을 맡는다.
- **질량수 · 원자 번호 검증** — `readConstants` 가 `aTarget + 1 = aHeavy + aLight + nOut` 과 `zTarget = zHeavy + zLight`
  를 확인하고 어긋나면 던진다. 주장이 「알갱이 수는 그대로다」 라서 저작자가 한쪽만 바꾼 선언이 틀린 장부를 조용히
  띄우지 않게 했다. 장부의 수는 모두 선언된 정수를 그대로 쓴다(²³⁶ 은 선언 정수 + 1).
- **에너지 200 MeV 는 선언된 정박값**(`energyMeV`)을 `'약 {e} MeV'` 문안 + `vars` 로 띄운다. 질량 결손에서 계산하지 않는다.
- **중성자 방향은 (시드, 주기 번호)의 함수** — 오른쪽 · 왼쪽을 번갈아, 위 · 아래를 두 개마다 바꾸고 기울기(42° ± 8°)의
  흩어짐만 `mulberry32(seed, cycle)` 로 뽑는다. 주기마다 조금씩 다르고, 같은 시각은 늘 같은 화면이다.
  기울기 상수는 화면 경계 안에 느린 화면 끝까지 머물도록 맞춘 배치 값이라 파일 머리 상수로 두었다.
- **중성자 꼬리는 짧게**(0.9 월드) — 처음에는 갈라진 곳부터 지금 자리까지 그었더니 가운데 장부 글자를 가로질렀다.
- **중성자 표식 `n` 은 움직이는 쪽의 반대편 위**에 둔다 — 오른쪽 위로 가는 중성자의 표식이 ⁹²Kr 이름표에 올라탔다.
- **장부는 캔버스 위 가운데**(화면 앵커). 글자 폭(약 200 px)이 느린 화면 시작 때 두 조각 사이 틈보다 넓어 월드에
  두면 Ba 에 닿았다. 에너지 글자만 갈라진 곳 가운데에 둔다.
- **느린 화면(`timeScale`)으로 장부를 읽힌다** — 조각을 멈추면 「날아간다」 가 끊기고, 제 속력이면 글자가 뜰 때
  조각이 화면 밖이다. `reveal`(0.1 초 → 화면 0.5 초)을 따로 두어 글자가 한 번에 떠오르게 했다 — 처음에는 `tally`
  전체에 걸쳐 천천히 짙어져 촬영 시각에 반쯤 옅었다.
- **물러남과 다시 섬을 두 단계로** — 한 단계로 겹치니 떠나는 Ba 위에 다음 느린 중성자가, 에너지 글자 위에 새 핵이
  겹쳐 나타났다.
- **이름표 높이는 흔들림이 가장 클 때의 윗가장자리**에 맞춘다 — 세로로 길쭉할 때 ²³⁶U 가 핵에 닿았다. 모양을 따라
  오르내리면 글자가 떨어 흡수 동안 그 높이로 올라가고 늘어나는 동안 조각 윗가장자리로 내려오게 이었다.
- **두지 않은 것**
  - 연쇄 반응 — 나온 중성자가 다른 핵을 때리는 것은 `chain-reaction` 의 주장이다. 중성자는 화면 밖으로 흘러간다.
  - 원자 번호 Z 아래 첨자 — 이 조각의 장부는 질량수다. Z 까지 적으면 이름표가 셋 겹이 되어 날아가는 조각 위에서 읽히지 않는다.
    Z 의 합은 선언 검증이 지킨다.
  - 감마선 · 조각의 뒤이은 β 붕괴 · 에너지 몫 나눔(조각 운동 약 170 MeV 등) — 「약 200 MeV 가 풀려나 조각을 밀어낸다」 한
    문장을 흐린다.
  - 질량 결손(E = mc²) 계산 — 에너지가 어디서 오는지는 `binding-energy-curve` · 질량-에너지 조각의 몫.
  - 원소 이름(바륨 · 크립톤) — 기호가 표식이라 번역 없이 두 언어에서 같다. 캡션도 `Ba-141` 꼴로 쓴다.
  - 조작기 · 그리드 · 제목 · 범례.

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ nuclear-fission` 로 다섯 시각을 라이트 · 다크 모두 열어 봤다
(`tasks/piece-lab/_report/_scratch/nuclear-fission/shots/`). 첫 촬영본이 aperi21 카탈로그 화면인 것을 확인했다.
주기 끝(10.1 느린 화면 끝 · 10.9 다시 섬)과 다음 주기(20.5, 중성자 방향이 주기마다 달라지는지)도 따로 찍어 봤다 —
20.5 는 중성자 속력 · 기울기를 줄이기 전 촬영이다. inventory 는 원래 다섯 시각으로 되돌렸다.

- **t=0.4** — 가운데 ²³⁵U 먹색 원, 왼쪽에서 회색 `n` 이 다가오는 중. 캡션 「느린 중성자 하나가 U-235 핵으로 다가간다.」
  라이트 · 다크 모두 선다.
- **t=3.6** — 이름표 ²³⁶U, 핵이 세로로 길쭉한 흔들림의 한 순간. 이름표가 핵에 닿지 않는다(고친 뒤). 선다.
- **t=5.6** — 가로로 늘어난 아령, 목이 잘록하고 왼쪽 덩이가 더 크다. 캡션 「…가운데가 잘록해진다.」 선다.
- **t=6.6** — ¹⁴¹Ba · ⁹²Kr 가 막 떨어져 좌우로 가고 강조색 화살표가 바깥으로, 가운데에서 `n` 셋이 비스듬히 튀어나오는 중.
  갈라진 직후라 중성자가 조각 가장자리 가까이 붙어 있어 조금 붐빈다 — 겹침은 없다. 선다.
- **t=8.6** — 느린 화면. 두 조각이 멀리 나가 화살표가 길어졌고(Kr 쪽이 더 길다), `n` 셋이 위아래로 흩어졌다.
  위 가운데 「235 + 1 = 141 + 92 + 3」, 가운데 「약 200 MeV」(강조색). 캡션 「알갱이 수는 그대로다 — …약 200 MeV 의 에너지를
  싣고 날아간다.」 선다.
- 다크에서 뒤집히는 것은 없다 — 핵(먹)은 두 테마에서 각각 바탕의 반대쪽(라이트 짙음 · 다크 밝음), 중성자 회색 · 강조색
  화살표 · 글자의 관계가 그대로다. 글자 겹침 · 화면 밖으로 나감 없음. 10.1 에서 위로 간 중성자가 장부 글자 아래까지 올라오지만 닿지 않는다.
- 캡션 글자 몇 자가 옅게 찍히는 현상(「알갱이」 의 「갱」, 「싣고」 의 「싣」)이 일부 촬영본에 있다 — 이웃 조각들에서 보고된 것과
  같은 촬영 쪽 현상으로 보인다(원인 미확인).
