# quantum-harmonic-oscillator — 양자 조화 진동자

자유 구현 원본이 없다. 엔진 어휘로 곧바로 지었다. 자유 렌더(`Bundle.renderers`) 0건.
쓴 어휘: `trajectory`(포물선 우물 · 점선 바닥선 V = 0 · 준위 선 · ψ) · `region`(벽돌 — 네 변 `outline`) ·
`body` point(마디) · `readout`(`n = k` · `ħω` · `½ħω` · `V(x)`),
선언 `timeline` · `startAt` · `caption` · `drawOrder: 'scene'` · `canvas` · `stages[].constants`. 상태는 비어 있다. 조작기 없음.

## (a) 답하는 질문과 동사

**질문** — 포물선 우물(용수철에 매인 입자) 속 에너지 준위는 어떻게 놓이고, 가장 낮은 준위는 우물 바닥에 닿는가.

**주장** — 준위는 (n + ½)ħω 라 같은 크기 ħω 가 벽돌처럼 쌓이듯 **같은 간격** 으로 오르고, 맨 아래 준위도 바닥(V = 0)에서
반 벽돌(½ħω) 떠 있으며, 한 층 오를 때마다 ψ 의 마디가 하나씩 는다.

**동사** — *같은 ħω 벽돌을 맨 위 준위에 얹을 때마다 그 윗면이 다음 준위가 된다.*

화면에서 일어나는 방식 —

- 가운데에 포물선 우물 `V(x)`, 꼭짓점에서 오른쪽으로 점선 바닥선(V = 0)이 벽돌 기둥 밑까지 간다.
- `ground` — 바닥 준위 n = 0 에 마디 없는 ψ₀ 가 얹혀 있다. 준위 선은 바닥선보다 위에 떠 있고, 오른쪽 기둥에는 그 틈을
  꼭 채우는 강조색 **반 벽돌 `½ħω`** 하나뿐이다 — 영점 에너지.
- `drop-n` — 같은 크기의 `ħω` 벽돌이 위에서 내려와 기둥 맨 위에 얹힌다. **모든 `drop-n` 이 같은 길이** 이고 벽돌도 늘 같다.
- `grow-n` — 벽돌 윗면 높이에 준위 선이 서고, 그 위에서 ψₙ 이 평평한 선에서 자라난다. 축을 가로지르는 마디가 먹색 점으로
  찍힌다 — 층마다 하나씩 많다(0 · 1 · 2 · 3 · 4).
- `hold-4` — 다섯 준위가 다 섰다. 기둥은 `½ħω` 하나 위에 `ħω` 넷이고, 벽돌 이음매마다 준위 선이 닿는다.
- `fade` — 위 준위와 벽돌이 흐려지고 바닥 준위 하나로 돌아간다.

물리는 Eₙ = (n + ½)ħω, ψₙ = 에르미트 함수(세 항 점화식)다(`physics.ts`). 준위 높이는 스테이지 상수 `quantum` 의
(n + ½) 배라 화면에 띄우는 수가 없다 — 글자는 기호 `ħω` · `½ħω` 뿐이다.

## (b) 화면 구성의 결정 — 두지 않은 것 포함

- **이웃 `particle-in-a-box` 와 장치를 가른다.** 거기는 점선 가로대가 같은 빠르기로 올라 「오를 때마다 오래 걸린다」 로 벌어짐을
  보였다. 여기서 같은 장치를 쓰면 「매번 같은 시간이 걸린다」 는 **일어나지 않는 일** 이라 동사가 약하다. 그래서 **같은 물건을
  되풀이해 얹는** 벽돌을 골랐다 — 같음은 「매번 같은 벽돌이 딱 맞는다」 로 일어나고, 다 쌓인 기둥이 곧 등간격의 자다. 영점
  에너지는 기둥 맨 아래 **반 벽돌** 하나로, 등간격과 같은 자 위에서 읽힌다.
- **벽돌은 얹혀야 준위가 선다.** 벽돌이 내려오는 동안 새 준위 선은 없고, 얹힌 순간 그 윗면에 준위가 선다. 준위를 먼저 두고
  벽돌을 맞춰 보이면 「우연히 맞았다」 로도 읽힌다.
- **벽돌은 위에서 내려온다(`smooth`).** 떨어지는 것(중력)으로 읽히지 않게 내려놓는 이징을 골랐다. 출발 높이가 고정이라 위층
  벽돌일수록 짧게 움직인다 — 주장과 무관한 차이다.
- **강조색은 「에너지 덩이」 한 뜻에만** — 벽돌과 `ħω` · `½ħω` 글자. ψ 와 마디는 같은 대상이라 모두 먹색, 우물 · 바닥선 ·
  준위 선은 muted. 준위를 색으로 가르지 않는다.
- **마디 점** — 「층마다 마디 수가 하나씩 는다」(시각 메모)를 셀 수 있게 마디 자리에 먹색 점을 찍었다. 마디 수 글자는 두지
  않았다 — 점이 수를 말하고 `n = k` 가 이미 옆에 있다.
- **|ψ|² 와 고전 진동자의 머무는 확률은 두지 않았다.** 고전 확률(되돌이점에 몰림)과 |ψ|² 의 비교는 좋은 그림이지만 주장이
  「대응 원리」 로 바뀐다 — 한 조각에 두 주장이다. |ψ|² 는 `wave-function` 의 몫이다.
- **상자와 나란히 두지 않았다.** n² 사다리와 한 화면에서 대비하면 판이 둘이 되고 세로가 모자란다. 대비는 벽돌 기둥(같은 크기)이
  이웃의 벌어지는 치수선과 모양으로 대비되는 것으로 둔다.
- **ψ 높이는 그림 배율이다(`psiHeight`).** 준위마다 가장 큰 봉우리를 같은 높이로 맞췄다 — 정규화 크기(ψ₀ 가 가장 높다)는 이
  주장의 것이 아니다. 간격(`quantum` = 3)의 절반보다 작게(1.2) 잡아 이웃 ψ 와 겹치지 않는다. 화면에 알리지 않는다 — 교과서
  그림의 관례이고 ψ 높이를 에너지로 읽을 자리가 없다.
- **ψ 는 포물선 밖으로 꼬리가 나간다** — 고전 되돌이점 너머 스며듦이다. 주장은 아니지만 지우면 틀린 그림이라 그대로 둔다
  (`psiRange` = ±4.5, 가장 높은 준위의 되돌이점 ξ = 3 너머).
- **조작기 없음.** 용수철 세기 · 질량은 ħω 의 크기만 바꾸고 「모두 같다」 · 「바닥은 반 칸」 은 바꾸지 않는다. ħω 의 실제 값 ·
  eV 도 두지 않았다 — 비가 주장이다.
- 준위 수 5(n = 0 … 4) — 넷이면 벽돌이 셋이라 「매번 같다」 가 두 번 비교뿐이고, 여섯이면 세로가 모자라 간격이 좁아진다.
- `startAt: 2.0` — 도착한 순간 ψ₀ 와 반 벽돌이 이미 있고 1 초 뒤 첫 벽돌이 내려온다.
- 물리량(`quantum` · `xScale` · `levelCount` · `psiHeight` · `psiRange`)은 `stages[].constants`, 배치(벽돌 기둥 자리 · 폭 ·
  출발 높이 · 우물 위 여유 · 경계)는 schema 이름 있는 상수, 선 굵기 · 글자 크기 · 띄움 · 채움 불투명도 · 표본 수는 scene 파일
  머리의 이름 있는 상수다.
- 그리드 · 카메라 단추 · 범례 · 제목 없음(기본값).

## (d) 주장이 화면에서 서는가

`?t=` 촬영본을 라이트 · 다크 모두 직접 열어 확인했다 (2026-09-18, `tasks/piece-lab/_report/_scratch/quantum-harmonic-oscillator/shots/`).

첫 판은 홀수 n 의 가운데 마디(ξ = 0 이 표본에 정확히 떨어짐)가 점으로 찍히지 않았다 — n = 1 에 점 0 개, n = 3 에 2 개. 부호가
바뀌는 자리만 찾던 `nodesOf` 가 값이 정확히 0 인 표본을 건너뛰었다. 고쳐 다시 찍었다 — 아래는 두 번째 판이다.

| t(초) | 단계 | 라이트 · 다크 |
| --- | --- | --- |
| 0.5 | ground | 포물선 속 n = 0 준위에 마디 없는 ψ₀. 준위 선이 점선 바닥선보다 위에 떠 있고, 오른쪽 기둥에 `½ħω` 반 벽돌 하나 |
| 1.6 | drop-1 | `ħω` 벽돌이 반 벽돌 위 높이에서 내려오는 중. n = 1 은 아직 없다 |
| 3.8 | hold-1 | 벽돌이 반 벽돌 위에 얹혔고 그 윗면 높이에 n = 1 준위 선 · 마디 하나(가운데 점) ψ₁ |
| 11.9 | drop-4 | n = 0 … 3 준위(마디 점 0 · 1 · 2 · 3)와 반 벽돌 위 `ħω` 벽돌 셋. 넷째 벽돌이 위에서 내려오는 중 |
| 15 | hold-4 | 다섯 준위, 기둥은 `½ħω` 위에 같은 높이 `ħω` 넷. 벽돌 이음매마다 준위 선이 닿고 마디 점이 0 … 4 개 |

- 동사 「같은 벽돌을 얹을 때마다 윗면이 다음 준위가 된다」 는 t = 1.6 → 3.8 의 얹힘과 t = 15 의 같은 높이 벽돌 넷에서 선다.
  영점 에너지는 t = 0.5 부터 반 벽돌과 떠 있는 준위 선으로 보인다.
- **다크** — ψ · 마디 점은 흰색(`ink` 뒤집힘), 우물 · 준위 선 · 바닥선은 회색, 벽돌은 호박색 윤곽에 어두운 채움. **라이트** — 먹색 ψ,
  벽돌은 주황 윤곽에 옅은 살구색 채움. 두 테마 모두 바탕과 갈리고 뒤집힘이 없다. 글자 겹침 · 화면 밖으로 나감 없음.
- **정지 촬영으로 판정하지 못한 것** — 벽돌 넷이 같은 빠르기 · 같은 모양으로 내려와 얹힌다는 것은 스틸에 나오지 않는다. 단계
  길이가 같게 선언되어 그렇게 되지만 화면에서 움직임을 눈으로 보지는 않았다(미확인).
- 캡션 몇 글자가 옅게 찍혔다(라이트 · 다크 1.6 의 「벽돌」 · 「맨」, 라이트 3.8 의 「벽돌 윗」). 이웃 `particle-in-a-box` · `harmonics` 와 같은
  현상으로 촬영 환경(글꼴 로딩) 쪽으로 판단한다(미확인).
