# bose-einstein-condensate — 제작 기록

자유 구현 원본 없이 엔진 어휘 위에서 바로 지었다.

## (a) 답하는 질문과 동사

**질문** — 원자 기체를 끝까지 식히면 그저 「더 느린 기체」 가 되는가?

**주장 한 문장** — 보손 원자 기체를 식히면 구름과 속도 분포가 매끄럽게 좁아지다가, 임계 온도 아래에서
원자들이 가장 낮은 한 상태로 몰려 구름 한가운데가 한 점으로 무너지고 속도 분포 한가운데에 뾰족한 봉우리가 선다.

**동사** — *식히면 분포가 한 점으로 무너져 봉우리가 선다.*

화면에서 일어나게 한 방법: 세 판을 가로로 놓았다.

- **온도계** — 채움이 내려간다. Tc 눈금이 처음부터 있어 「저 줄을 넘는 순간」 을 눈이 기다린다.
- **덫 속 원자** — 600 개 점이 조화 덫 속에서 계속 돈다(자리 = σ·(a·cos ωt + b·sin ωt), a · b 는 시드 결정적 정규 난수).
  구름 폭 σ 는 √T 에 비례해 줄어든다. Tc 아래에서는 바닥 상태 몫 N₀/N = 1 − (T/Tc)³ 만큼의 원자가 차례로
  바닥 상태 폭(온도와 무관)으로 건너가 한가운데로 **빨려 들어간다** — 점이 한자리에 겹쳐 덩이가 된다.
- **속도 분포** — 같은 가로 배율의 1차원 곡선 = 열 몫 · 넓은 가우스 + 바닥 상태 몫 · 좁은 가우스.
  Tc 위에서는 낮고 넓은 언덕이 좁아지기만 하고, Tc 아래에서 한가운데에 봉우리가 솟는다. 세로 배율은
  가장 차가운 멈춤(0.3 Tc)의 봉우리가 판 꼭대기에 닿도록 상수에서 한 번 정했다 — 뜨거운 언덕이 낮은 것 자체가 대비다.

시간표: `appear` → `hot` → `cool-to-tc` → `cool-below` → `hold-mid`(두 겹 분포) → `cool-deep` → `hold` → `fade`.
온도는 세 식힘 단계 진행도(`at()`)의 합이라 분기가 없고, 멈춤 단계에서는 저절로 멈춘다.

## (b) 화면 구성의 결정

- **이웃 `pauli-exclusion` 과 겹치지 않게** 준위 사다리(에너지 준위를 채우는 그림)를 두지 않았다. 이 조각의 그림은
  「준위에 몇 개가 들어가나」 가 아니라 「자리 · 속도 분포가 한 점으로 무너진다」 이다. 이웃은 작업 시점에 스텁이라
  src · NOTES 를 대조하지 못했다.
- **덫 속 자리와 속도 분포를 함께** 두었다. 1995 년 그림은 풀어 준 뒤 퍼진 원자의 흡수 영상(= 속도 분포)이지만,
  「덫 안의 원자들이 한가운데로 모인다」 는 자리 그림이 더 곧게 읽힌다. 조화 덫에서는 자리 폭과 속도 폭이 같은
  비율로 줄므로 두 판의 가로 배율을 같게 두었다.
- **바닥 상태로 간 원자를 다른 색으로 칠하지 않았다.** 같은 원자다. 몰렸다는 것은 점이 겹친 덩이와 곡선의 높이로
  보인다 (S-piece). 강조색은 쓰지 않았다 — 가를 뜻이 없다.
- **원자들은 늘 움직인다.** 조화 덫의 위상 공간 회전이라 구름 모양은 어느 시각에도 같은 가우스인데 점들은 돈다 —
  멈춤 단계에서도 그림이 살아 있고, 몰린 원자는 거의 움직이지 않는다. 가로 · 세로 진동수를 다르게 둔 것은 실제 덫이
  찌그러져 있어서이고, 같은 무늬가 짧은 주기로 되풀이되지 않게 하기 위해서다.
- **바닥 상태 폭을 키웠다** (`groundWidth` 0.12, 열 구름 폭의 1/5 at Tc). 실제 비율대로 좁히면 봉우리가 판 높이를
  다 먹어 Tc 위의 언덕이 한 줄로 납작해진다. 화면에 알리지 않은 것은, 이 조각이 재는 것이 폭의 비가 아니라
  「넓은 언덕 → 뾰족한 봉우리」 의 모양 변화이기 때문이다.
- **원자가 건너가는 몫을 퍼뜨렸다** (`joinSpread` 0.08). 원자마다 문턱이 달라 단계로 풀 수 없어 스테이지 상수로 두었다.
  0 이면 원자가 바깥에서 한가운데로 순간 이동해 「빨려 든다」 가 사라진다.
- **두지 않은 것** — 온도 · 원자 수 · 바닥 상태 비율의 수치(nK, %), 세로축 눈금, 1995 년 세 봉우리의 3차원 곡면.
  몫은 %로 띄우지 않고 점의 덩이와 곡선의 높이로만 보인다. 온도 눈금은 Tc 하나다 — 주장이 기대는 기준은
  「Tc 위냐 아래냐」 뿐이다. 그리드 · 카메라 단추 · 조작기도 없다. 독자가 직접 해 봐야 하는 것이 없다 —
  온도를 끌게 하면 「Tc 아래로 내렸다」 를 독자가 맞춰야 주장이 선다.
- 이 모형은 **상호작용 없는 이상 보스 기체**다. 실제 응축체는 원자 사이 상호작용으로 바닥 상태보다 조금 넓고,
  찌그러진 덫에서는 풀어 준 뒤 모양이 뒤집히는 비등방 팽창도 보인다 — 둘 다 이 주장 밖이라 두지 않았다.

## (d) 주장이 화면에서 서는가

`?t=` 고정 촬영으로 라이트 · 다크를 모두 열어 봤다 (`tasks/piece-lab/_report/_scratch/bose-einstein-condensate/shots/`).

- **t=1 (cool-to-tc)** — 온도계 채움이 Tc 눈금 위. 구름은 넓게 퍼져 있고 분포는 낮고 넓은 언덕 하나. 두 테마 모두 선다.
- **t=4.6 (cool-below)** — 채움이 Tc 아래. 구름 한가운데에 짙은 덩이가 생겼고, 분포 한가운데에 좁은 봉우리가 솟으며
  「가장 낮은 한 상태」 이름표가 나타난다. 선다.
- **t=6 (hold-mid)** — 넓은 언덕 위에 봉우리가 선 두 겹 분포, 구름은 성긴 바깥과 한가운데 덩이로 갈린다. 다크에서도
  먹색 곡선 · 회색 점이 뒤집히지 않고 읽힌다. 선다.
- **t=10 (hold)** — 바깥 원자가 거의 없고 원자 대부분이 한 점에 몰렸다. 분포는 언덕이 사라진 뾰족한 봉우리 하나가 판
  꼭대기까지. 봉우리 이름표 · 캡션 모두 겹치지 않고 화면 안이다. 선다.
