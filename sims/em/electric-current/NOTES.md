# electric-current — 전류

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 전류가 「세다」 는 것은 무엇이 많다는 것인가.

**주장** — 전류는 한 단면을 1 초에 지나는 전하의 양이다. 알갱이가 두 배 빠르게 흐르거나
두 배 촘촘하면 같은 시간에 문을 지나는 수가 두 배다.

**동사** — 같은 시간에 문을 지나는 알갱이가 **두 배로 쌓인다.**

화면에서 일어나는 일:

1. 세 도선이 위아래로 흐른다 — `v, d`(기준) · `2v, d`(두 배 빠르게) · `v, d/2`(두 배 촘촘히).
   알갱이는 전자라 왼쪽으로 가고, 위에 방향 표식 `e⁻ ←` · `→ I` 이 한 번 있다.
2. 세 도선의 단면 문이 **같은 x 에서 함께** 열린다(강조색 · 굵은 선). 문 위 시간 막대가
   `count` 단계 길이(`1 s`)만큼 차오르는 동안, 문을 지나는 알갱이마다 강조색으로 바뀌고 문 옆에 네모가 하나씩 붙는다.
3. 막대가 다 차면 문이 닫힌다. 네모 줄이 **4 · 8 · 8** 로 남는다. 세어진 무리는 빠른 도선에서
   두 배 길게, 촘촘한 도선에서는 같은 길이에 두 배로 놓여 왼쪽으로 흘러간다 — 「더 멀리서 온
   것을 셌다」 와 「같은 거리에 더 많이 있었다」 가 두 배의 두 까닭으로 함께 보인다.
4. 쌓인 것이 흐려지고 다시 센다.

센 수는 알갱이 번호에서 곧바로 나온다(`readLane`) — 네모의 수와 강조된 알갱이의 수가 어긋날
수 없다. 첫 통과를 문이 열린 뒤 반 간격(d/2v)에 두어, 통과 시각이 창 경계와 겹치지 않는다.
그래서 매 주기 정확히 v·T/d 개를 센다(부동소수로 4 가 3 이 되는 주기가 없다).

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 세 도선을 나란히 | 「빠르게」 와 「촘촘히」 가 **서로 다른 두 길로 같은 두 배**에 닿는다는 것이 주장의 절반이다. 한 도선에서 번갈아 보이면 기준과 견줄 수 없다 |
| 문 · 시간 막대를 세 도선이 공유(같은 x, 같이 열림) | 「같은 시간」 이 전제다. 문마다 따로 열리면 센 수의 차이가 시간 탓인지 흐름 탓인지 갈리지 않는다 |
| 센 수는 **네모 줄 길이**로, 수는 띄우지 않음 | 네모 크기 · 간격이 세 줄에서 같아 4 와 8 이 길이로 견줘진다. 정수 계수를 띄울 수는 있으나 계산한 수를 화면에 쓰는 것을 피했다(S-piece 유효숫자). 네모는 하나씩 셀 수 있다 |
| 강조색 = 「세었다」 한 뜻 | 열린 문 · 세어진 알갱이 · 네모 · 차오르는 시간 막대. 닫힌 문은 muted 로 물러난다 |
| 세어진 알갱이는 primary 한 벌 위에 accent 한 벌을 겹침 | 흐려짐 단계에서 강조 벌만 옅어져 제 색으로 돌아간다 — 주기 경계에서 색이 튀지 않는다 |
| 방향 표식은 한 번(위쪽) | 전자와 전류의 방향이 반대라는 것은 이 조각의 부주장이다. 전자 화살표는 알갱이와 같은 primary, 전류 화살표는 먹색. 색이 아니라 기호(`e⁻` · `I`)와 방향으로 가른다 |
| 도선 기호 `v, d` · `{n}v, d` · `v, d/{n}` | 무엇이 두 배인지를 표식으로. `n` 은 스테이지 상수 `fastMultiple` · `denseDivisor` 를 그대로 끼운다(가운데 속력 = speed × fastMultiple, 아래 간격 = spacing ÷ denseDivisor). 문장으로 쓰면 도선 셋마다 이름표 문안이 되어 캡션과 겹친다 |
| 세는 시간 = `count` 단계 | 문은 그 단계가 시작할 때 열려 끝날 때(`tl.end('count')`) 닫히고, 막대 이름표도 `tl.duration('count')` 를 쓴다. 따로 상수를 두면 저작자가 단계 길이만 바꿨을 때 단계 중간에서 닫힌다(rule-guard 사후 검증) |
| 문을 오른쪽 끝 가까이(x = 1.2) | 전자가 왼쪽으로 가므로 세어진 무리가 문 뒤로 길게 남는다 |
| 도선 끝에서 알갱이가 흐려지며 드나듦 | 잘린 도막이 아니라 긴 도선의 한 단면으로 읽히게. 양 끝 변도 긋지 않았다 |
| 모든 단계를 같은 `timeScale` 0.25 | 빠른 도선은 1 초에 8 개가 지나가 실시간으로는 못 센다. 단계마다 배율이 다르면 흐름이 경계에서 갑자기 빨라진다 |
| 주기 2.5 초 × 속력/간격(4 · 8 · 8) = 정수 | 주기가 돌아올 때 알갱이가 간격의 정수배만큼 밀려 제자리로 이어진다 — 흐름이 튀지 않는다 |
| 캡션에 `e⁻` 를 쓰지 않음 | 캡션 글꼴에서 위첨자 빼기가 떨어져 `(e⁻ )` 로 벌어졌다. 기호는 화살표가 말한다 |
| 두지 않은 것 | 전류 값(A) · 전하량(C) · 식 `I = ΔQ/Δt` — 문단의 몫. 전자가 실제로 얼마나 느린가(표류 속도)는 `drift-velocity` 의 몫이라 속력의 실제 크기를 말하지 않는다. 전지 · 회로 기호 — 이 조각은 도선 한 단면만 본다. 그리드 · 조작기 — 잴 것은 거리가 아니라 개수이고, 속력을 끌게 하면 센 수가 정수에서 벗어난다 |

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 정지 화면만으로는 가운데 도선이 두 배 빠른 것이
