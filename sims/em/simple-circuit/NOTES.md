# simple-circuit — 전기 회로 만들기

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다. 초등 수준이다.

## (a) 답하는 질문과 동사

**질문** — 전구에 불이 켜지려면 전지 · 전선 · 전구가 어떻게 놓여야 하는가.

**주장** — 전지 · 전선 · 전구가 끊김 없는 한 고리를 이룰 때만 알갱이가 돌고 전구가 켜진다.
고리의 **어디** 한 곳을 끊어도 모든 알갱이가 멈추고 전구가 꺼진다.

**동사** — 한 곳을 끊으면 *고리 전체가 멈추고 전구가 꺼진다*, 다시 이으면 *다시 돌고 켜진다*.

화면에서 일어나는 일 (한 주기 14.2 초, `timeline` 12 단계):

1. `lit-a` — 네모 고리. 왼쪽 변에 전지(긴 판 + 위 · 짧은 판 − 아래), 위 변 가운데에 전구.
   전자 알갱이가 꼬리를 달고 − 극에서 나와 아래 변 → 오른쪽 변 → 위 변(전구를 지나) → + 극으로 돈다.
   전구 동그라미 안이 가득 찬 빛(`light: 1`)이고 위쪽으로 빛살 다섯 줄.
2. `cut-a` → `dark-a` — 전구 바로 오른쪽 위 전선 토막이 경첩에서 위로 젖혀진다. 떨어지는 순간(`cut-a` 시작)
   고리 **전체의** 알갱이가 멈추고(꼬리가 사라진다) 전구가 빛 없음으로 바뀌며 빛살이 사라진다.
   끊긴 자리를 강조색 고리가 두른다.
3. `join-a` → `lit-b` — 토막이 다시 닫히고, 닿는 순간(`join-a` 끝) 다시 흐르고 켜진다.
4. `b` (전구에서 가장 먼 오른쪽 변, 오른쪽으로 젖혀짐) · `c` (전지 가까운 아래 전선, 아래로 젖혀짐)에서 같은 일이 되풀이된다.

세 자리는 전구와의 거리가 다르다 — 바로 옆 · 가장 먼 곳 · 전지 곁. 셋 모두에서 결과가 같다는 것이
「어디를 끊어도」 의 몫이다. 알갱이가 흐른 거리는 `lit-*` 단계 길이의 합 × 빠르기로 닫힌 식이라
(주기 번호 × 한 주기 흐름 + 이번 주기 흐름) 같은 시각은 같은 화면이고 주기 경계에서 튀지 않는다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 끊김 = 경첩에서 젖혀지는 전선 토막 | 「스위치를 끈다」 가 아니라 「전선 한 곳이 떨어진다」 가 주장이다. `circuitElement` switch 를 세 곳에 두면 스위치 세 개로 읽히고 「어디든」 이 약해진다. 토막 양 끝의 이음점(`terminal` node)은 세 자리 모두에 늘 보여, 끊을 수 있는 곳이 처음부터 드러난다 |
| 멈춤은 고리 **전체** · 한순간 | 끊긴 곳 근처만 멈추거나 차례로 멈추면 「물이 새듯 흐름이 끊긴 곳에서 막힌다」 로 오독된다. 떨어지는 순간(`cut-*` 시작)과 닿는 순간(`join-*` 끝)을 단계 경계로 선언했다 |
| 흐름은 알갱이 + 길을 따르는 꼬리 | 정지 화면에서도 흐르는가 · 멈췄는가가 꼬리의 유무로 갈린다. 꼬리 길이 = `flowSpeed × trailSeconds`(스테이지 상수) |
| 젖혀진 토막 위 알갱이는 토막과 함께 들린다 | 틈에 알갱이가 떠 있으면 「끊겼는데 알갱이가 건너간다」 로 읽힌다 |
| 전구 켜짐 = 빛 채널 원 + 빛살 | 색 역할로 칠하면 라이트 테마에서 밝음이 어둡게 나온다(G34 해결 방식). 가득 찬 빛(흰색)이 라이트 미색 바탕에 묻히므로(G92) 모양(빛살)으로도 말한다. 꺼지면 빛 없음(거의 검정) — 라이트에서는 검은 공, 다크에서는 빈 동그라미 |
| 강조색 = 「지금 끊긴 자리」 한 뜻 | 젖혀진 만큼(`openness`, `cut-*` · `join-*` 진행도) 짙어진다. 알갱이 · `e⁻` 는 primary, 장치는 먹색 |
| 전자 알갱이와 `e⁻ →` 표식 한 번 | 알갱이가 무엇인지 표식으로 밝힌다(지시서). 관례 전류 `I` 는 두지 않았다 — 초등 주장에 방향 규약이 끼어들면 요점이 흐려진다. 알갱이는 − 극에서 나와 + 극으로 들어가 전자의 방향과 맞다 |
| 전지는 `lineSet` 두 판 | G178 — `circuitElement` battery 는 리드선과 기호 사이가 비어 **끊긴 회로로 보인다.** 「끊김」 이 주장인 조각에서 치명적이다 |
| 전구는 `circuitElement` lamp | 동그라미가 리드선에 닿아 틈이 없다. 빛 원은 기호 **아래** 에 깔린다(`drawOrder: 'scene'`) |
| 고리를 가로로 길게(10 × 3 월드) | 세로가 비싸다(S-piece). 첫 촬영에서 6 × 3 이 세로에 묶여 작게 나와 가로로 넓혔다 |
| 두지 않은 것 | 전압 · 전류 값 · 저항 · 식 — 초등 주장은 「이어졌는가」 뿐이고 수는 문단의 몫도 아니다. 조작기 — 독자가 끊어 볼 수 있게 하는 것도 생각했으나 자동 진행이 세 자리를 모두 보이고, 끊는 자리 고르기는 조작기 어휘(G90 계열 2위치 스위치)가 없어 탭 · 클릭 선언으로 표현할 수 없다. 그리드 · 카메라 단추 — 잴 거리가 없다. 빛의 세기 단계(희미하게 켜짐) — 이 조각의 전구는 켜짐 / 꺼짐 둘뿐이다 |
| 캡션 | 지금 벌어지는 일만. `cut-*` · `dark-*` 는 같은 문장(끊었다 — 멈추고 꺼졌다), `join-*` 는 「다시 잇는다」, `lit-b` · `lit-c` 는 「다시 이어지자 … 다시 켜졌다」. 다음 단계를 미리 말하지 않는다 |

## (c) 어휘 부족

| 장부 id | 겪은 것 | 영향 |
|---|---|---|
| G178 | `circuitElement` battery 의 리드선 · 기호 틈 — 전지를 `lineSet` 두 판으로 그었다 | 근사 |
| G90 | 코어에 회로 기호 · 2위치 스위치가 없다 — 끊는 토막을 `lineSet` 선분 + `terminal` 이음점으로 조립했다 | 근사 |
| G89 | 길을 따라 흐르는 점 묶음이 없다 — scene 이 알갱이 번호마다 호길이 자리를 계산해 `particleSystem` 에 넘긴다 | 근사 |
| G181 | `particleSystem` 꼬리가 곧은 선이라 모서리에서 길 밖으로 삐진다 — 알갱이마다 호길이 구간을 잘라 `lineSet` 으로 길을 따라 긋는다 | 근사 |
| G92 | 가득 찬 빛이 라이트 바탕에 묻힌다 — 켜진 전구에 빛살(먹색 `lineSet`)을 더했다 | 근사 |
| G140 | 빛 없음이 다크 바탕과 거의 같다 — 꺼진 전구는 다크에서 빈 동그라미로 보인다(기호 테두리 · 가위표가 경계를 준다) | 근사 |
| G105 | 끊는 자리 셋(호길이 구간)의 목록을 스테이지 상수로 선언할 수 없다 — `schema.ts` 모듈 상수 `CUT_A · CUT_B · CUT_C` 와 `physics.ts` 의 `CUTS` 표로 남는다. 에디터로 자리를 옮기거나 넷째 자리를 더할 수 없다 | 근사 |
| G129 | 단계 사이 관계(`cut-x` 뒤에 `dark-x` · `join-x` 가 와야 하고, 흐름은 `lit-*` 에서만)를 선언할 자리가 없다 — 단계 id 접두어(`lit-`)와 `cut-{id}` · `join-{id}` 이름 짝에 기댄다. 저작자가 단계 이름을 바꾸면 던진다(없는 id) | 근사 |

새 부족:

| 부족 | 영향 |
|---|---|
| `circuitElement` lamp 에 켜짐 · 밝기 상태가 없다 — 기호는 늘 같은 빈 동그라미 + 가위표다. 켜짐을 `body` circle(`light` 채널 · `glow`)을 기호 아래 깔고 빛살 `lineSet` 을 덧그려 근사했다. 전구 · 빛 · 빛살이 따로 인스턴스라 에디터로 전구만 옮기면 빛이 남는다. 다크에서 켜지면 흰 빛 위 가위표가 거의 사라진다(기호 선이 전경색) | 근사 |
| `circuitElement` 의 도선이 끊기는 것 · 스위치가 열리고 닫히는 **도중** 을 선언할 수 없다 — switch 는 `open` / `closed` 두 모습뿐이고 30° 로 고정이라 젖혀지는 움직임이 없다. 끊는 토막을 경첩 회전 선분으로 직접 계산했다 | 근사 |

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ simple-circuit` — 라이트 · 다크 각 5 장
(두 번째 촬영: 고리를 가로로 넓힌 뒤).

| t | 라이트 | 다크 |
|---|---|---|
| 1.1 | 고리 전체에 알갱이와 길을 따르는 꼬리. 전구 안이 흰 빛, 둘레 옅은 번짐 + 먹색 빛살 다섯. 이음점 여섯 모두 닫힘. 캡션 「… 한 바퀴 이어져 있다 — 알갱이가 돌고 전구가 켜져 있다」 — 섬 | 전구가 흰 빛 + 번짐 + 흰 빛살로 또렷. 꼬리가 전선을 붉게 덮어 흐름이 분명 — 섬 |
| 3.3 | 전구 오른쪽 토막이 위로 젖혀져 틈, 강조색 고리. 꼬리 없음(멈춤), 전구가 검은 공, 빛살 없음. 토막 위 알갱이 하나가 함께 들림 — 섬 | 같다. 전구는 빈 동그라미 + 가위표(G140), 전선이 흰색으로 돌아와 멈춘 것이 또렷 — 섬 |
| 5.6 | 토막 닫힘, 꼬리 다시 있음, 전구 다시 흰 빛 + 빛살. 캡션 「다시 이어지자 … 다시 켜졌다」 — 섬 | 같다 — 섬 |
| 7.9 | 오른쪽 변 토막이 오른쪽으로 젖혀짐, 강조 고리. 전구에서 먼 곳인데도 꼬리 없음 · 전구 꺼짐 — 섬 | 같다 — 섬 |
| 12.5 | 전지 곁 아래 전선 토막이 아래로 젖혀짐. 멈춤 · 꺼짐. 강조 고리가 캡션 줄 위에서 멈춰 겹치지 않음 — 섬 | 같다 — 섬 |

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 정지 화면에서는 「흐른다 / 멈췄다」 가 꼬리의 유무로 갈리고,
움직이는 화면에서는 알갱이가 실제로 돌다 멈춘다. 라이트 캡션 몇 글자가 옅게 찍히는 현상은 다른 조각들과 같다(원인 미확인).
