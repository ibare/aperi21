# joule-heating — 줄 열

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 직렬로 이은 두 저항에 전류를 흘리면 어느 쪽이 먼저 뜨거워지는가.

**주장** — 크기가 같은 두 저항을 한 줄로 이어 같은 전류를 흘리면, 저항이 큰 쪽이 더 빨리 뜨거워진다.

**동사** — 스위치를 닫으면 같은 전자 흐름이 두 덩어리를 지나고, **큰 저항 쪽 원자가 더 세게 떨고
온도계가 더 빨리 오른다.**

화면에서 일어나는 일 (한 주기 10 초, `timeline` 6 단계):

1. `rest` — 네모 회로. 왼쪽 변에 전지(`16 V`, 긴 판 + 위), 아랫변 가운데에 스위치(레버가 들림),
   윗변에 같은 크기의 저항 덩어리 둘(`6 Ω` · `2 Ω`)이 한 줄로. 덩어리 속 원자 두 줄이 줄 맞춰
   거의 제자리에 있고, 덩어리 바로 아래 온도계 둘이 같은 실온 높이다. 전자 알갱이는 멈춰 있다.
2. `close` — 레버가 내려와 닿는다.
3. `flow` — 전자 알갱이가 꼬리를 달고 고리를 돈다. 윗변에서 두 덩어리를 **같은 빠르기로 차례로**
   지난다(원자 두 줄 사이). 두 온도계가 오르기 시작한다.
4. `heat` — 온도계 차가 벌어진다. `6 Ω` 막대가 `2 Ω` 막대의 세 배 빠르기로 오르고, `6 Ω` 덩어리의
   원자 격자가 크게 흐트러진다. `2 Ω` 쪽은 조금만 흔들린다.
5. `open` — 레버가 들린다. 알갱이가 멈추고 꼬리가 사라진다.
6. `cool` — 두 막대가 실온 높이로 내려오고 떨림이 잦아든다. 다음 주기의 `rest` 로 이어진다.

온도는 전류가 흐른 시간의 닫힌 식이다 — 두 덩어리의 오르는 빠르기는 I²R / C (`heatingRate`),
전류는 V / (R₁ + R₂)(`seriesCurrent`)이다. 떨림은 원자마다 (시드, 조각 시계)의 사인 함수라 같은 시각은
언제나 같은 화면이다. 쌓는 상태가 없다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 두 저항을 **같은 크기** 덩어리로, 저항은 이름표로 | 시각 메모의 「굵기가 다른 두 도선」 을 따르면 굵은 쪽이 열용량도 커서, 「같은 전류에서 저항이 큰 곳이 열을 더 낸다」 에 「가는 것은 쉽게 달아오른다」 가 섞인다(온도 비가 R 비가 아니라 R² 비가 된다). 크기를 같게 두어 열용량을 같게 하고 저항만 다르게 했다. 두 덩어리의 열용량은 스테이지 상수 `heatCapacity` 하나다 |
| 한 줄(직렬) 회로 하나 | 「같은 전류」 가 배선 모양으로 보인다 — 알갱이 하나가 두 덩어리를 차례로 지난다. 두 회로를 나란히 두면 전류가 같다는 것을 믿어야 한다 |
| 병렬 대비(P = V²/R, 작은 저항이 더 뜨거움)를 **두지 않음** | 지시서가 한 단계로 허락했으나, 한 주기 안에서 「큰 쪽이 뜨겁다」 와 「작은 쪽이 뜨겁다」 가 다 나오면 주장이 둘이 된다. 병렬은 전류가 둘로 갈리는 배선이 따로 필요해 화면도 둘이 된다 — 조각이 둘이다 |
| 달아오름 = 원자 떨림 폭 + 온도계 막대 | 떨림은 「뜨거움」 이 무엇인지를, 막대는 「얼마나 빨리」 를 보인다. 정지 화면에서는 떨림이 격자가 흐트러진 정도로 읽힌다. 막대만 두면 수치 그래프가 되고, 떨림만 두면 빠르기를 견줄 수 없다 |
| **빛나는 색 · 붉게 달아오른 색을 쓰지 않음** | 지시서 금지. 덩어리 · 원자는 온도와 무관하게 먹색이다 — 색이 온도를 말하면 색으로 설명하는 것이 된다(S-piece) |
| 강조색 = 「열(온도)」 한 뜻 | 온도계 알과 차오른 막대만. 전자는 primary, 원자 · 덩어리 · 전지 · 레버는 먹색, 도선 · 관 · `T` 는 muted. 열 전용 역할이 없어 accent 를 빌렸다(G102) — 이 조각에서 accent 의 다른 쓰임은 없다 |
| 전자 알갱이는 두 덩어리를 같은 빠르기 · 같은 간격으로 | 「같은 전류」 를 한 가지 모양으로. 덩어리 속 전하 밀도 · 표류 속도는 drift-velocity 의 몫이라 여기서 섞지 않는다. 원자 두 줄 사이를 지나 원자와 겹치지 않고, 알갱이(2.5 px, primary)와 원자(4 px, 먹색)는 크기 · 색으로 갈린다 |
| 흐르는 동안에만 꼬리 | 스위치를 연 뒤 멈춘 것이 정지 화면에서도 읽힌다. 레버가 들린 동안 틈 속 알갱이는 가린다 — 첫 촬영에서 틈 공중에 알갱이가 떠 있었다 |
| 달아오르는 동안 열 손실 없음, 식음은 `cool` 단계 하나 | 온도가 곧게 올라 「빠르기가 R 에 비례」 가 막대 높이 비(3 : 1)로 매 순간 서 있다. 뉴턴 냉각을 넣으면 두 막대가 다른 높이에서 포화해 빠르기 견줌이 흐려진다. 식음은 주기를 닫는 일이라 이징(`smooth`)으로 실온까지 내린다 — 두 막대가 같은 때 실온에 닿는 것은 물리가 아니라 주기 되감기다 |
| 전압 하나, 전지 한 칸 | 전압을 올리면 전류가 는다는 것은 ohms-law 의 몫이다 |
| 막대 눈금 · 온도 값 · 전류 · 전력 값을 **두지 않음** | 모두 계산값이라 띄우면 자릿수를 줄이게 되고, 정박값으로 선언하면 V · R 과 이중 선언이 된다(G143). 주장은 두 막대의 높이 비와 떨림 차이다. 식 `P = I²R` 은 문단의 몫 |
| 온도계 위 `T` 표식 | 관이 온도계라는 것을 밝힌다. 수식 기호라 표식이다(C1 판정 3) |
| 캡션 값은 선언값을 state 로 옮겨 끼움 | `{rLarge}` · `{rSmall}` — 스테이지 상수를 `initialState` 가 `String(값)` 으로 옮긴다(G133 우회). 「세 배」 처럼 상수 비에 기대는 말은 쓰지 않았다 |
| 캡션이 스위치 단계에서는 스위치 일만 | `close` 「스위치를 닫는다」, `open` 「스위치를 연다」. 흐름 · 식음은 그다음 단계 캡션이 말한다 |
| `startAt` = `flow` 에 0.5 초 들어간 자리 | 도착한 순간 이미 흐르고 온도계가 오르고 있다 |
| 조작기 · 그리드 없음 | 자동 진행으로 주장을 마친다. 잴 거리가 없다 |

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ joule-heating` — 라이트 · 다크 각 5 장. 두 번 찍었다
(1 차: 실온 막대가 온도계 알에 묻혀 거의 안 보임, 스위치가 열린 동안 틈 공중에 전자 알갱이가 떠 있음 →
`ROOM_COLUMN` 0.12 → 0.2, 레버가 들린 동안 틈 속 알갱이를 가림).

| t | 라이트 | 다크 |
|---|---|---|
| 0.5 | 스위치 닫힘. 알갱이가 꼬리를 달고 고리 전체를 돈다(윗변에서 두 덩어리 원자 줄 사이를 지남). 두 막대가 실온에서 조금 올랐고 `6 Ω` 이 약간 높다. 두 격자 모두 줄 맞춤. 캡션 「같은 전류가 두 저항을 차례로 지난다」 — 섬 | 같다. 원자 흰색, 막대 금빛 — 섬 |
| 3.0 | `6 Ω` 막대가 `2 Ω` 막대보다 눈에 띄게 높다. `6 Ω` 격자가 흐트러짐, `2 Ω` 은 거의 줄 맞춤. 캡션 「6 Ω 쪽이 더 빨리 뜨거워진다 …」 — 섬 | 같다 — 섬 |
| 5.2 | 달아오름 끝 무렵. `6 Ω` 막대가 관 위 끝 가까이, `2 Ω` 막대는 그 1/3 쯤. `6 Ω` 원자가 크게 흩어짐 — 섬 | 같다 — 섬 |
| 6.9 | 레버가 들려 있고 틈에 알갱이 없음, 꼬리 없음. 두 막대가 내려오는 중(`6 Ω` 이 아직 높음), `6 Ω` 격자 흐트러짐이 줄었다. 캡션 「전류가 멎자 두 저항이 식는다」 — 섬 | 같다 — 섬 |
| 8.5 | 다음 주기의 쉼. 레버 들림, 두 막대가 같은 실온 높이, 두 격자 줄 맞춤. 캡션 「크기가 같은 두 저항 6 Ω · 2 Ω 을 한 줄로 이었다 — 지금은 둘 다 같은 온도다」 — 섬 | 같다 — 섬 |

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 정지 화면에서 떨림은 흐트러진 격자로만 보인다(N1) — 두 막대 높이가
같은 말을 하고, 움직이는 화면에서는 떨림이 보인다(촬영으로는 미확인 — 떨림 식은 시각의 사인 함수다).
라이트 8.5 장의 캡션에서 한 글자가 옅게 찍힌 것은 글꼴 적재 시점의 촬영 흔적으로 보인다(미확인 — 다른 시각 · 다크에는 없음).
