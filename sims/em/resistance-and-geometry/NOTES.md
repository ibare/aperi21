# resistance-and-geometry — 저항과 형태

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 같은 재료 도선이 길어지거나 가늘어지면 전류는 어떻게 되는가.

**주장** — 같은 재료 도선에 같은 전압을 걸면, 길이를 두 배로 늘인 도선으로는 같은 시간에 절반의
전하가, 단면적을 두 배로 넓힌 도선으로는 두 배의 전하가 빠져나간다 — 길고 가늘수록 저항이 크다.

**동사** — 같은 시간 동안 도선 끝을 **빠져나간 알갱이가** 긴 도선에서 절반, 굵은 도선에서 두 배로 **쌓인다.**

화면에서 일어나는 일:

1. 위 전지(`6 V`, 긴 판 + 가 오른쪽)의 두 레일 사이에 같은 재료 도선 막대 셋이 나란히 걸려 있다 —
   `L · A`(기준), `2L · A`(길이만 늘임), `L · 2A`(두께 = 단면적만 넓힘). 셋이 같은 두 레일에 걸려
   같은 전압을 받는다는 것이 배선 모양으로 보인다. 셋의 출구(오른쪽 끝)는 한 세로줄에 있다.
2. 막대마다 전자 알갱이가 같은 간격 · 같은 레인 간격으로 차서 왼쪽에서 오른쪽으로 흐른다(`e⁻ →`,
   관례 전류 `I ←` 표식 한 번). 긴 막대의 알갱이는 기준의 절반 빠르기(꼬리가 짧다), 굵은 막대는
   기준과 같은 빠르기에 레인이 두 배다.
3. 세는 단계 — 세 출구에 강조색 문이 서고, 출구를 지나는 알갱이마다 오른쪽 레일 너머에 두 줄
   무더기로 한 알씩 쌓인다. 굵은 도선 무더기가 가장 빨리, 긴 도선 무더기가 가장 느리게 자란다.
4. 견주는 단계 — 문이 사라지고 무더기가 **12 · 6 · 24 개(6 · 3 · 12 열)** 로 멈춰 있다. 줄 수가 같아
   개수의 비가 폭의 비 1 : ½ : 2 로 읽힌다. 이어 무더기가 흐려지고 다음 주기에 다시 센다.
5. 긴 막대 가운데 세로 점선, 굵은 막대 가운데 가로 점선 — 긴 도선은 기준 도선 둘을 **이어 붙인** 것,
   굵은 도선은 **나란히 붙인** 것이라는 관점이 모양으로 남는다(직렬 · 병렬).

알갱이 자리와 무더기 크기는 빠르기 × 조각 시계의 닫힌 식이다 — 같은 시각은 언제나 같은 화면이고,
주기 경계에서도 알갱이가 튀지 않는다(빠르기가 주기 내내 일정하다).

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 도선 셋을 한 전지의 두 레일에 나란히 | 「같은 전압」 을 문장이 아니라 배선으로 보인다. 도선마다 전지를 따로 두면 세로가 세 배로 들고 「같은가」 를 글자로 확인해야 한다 |
| 기준 · 길이만 · 단면적만, 한 번에 하나만 바꾼 셋 | 두 변수를 한 도선에서 함께 바꾸면 무엇 때문인지 가릴 수 없다. 기준이 둘의 공통 잣대다 |
| 단면적 = 막대 **두께** | 2D 그림이라 단면을 보일 자리가 없다. 두께가 두 배면 레인이 두 배 — 「넓게 흐른다」 가 모양이 된다 |
| 알갱이 촘촘함(앞뒤 · 레인 간격)은 세 도선이 같다 | 같은 재료 = 같은 운반자 밀도. 촘촘함이 달라 보이면 「재료가 다르다」 로 읽힌다 |
| 빠르기 = 유동 속도 비 **L₀/L** (단면적과 무관) | 물리 그대로다 — v = I/(nqA) ∝ V/(ρL). 굵은 도선의 전류가 느는 것은 빨라져서가 아니라 넓어져서다. 두 원인(느려짐 · 넓어짐)이 서로 다른 모양으로 보이는 것이 이 조각의 요점이다 |
| 전류는 **무더기 개수**로 — 같은 시간 동안 출구를 지난 알갱이 | 전류 = 단위 시간에 단면을 지나는 전하. 빠르기만 보이면 굵은 도선의 두 배가 보이지 않는다(같은 빠르기다). 세어 쌓으면 두 원인이 한 잣대로 합쳐진다 |
| 무더기 줄 수 고정(`pileRows` 2) | 개수의 비가 폭의 비로 곧장 읽힌다. 레인 수만큼 쌓으면 굵은 무더기가 넓이로만 커져 비가 흐려진다 |
| 기준 빠르기를 `countPerLane × 간격 / 세는 단계 길이` 로 얻음 | 세기가 끝났을 때 무더기가 **정확한** 정수(12 · 6 · 24)가 된다. 레인마다 floor 차이는 알갱이 자리와 같은 식이라 출구를 지나는 순간 한 알이 는다. 끝값은 반올림으로 고정해 부동소수 끝자리에 한 알이 흔들리지 않는다. 대신 세는 단계 길이를 바꾸면 흐름 빠르기도 바뀐다(G13 에 가까운 연결 — (c)) |
| 알갱이 꼬리 = 빠르기 × `trailSeconds`(0.5 초), 막대 안으로 clip | 정지 화면에서도 긴 도선의 느림이 짧은 꼬리로 읽힌다. 0.6 초로 두면 기준 꼬리가 간격(0.3)에 닿아 한 줄로 이어졌다(2차 촬영). 막대 밖 이음 도선 위로 꼬리가 삐지지 않게 `clip` |
| 강조색 = 「지금 세는 출구」 한 뜻 | 세는 단계에만 문이 선다. 무더기 알갱이는 도선 속 알갱이와 같은 대상이라 같은 primary |
| 이음매 점선을 알갱이 **위**에 | 아래에 깔면 긴 막대의 세로 이음매가 알갱이 · 꼬리에 묻혀 보이지 않았다(2차 촬영). 막대 밖으로 조금 삐져나와 「이음매」 로 읽힌다 |
| 이름표 `L · A` · `{lf}L · A` · `L · {af}A` | 기호(표식)에 배수만 선언값으로 끼운다. 실제 길이 · 넓이 수(m · mm²)는 이 그림의 잣대가 아니다 |
| 캡션 값은 선언값을 state 로 옮겨 끼움 | `{v}` · `{lf}` · `{af}` — `initialState` 가 `String(값)` 으로 옮긴다(G133 우회). 「절반」 · 「두 배」 를 문안에 박지 않고 `1/{lf}` · `{af}배` 로 쓴다 |
| 두지 않은 것 | **저항 · 전류 수(Ω · A)** — 계산값이라 띄우면 유효숫자를 줄이게 되고, 정박값으로 선언하면 ρL/A 와 이중 선언이 된다(G143). 비는 무더기 폭이 말한다. **식 `R = ρL/A`** — 문단의 몫. **비저항 ρ 표시** — 세 도선이 같은 재료라 비에서 지워진다. 선언값으로는 계산에 들어간다. **전류계** — `scale` dial 이 값 글자를 `toFixed` 로 늘 쓰고(G144) 이 조각의 동사는 쌓임이다. **`circuitElement`** — 전지 기호가 리드선과 떨어져 보이고(G178) 저항 기호 지그재그로는 길이 · 굵기를 보일 수 없다. **조작기 · 그리드** — 자동 진행으로 주장을 마치고, 배수를 끌게 하면 무더기가 정수로 떨어지지 않는다. **온도 · 재료 바꾸기** — temperature-and-resistance 의 몫 |

## (c) 어휘 부족

| 장부 id | 겪은 것 | 영향 |
|---|---|---|
| G90 | 코어에 회로 기호가 없다 — 전지는 `lineSet` 긴 판 · 짧은 판, 도선 · 레일은 `trajectory` · `lineSet` 으로 긋는다 | 근사 |
| G178 | plugin-circuit `circuitElement` battery 는 리드선과 기호 사이가 비어 회로가 끊겨 보인다 — 쓰지 않았다 | 근사 |
| G89 | 경로를 따라 흐르는 점 묶음이 없다 — scene 이 레인마다 알갱이 자리를 계산해 `particleSystem` 에 넘긴다 | 근사 |
| G105 | 도선 셋(형태 · 줄 높이 · 이름표)의 목록을 스테이지 상수로 선언할 수 없다 — `scene.ts` 의 `wires` 코드 표. 줄마다의 값은 `baseLength` · `baseArea` · `lengthFactor` · `areaFactor` 로 흩었다 | 근사 |
| G143 | 상수 사이 관계를 선언할 자리가 없다 — `countPerLane` 이 `lengthFactor` 로 나눠 떨어져야 긴 도선 무더기가 정수이고, `baseLength` · `baseLength × lengthFactor` 가 `carrierSpacing` 으로 나눠 떨어져야 알갱이 간격이 선언값과 같다(안 떨어지면 `pitchOf` 가 가장 가까운 간격으로 고친다). 저작자가 한쪽만 바꾸면 경고 없이 무더기가 반올림된다 | 근사 |
| G143 | 선언 사이 관계를 선언할 자리가 없다 — **흐름 빠르기(전류 → 알갱이 속력 배율)가 세는 단계 길이를 따라간다**(`baseSpeed`). 저작자가 세는 단계를 늘이면 알갱이가 느려진다 | 근사 |
| G133 | 캡션 `vars` 가 state 경로만 가리킨다 — 선언 전압 · 배수를 `initialState` 가 글자로 옮긴다 | 근사 |

새 부족: 없다. 꼬리가 직선인 `particleSystem` 의 속도 획은 여기서는 곧은 막대라 그대로 맞았고(ohms-law N1 은 꺾인 길의 일),
막대 밖으로 삐지는 것은 `clip` 으로 막았다.

(1 차: 주장은 섰으나 정지 화면에서 긴 도선의 느림이 꼬리 차로 약함, 긴 막대 이음매가 거의 안 보임 → 꼬리 0.6 초.
2 차: 기준 꼬리가 간격에 닿아 선으로 이어짐, 이음매 여전히 묻힘 → 꼬리 0.5 초, 이음매를 알갱이 위로 · 막대 밖으로 삐지게).

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 무더기 가장 넓은 끝(굵은 도선 12 열)이 경계 안에 든다.
정지 화면에서 긴 도선의 느림은 꼬리 길이로 약하게만 보이지만, 무더기가 같은 말을 하고 움직이는 화면에서는 빠르기가 보인다.
다크 0.8 · 7.6 장의 캡션에서 몇 글자가 옅게 찍힌 것은 글꼴 적재 시점의 촬영 흔적으로 보인다(미확인 — ohms-law 에서도 같은 흔적, 라이트에는 없음).
