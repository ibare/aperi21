# drift-velocity — 표류 속도

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 전자는 도선 속을 초당 0.1 mm 쯤 기어간다는데, 왜 스위치를 켜면 등은 곧바로 켜지는가.

**주장** — 스위치를 닫으면 등은 곧바로 켜지지만 스위치 옆 전자 하나는 거의 제자리다. 등을 켠 것은 전구까지
달려간 전자가 아니라, 이미 도선 전체에 차 있던 전자들이 **한꺼번에** 밀리기 시작한 것이다.

**동사** — 닫는 순간 *등이 켜지고 도선 곳곳의 전자가 한꺼번에 밀리기 시작한다*. 그동안 표시한 전자는
*겨우 조금 나아간다*.

화면에서 일어나는 일 (한 주기 12 초, `timeline` 7 단계):

1. `tag` · `open` — 네모 고리. 왼쪽 변에 전지(긴 판 `+` 위 · 짧은 판 `−` 아래), 아래 변 전지 곁에 스위치
   (레버가 고리 안쪽으로 들려 있다), 오른쪽 변에 전구(빛 없음). 도선 띠 속 전자가 제자리에서 마구 떤다 —
   꼬리가 없다. 스위치 오른쪽 옆 전자 하나에 강조색 고리가 나타난다.
2. `close` — 레버가 내려와 닿는다. 닿는 순간(단계의 끝)에 —
3. `lit` — 전구가 가득 찬 빛으로 켜지고 빛살이 뻗는다. **같은 순간** 고리 네 변의 모든 전자에 밀리는 방향의
   꼬리가 붙고 전자 줄 전체가 천천히 흐른다(아래 변은 오른쪽, 오른쪽 변은 위). `e⁻ →` 표식이 나타난다.
   표시한 전자가 닫힐 때 있던 자리에 강조색 눈금이 남는다.
4. `compare` — 표시한 전자의 고리가 눈금에서 전자 간격 하나에 못 미치게(화면 15 px 쯤) 나아가 있다. 전구는
   도선을 따라 그보다 스무 배 넘게 먼 곳에 있는데 벌써 8 초째 켜져 있다. 눈금 위 이름표 「실제 약 0.1 mm/s」.
5. `release` · `untag` — 레버가 들리는 순간 전구가 꺼지고 꼬리 · 표식이 한꺼번에 사라진다 — 전자는 다시 떨기만
   한다. 표시 고리 · 눈금 · 이름표가 흐려지고 다음 주기에 스위치 옆 전자를 새로 표시한다.

표류 거리는 「지난 주기들의 닫힌 시간 + 이번 주기에 닫힌 뒤 흐른 시간」 × 표류 속력으로 닫힌 식이고
**모든 전자에 같은 값**이다 — 곳곳이 한꺼번에 밀린다는 것이 식 자체에 들어 있다. 주기가 바뀌어도 이어져 튀지
않는다. 열운동 흔들림은 (시드, 전자 번호, 조각 시계)의 값 잡음이라 같은 시각은 같은 화면이다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 전구를 스위치에서 도선을 따라 먼 쪽(오른쪽 변)에 | 「전구까지 달려간 전자가 켠 것이 아니다」 가 요점이다. 표시한 전자와 전구 사이가 멀수록 「겨우 이만큼」 과 「벌써 켜짐」 의 견줌이 선다 |
| 켜짐 · 밀림 · 꼬리 · 표식이 같은 두 경계(`close` 끝 · `release` 시작)를 읽음 | 「곧바로」 와 「한꺼번에」 가 주장의 절반이다. 하나라도 따로 늦으면 신호가 퍼져 가는 것으로 읽힌다 |
| 전자는 도선 띠(옅은 관) 속 알갱이, 열운동은 제자리 흔들림 | 「스위치가 열려 있어도 전자는 이미 도선에 가득하다」 가 전제다. 빈 도선에 전자가 흘러 들어오는 그림이면 주장이 뒤집힌다 |
| 꼬리 = **표류 방향만** (속도 = 표류 속도, 열운동 몫 제외) | 순간 속도(열운동 포함)로 꼬리를 그리면 사방으로 흩어져 「한쪽으로 밀림」 이 사라진다. 꼬리 길이 = 화면 표류 속력 × `trailSeconds`(스테이지 상수). 스위치가 열려 있는 동안은 꼬리가 없다 |
| 강조색 = 「표시한 전자」 한 뜻 | 표시 고리 · 닫힐 때의 자리 눈금. 전자는 primary 한 색, 장치(전지 · 전구 둘레 · 단자 · 빛살 · 부호)는 먹색, 도선 띠는 muted |
| 표시 고리는 닫힌 `trajectory` | `body` 둘레는 가는 선 고정이라(G03) 전자 떼 속에서 묻혔다(1차 촬영) |
| 전구 켜짐 = 빛 채널 원 + 빛살 + 먹색 둘레 · 가위표 | 역할색으로 칠하면 라이트에서 밝음이 어둡게 나온다. 가득 찬 빛이 라이트 미색 바탕에 묻히므로(G92) 빛살 · 둘레로 모양도 말한다. 꺼지면 빛 없음 — 라이트에서 검은 공, 다크에서 빈 동그라미 |
| 스위치 구간의 전자는 레버와 함께 들림 | 틈에 전자가 떠 있으면 「끊겼는데 건너간다」 로 읽힌다 |
| 이름표 「실제 약 {v} mm/s」 — `driftMmPerS` 를 그대로 | 화면의 표류는 `driftExaggeration`(4 배)만큼 과장돼 있다. 실제 빠르기로는 한 주기에 5 px 쯤이라 움직였는지 가릴 수 없다. 배율을 화면에 따로 띄우지 않은 대신 이름표를 「실제」 로 적어, 보이는 움직임이 실제 값 그대로가 아님을 알린다. 배율 · 월드 길이(`worldMm`)는 스테이지 상수다 |
| 열운동 크기는 표현 | 실제 열운동 속력(약 10⁶ m/s)은 표류보다 10¹⁰ 배쯤 빨라 어떤 배율로도 한 화면에 함께 둘 수 없다. `thermalAmplitude` · `thermalRate` 는 「마구 흔들린다」 를 보이는 크기이고 속력의 비를 말하지 않는다. 흔들림의 크기를 표류 한 주기 몫보다 작게 두어 고리의 순이동이 흔들림에 묻히지 않게 했다 |
| 과장 배율 4 | 켜진 8 초 동안 0.32 월드 — 전자 간격(0.39)에 조금 못 미친다. 더 키우면 표시한 전자가 이웃 자리를 넘어 「거의 제자리」 가 흐려지고, 더 줄이면 움직임이 보이지 않는다 |
| 관례 전류 `I` 를 두지 않음 | 이웃 `electric-current` 가 방향 규약을 맡는다. 여기서 화살표를 둘 겹치면 요점(느림 · 동시)이 흐려진다. `e⁻` 는 알갱이가 무엇인지 밝히려 밀리는 동안만 둔다 |
| 두지 않은 것 | 신호(장)가 도선을 따라 퍼지는 파면 — 「곧바로」 를 「빠르게 퍼진다」 로 바꿔 그리면 속도 비교 그림이 되어 요점(이미 차 있는 전자가 함께 밀린다)이 흐려진다. 전류 · 전압 · 수 밀도 값, 식 `I = nqAv` — 문단의 몫. 그리드 · 조작기 — 잴 것은 거리가 아니라 「거의 제자리」 라는 견줌이고, 속력을 끌게 하면 과장 배율의 뜻이 흔들린다 |

## (c) 어휘 부족

| 장부 id | 겪은 것 | 영향 |
|---|---|---|
| G89 | 고리 경로를 따라 흐르는 점 묶음이 없다 — scene 이 전자 번호마다 호길이 · 모서리 · 레버 위 자리를 계산해 `particleSystem` 에 넘긴다 | 근사 |
| G90 | 코어에 회로 기호가 없다 — 전지는 `lineSet` 두 판, 스위치는 도선 띠와 같은 `lineSet` 레버 + 단자 `body`, 전구는 빛 `body` + 가위표 `lineSet` + 둘레 `body` 로 조립한다. plugin-circuit 의존이 없는 스텁이라 `circuitElement` 는 쓰지 않았다(G178 · G184 도 피한다) | 근사 |
| G92 | 가득 찬 빛이 라이트 바탕에 묻힌다 — 빛살과 먹색 둘레를 더했다 | 근사 |
| G03 | `body` 둘레 굵기를 고를 수 없다 — 표시 고리를 닫힌 `trajectory` 로 긋는다 | 근사 |

새 부족

| 부족 | 영향 |
|---|---|
| `particleSystem` 안의 알갱이 하나를 짚는(따라가는) 선언이 없다 — 표시할 전자를 번호로 고르고 그 번호의 흔들린 자리를 scene 이 따로 계산해 고리 `trajectory` 를 얹는다. 표시 대상이 선언이 아니라 코드(가장 가까운 번호 고르기)에 있어 에디터가 「이 알갱이를 표시」 를 편집할 수 없고, 고리와 알갱이가 따로 인스턴스다 | 근사 |

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ drift-velocity` — 라이트 · 다크 각 5 장 (표시 고리를
`trajectory` 로 바꾼 뒤 다시 찍은 것).

| t | 라이트 | 다크 |
|---|---|---|
| 1.2 | 레버 들림, 전구 검은 공, 전자가 도선 띠 속에 흩어져 떨고 꼬리 없음. 스위치 오른쪽 옆 전자에 강조색 고리. 캡션 「스위치가 열려 있다 — …」 — 섬 | 같다. 전구는 흰 둘레 · 가위표의 빈 동그라미, 단자 흰 점 — 섬 |
| 3.0 | 레버 닿음, 전구 켜짐(흰 원 · 먹색 둘레 · 빛살 다섯). 네 변 모든 전자에 진행 방향 꼬리, `e⁻ →` 표식, 표시 전자 자리에 강조색 눈금(고리가 눈금 위). 캡션 「등이 곧바로 켜졌다 — …한꺼번에…」 — 섬 | 같다. 켜진 전구가 밝은 원으로 또렷 — 섬 |
| 6.5 | 켜진 채, 모든 꼬리가 같은 방향. 고리가 눈금에서 조금 오른쪽 — 섬 | 같다 — 섬 |
| 10.0 | 고리가 눈금에서 약 15 px(전자 간격 하나 못 미침). 눈금 위 「실제 약 0.1 mm/s」, 캡션 「그동안 표시한 전자는 … 겨우 이만큼 나아갔다」. 전구는 도선을 따라 훨씬 멀리서 켜져 있다 — 섬 | 같다 — 섬 |
| 11.0 | 레버가 들리는 중, 전구 꺼짐 · 빛살 없음, 꼬리 전부 사라짐, `e⁻` 표식은 흐려지는 중. 캡션 「스위치를 열자 등이 곧바로 꺼지고, …한꺼번에 밀리기를 멈춘다」 — 섬 | 같다 — 섬 |

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 정지 화면에서는 「한꺼번에 밀린다」 를 꼬리가 말하고(열림 시각에는
없고 닫힘 시각에는 네 변 모두에 있다), 움직이는 화면에서는 전자 줄 전체가 같이 흐르는 것이 보인다.
전지 `−` 표식이 글꼴에서 짧은 줄표처럼 찍힌다(표식으로는 읽힌다).
