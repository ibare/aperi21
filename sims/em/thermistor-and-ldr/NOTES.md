# thermistor-and-ldr — 써미스터와 광저항

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 온도나 밝기를 어떻게 전압으로 읽는가.

**주장** — 써미스터(NTC)는 데우면, 광저항(LDR)은 빛을 쬐면 저항이 내려간다. 분압기 한쪽에 두면 그만큼
출력 전압이 올라, 온도 · 밝기를 전압으로 읽는 감지기가 된다.

**동사** — 데우거나 빛을 늘리는 동안 *소자의 저항 막대가 줄고 출력 전압 바늘이 오른다.*

화면에서 일어나는 일 (한 주기 17.6 초, `timeline` 8 단계):

1. 판 둘이 나란히 — 왼쪽 써미스터, 오른쪽 광저항. 판마다 `6 V` · `0 V` 레일 사이에 소자(위, 지그재그 + 표지)와
   고정 저항(아래 지그재그)이 이어지고, 가운데 접점에서 고정 저항 양단을 눈금판(`출력 전압`)이 읽는다. 소자 · 고정 저항
   오른쪽의 굵은 막대 길이가 그 저항이고, 소자 막대 뒤에 표본 최댓값 길이의 점선 윤곽이 깔려 있다.
2. `therm-cold` — 온도계 수은이 `20 °C` 눈금, 써미스터 막대 `10 kΩ`, 바늘 `3.0 V`.
3. `heat` (smooth) — 수은이 `60 °C` 로 오르는 동안 써미스터 막대가 점선 윤곽 안에서 줄고 바늘 · 강조 부채꼴이 자란다.
4. `therm-hot` — 막대 `2.5 kΩ`, 바늘 `4.8 V`. 아래 고정 저항 막대(`10 kΩ`)는 그대로다.
5. `cool` — 수은이 내려가고 막대가 다시 길어지며 바늘이 `3.0 V` 로 돌아간다.
6. `ldr-dark` — 등에서 광저항으로 광선 한 줄, 광선 위 알갱이가 흐른다. 막대 `20 kΩ`, 바늘 `2.0 V`.
7. `brighten` (smooth) — 광선이 가운데 자리부터 한 줄씩 차올라 다섯 줄이 되는 동안 막대가 줄고 바늘이 오른다.
8. `ldr-bright` — 막대 `2 kΩ`, 바늘 `5.0 V`. `dim` 에서 광선이 한 줄로 줄고 막대 · 바늘이 돌아간다.

데워진 몫 · 밝아진 몫은 오름 단계의 진행도에서 내림 단계의 진행도를 빼서 얻는다(`at('heat') − at('cool')`) — 단계 경계를
코드로 가르지 않는다. 광선 위 알갱이 자리도 조각 시계의 함수다. 쌓는 상태가 없어 같은 시각은 같은 화면이다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 판 둘을 **같은 모양**으로 나란히 | 두 소자는 「무엇에 반응하는가」 만 다르고 감지기로 쓰는 방식은 같다. 같은 레일 · 같은 고정 저항 · 같은 전압계라 다른 것이 자극(온도계 · 등)과 소자 표지뿐임이 모양으로 보인다 |
| 한 번에 한 판만 움직인다(써미스터 → 광저항) | 두 판이 함께 움직이면 눈이 어느 쪽 원인과 결과를 이을지 모른다. 쉬는 판은 차가움 · 어두움 표본에 머문다 |
| 저항은 **막대 길이**(두 판 · 두 저항이 같은 잣대 `barPerKohm`) | 「저항이 내려간다」 가 숫자가 아니라 줄어드는 길이로 일어나야 한다(S-piece). 고정 저항 막대가 곁에 있어 「소자 막대가 고정 저항보다 짧아지면 바늘이 가운데를 넘는다」 가 한눈에 견줘진다 — 이 관계는 문장으로 쓰지 않는다 |
| 소자 막대 뒤 점선 윤곽 = 표본 최댓값 길이 | 막대가 줄어든 만큼이 윤곽과의 빈틈으로 남는다 |
| 저항 글자 `{r} kΩ` 는 **표본에 멈췄을 때만** | 선언한 표본 값을 `String` 으로 그대로 쓴다. 옮겨 가는 동안의 저항은 계산값이라 글자로 띄우지 않고 막대만 말한다(S-piece 유효숫자) |
| 바늘 정박값을 표본마다 따로 선언(`outCold` · `outHot` · `outDark` · `outBright`) | 멈춘 바늘 글자(`toFixed`, G144)가 계산값을 줄인 것이 아니라 선언값 그대로이게. 사이 구간은 분압 곡선의 모양(기하 보간한 저항 → 분압)을 두 정박값 사이로 옮겨 쓴다. 정박값은 분압과 맞아야 한다(G143) |
| 표본 사이 저항은 **기하 보간** | NTC 저항은 온도에 지수꼴, LDR 은 조도에 거듭제곱꼴로 변한다. 로그 눈금에서 곧게 이어 곱셈꼴 변화를 흉내 낸다. 광선 수는 곧게 늘어난다 — 조도 ∝ 광선 수로 보면 근사다 |
| 표본 값(10 → 2.5 kΩ, 20 → 2 kΩ) | 실제 LDR 의 어두운 저항은 수백 kΩ ~ MΩ 이지만, 한 잣대의 막대가 판에 들어가도록 줄였다. 저작자가 스테이지 상수로 바꾼다(막대가 넘치면 `barPerKohm` 도 함께 — G143) |
| 출력은 **고정 저항 양단** | 온도 · 밝기가 오르면 바늘도 오른다 — 「감지기의 읽음이 자극을 따라 오른다」 가 곧바로 읽힌다. 소자 양단을 읽으면 반대로 내려가 한 번 더 뒤집어 생각해야 한다 |
| 강조색은 **「출력 전압」 한 뜻** | 전압계의 0 → 바늘 부채꼴에만. 소자 · 고정 저항 막대는 둘 다 먹색 — 같은 종류(저항)라 색으로 가르지 않고 자리와 표지로 가른다. 온도계 수은은 neighbor `temperature-and-resistance` 와 같은 secondary |
| 빛은 **광선 수 · 알갱이**로, 색 없이 | 밝기를 색 · 등의 빛남으로 칠하지 않는다(지시). 광선은 먹색 화살표, 광선마다 알갱이 둘이 등에서 소자로 흐른다. 새 광선은 가운데 자리부터 위아래로 번갈아 차오른다 — 광선이 한 줄일 때도 소자 가운데를 비춘다 |
| 레일(`6 V` · `0 V`)로 전원을 나타냄 | 전지 기호 고리를 두 판에 그리면 가로가 모자라 그림이 작아진다. 감지 회로 도식의 관례대로 공급 레일로 둔다 |
| 이상적 전압계 · 부하 없음 | 출력에 부하를 달면 나눔이 어긋나는 일은 다른 주장이다(physics 머리) |
| 두지 않은 것 | 전류 값 · 옮겨 가는 동안의 저항 · 전압 수치(계산값), 식 `V·R/(R+Rs)`(문단의 몫), 온도 사이 눈금(두 표본만), 조도 단위(lux — 광선 수가 빛의 양이다), 그리드 · 카메라 단추(잴 거리가 없다) |
| 조작기 없음 | 자동 진행이 두 소자의 두 표본을 모두 보인다. 슬라이더로 온도 · 빛을 끌게 하면 step 이 상태를 쌓아야 하고 시간표와 겹친다 — 독자가 직접 해 봐야 새로 알게 되는 것이 없다 |
| 캡션 | 단계의 일만 — 멈춘 단계는 「막대가 길다 / 짧아졌다, 바늘은 낮은 / 높은 자리」, 움직이는 단계는 「데운다 · 빛을 늘린다 — 막대가 줄고 바늘이 오른다」. 값(10 kΩ · 4.8 V)을 문안에 박지 않는다 |

## (c) 어휘 부족

| 장부 id | 겪은 것 | 영향 |
|---|---|---|
| G204 | plugin-circuit `circuitElement` 에 써미스터 · LDR 소자가 없다 — 지그재그 `lineSet` 위에 써미스터는 사선 + 발(`lineSet`), 광저항은 속 빈 동그라미(`body`)를 얹는다. 전압계에도 바늘이 없어 `scale` dial 로 대신한다 | 근사 |
| G90 | 코어에 회로 기호가 없다 — 저항 지그재그 · 레일 · 도선을 `lineSet` 으로 긋는다. 등 기호도 `body` 동그라미 + 가위표 `lineSet` | 근사 |
| G144 | `scale` dial 이 지금 값을 `toFixed(digits)` 로 늘 쓴다 — 멈춘 자리에서는 선언 정박값과 같지만(3.0 · 4.8 · 2.0 · 5.0 V), **옮겨 가는 동안은 반올림한 중간값(4.1 V · 3.9 V …)이 뜬다.** 눈금 숫자도 같은 자릿수로 쓰여 `6` 이 `6.0` 이 되고, 글자가 반지름 비율로 작다 | 근사 |
| G143 | 상수 사이 관계를 선언할 자리가 없다 — 바늘 정박값 넷이 레일 전압 · 고정 저항 · 표본 저항의 분압과 같아야 하고, 표본 최댓값 × `barPerKohm` 이 막대 자리(전압계 · 이름표와 겹치지 않는 길이)를 정하며, `meterDigits` 가 정박값 소수 자릿수와 맞아야 한다. 어기면 경고 없이 바늘이 분압과 어긋나거나 막대가 넘친다 | 근사 |
| G105 | 표본 목록을 선언할 수 없다 — 두 소자 × 두 표본을 이름 여덟(`thermRCold` · `outHot` …)으로 흩었다. 표본을 셋으로 늘리려면 코드(단계 이름 · `thermistorNow`)를 고친다 | 근사 |
| G13 | 시간표 단계에 값을 실을 수 없다 — 어느 단계가 어느 소자를 움직이는지를 단계 이름(`heat` · `brighten` …)과 physics 식으로 잇는다 | 근사 |
| G89 | 경로를 따라 흐르는 점 묶음이 없다 — 광선 위 알갱이 자리를 scene 이 광선마다 계산해 `particleSystem` 에 넘긴다 | 근사 |

새 부족: 없다. 저항 막대는 `lineSet` + 점선 `trajectory`, 온도계는 `region` · `body` · `lineSet` · `readout`, 광선은
`vector`(`opacity` 로 한 줄씩 차오름)로 됐다.

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ thermistor-and-ldr` — 라이트 · 다크 각 5 장.
첫 촬영에서 광선 일곱 줄이 광저항 왼쪽 좁은 호에 몰려 셀 수 없었다 — 등을 멀리 · 낮게 옮기고 닿는 호를 넓히고
밝을 때 광선을 다섯 줄로, 전압계 반지름을 1.0 → 1.1 로 올려 다시 찍었다.
