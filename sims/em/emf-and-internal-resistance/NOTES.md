# emf-and-internal-resistance — 기전력과 내부 저항

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 전지에서 전류를 많이 끌어 쓰면 단자 전압은 어떻게 되는가.

**주장** — 전지는 기전력 ε 와 작은 내부 저항 r 의 묶음이라, 바깥 저항을 줄여 전류를 많이 끌어 쓸수록
r 에서 내려가는 몫이 커져 단자 전압이 내려간다. V–I 평면의 점들은 ε 에서 출발해 내려가는 한 직선 위에 놓인다.

**동사** — 바깥 저항이 줄 때마다 **흐름이 빨라지고, 사선 몫(Ir)이 자라며 단자 전압(채움)과 점이 내려간다.**

화면에서 일어나는 일 (한 주기 15.4 초, `timeline` 7 단계):

1. `open` — 점선 상자(전지) 안에 ε 칸과 r 지그재그가 한 줄로 있고, 바깥에 `R = 5 Ω` 이 끼워져 있다. 스위치가
   들려 있어 전자 알갱이는 멈춰 있다. 왼쪽 전위 막대는 ε 점선 테두리까지 강조색으로 가득 차고, 평면에는
   세로축 위 ε 높이에 강조색 점 하나.
2. `load1` — 스위치가 닫혀 5 Ω 으로 전자가 흐른다(관례 전류와 반대, 회로 안쪽에 `← e⁻` · `I →` 표식 한 번).
   막대 꼭대기에 얇은 사선 몫 `Ir` 이 생기고 채움 `V` 가 그만큼 낮아진다. 평면의 지금 점도 오른쪽 아래로 옮겨
   가고, 점에서 ε 선까지 같은 사선 기둥 `Ir` 이 선다. 지난 점(ε)은 먹색으로 남는다.
3. `load2` · `load3` — 바깥 저항이 `2 Ω` · `1 Ω` 으로 줄며 지그재그가 짧아진다. 흐름이 빨라지고(꼬리가 길어짐)
   사선 몫이 자라고 채움과 점이 내려간다. 1 Ω 에서 바깥 R 과 내부 r 의 지그재그가 같은 크기다 — 막대가 반반.
4. `line` — ε 절편에서 직선이 뻗어 점 넷을 모두 지나 가로축 끝까지 간다.
5. `read` · `fade` — 직선을 읽고, 점과 직선이 흐려지고, 스위치가 다시 열린다.

전류 I = ε/(R + r), 단자 전압 V = ε − Ir 은 physics 가 스테이지 상수(ε · r · 부하 셋)에서 계산한다. 알갱이 자리는
단계마다 일정한 속력을 곧바로 적분한 닫힌 식이다(`flowDistance`) — 같은 시각은 언제나 같은 화면이다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 전지를 점선 상자 하나로, 안에 ε 칸과 r 을 한 줄로 | 「전지 = ε 와 r 의 묶음」 이 모양으로 보인다. 상자 끝의 두 점이 단자다 — 단자 전압이 어디서 재는 값인지 밝힌다 |
| 전위 막대 — 높이 ε(점선 테두리, 늘 같음) 중 V 채움 + Ir 사선 | 「같은 ε 를 둘로 나눈다」 가 한눈에. Ir 은 같은 ε 의 다른 몫이라 색이 아니라 **결**(`region.fill: 'hatch'`)로 갈랐다(S-piece — 색으로 설명하지 않음) |
| 막대와 평면이 같은 볼트 배율 · 같은 바닥 높이 | 막대 윗변(ε)과 평면의 ε 점선이 같은 높이, 막대의 채움 높이와 지금 점의 높이가 같다 — 두 그림이 같은 양이라는 것이 배치로 읽힌다 |
| 평면의 지금 점 위에 막대와 같은 사선 기둥 `Ir` | 직선이 ε 에서 내려간 거리가 곧 전지 안에서 잃은 몫이라는 것을 같은 결로 잇는다 |
| 강조색 = 「지금 단자 전압」 한 뜻 | 막대 채움과 평면의 지금 점(같은 양). 지난 점 · 직선 · 저항 · 전지 · 스위치 · Ir 결은 먹색, 도선 · 축 · 상자 · 이름표는 muted, 전자는 primary |
| 바깥 저항을 **줄여** 전류를 늘림(부하 5 · 2 · 1 Ω) | 「끌어 쓴다」 의 실제 모습이 부하를 더 무겁게(저항을 작게) 거는 것이다. 지그재그 길이 ∝ 저항이라 줄어드는 것이 모양으로 보인다 |
| 두 저항이 같은 배율 · 같은 톱니 간격 | 첫 촬영에서 1 Ω 인 R 은 톱니 하나, 같은 1 Ω 인 r 은 톱니 넷이라 어긋났다 → `resistorWorldPerOhm` 하나로 두 지그재그를 긋는다. `load3` 에서 R 과 r 이 같은 크기로 보이고 막대가 반반이 된다 |
| 첫 단계가 스위치 열림 | I = 0 이면 V = ε — 직선의 절편이 무엇인지 점 하나로 먼저 보인다. 열린 동안 끊긴 틈 위의 알갱이는 두지 않았다 |
| 전류 = 알갱이 **속력**, 간격은 모든 단계에서 같음 | ohms-law 와 같은 약속. 꼬리 = 속력 × `trailSeconds`(0.16 초) — 가장 빠른 3 A 꼬리가 간격을 넘지 않게. 첫 촬영에서 0.2 초 · 배율 0.9 는 도선이 붉은 한 줄로 이어 보여 배율 0.6 으로 낮췄다 |
| 캡션 값은 선언값을 state 로 옮겨 끼움 | `{e}` · `{r1}` · `{r2}` · `{r3}` — `initialState` 가 `String(값)` 으로 옮긴다(G133 우회). 「반」 · 「두 배」 처럼 상수 관계에 기대는 말은 쓰지 않았다 |
| 두지 않은 것 | 전류 값(A) · 단자 전압 값(V) — 계산값이라 띄우면 유효숫자를 줄이게 되고, 정박값으로 선언하면 ε/(R+r) 와 이중 선언이 된다(G143). 값은 막대 높이 · 점 높이 · 흐름 빠르기가 말한다. 가로축 눈금 수 — 같은 이유. 기울기 = −r · 식 V = ε − Ir — 문단의 몫(`Ir` · `ε` 는 도식 옆 표식 한 조각까지만). 전압계(`scale` dial) — 값 글자를 `toFixed` 로 늘 쓴다(G144). `circuitElement` — G178. 조작기 · 그리드 — 자동 진행으로 주장을 마친다 |

## (c) 어휘 부족

| 장부 id | 겪은 것 | 영향 |
|---|---|---|
| G90 | 코어에 회로 기호 · 스위치가 없다 — 저항은 `trajectory` 지그재그, ε 칸은 `lineSet` 긴 판 · 짧은 판, 스위치는 `trajectory` 막대 + `body` 받침점, 전지 상자는 닫힌 점선 `trajectory` | 근사 |
| G178 | plugin-circuit `circuitElement` battery 는 리드선과 기호 사이가 비어 회로가 끊겨 보인다 — 쓰지 않았다. 내부 저항을 품은 전지 기호도 없다 | 근사 |
| G89 | 경로를 따라 흐르는 점 묶음이 없다 — scene 이 폐곡선 호길이로 알갱이 자리와 길 따라가는 꼬리를 계산한다(ohms-law N1 과 같은 우회). 바깥 저항 지그재그 길이가 단계마다 바뀌어 고리 둘레가 바뀌므로, 저항을 바꿔 끼우는 순간 흐른 거리를 새 둘레로 접으며 알갱이가 한 번 자리를 바꾼다 | 근사 |
| G47 | 그래프 축 어휘가 없다 — V–I 평면을 `vector`(축) · `trajectory`(ε 점선 · 직선) · `body`(점) · `region`(Ir 기둥) · `readout`(축 이름 · ε · 원점 · 점 이름표)으로 월드에 조립한다 | 근사 |
| G13 | 시간표 단계에 값을 실을 수 없다 — 「`load2` 부터 부하 2」 라는 단계 → 부하 대응이 physics `levelAt` 의 코드로 남는다 | 근사 |
| G01 | `step` 이 시간표를 받지 못한다 — scene 이 단계마다 (속력 × 머문 시간)을 시간표에서 다시 적분한다 | 근사 |
| G105 | 부하 목록을 스테이지 상수로 선언할 수 없다 — `load1` · `load2` · `load3` 으로 흩었고 단계 수(셋)는 코드에 있다 | 근사 |
| G143 | 지그재그 길이 배율과 부하 목록 사이 관계(가장 큰 부하가 위 변 안에 들어가야 함)를 선언할 자리가 없다 — 저작자가 부하를 키우면 지그재그가 모서리를 넘는다 | 근사 |
| G133 | 캡션 `vars` 가 state 경로만 가리킨다 — ε · 부하 선언값을 `initialState` 가 글자로 옮긴다 | 근사 |

새 부족: 없다. 막대(ε 테두리 · V 채움 · Ir 사선)는 `region` 의 `fill: 'hatch'` · `opaque` 와 닫힌 점선 `trajectory` 로 그대로 됐다.
