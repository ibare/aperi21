# temperature-and-resistance — 온도와 저항

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 도선을 데우면 저항은 커지는가, 작아지는가.

**주장** — 같은 전압을 건 금속과 반도체를 함께 데우면, 금속은 전자 수가 그대로인 채 크게 떨리는
원자에 막혀 흐름이 줄고(저항 증가), 반도체는 열이 풀어 준 e⁻ · h⁺ 로 나르개가 늘어 흐름이 는다(저항 감소).

**동사** — 데우는 동안 금속의 흐름 막대는 점선 밑으로 **줄고**, 반도체의 흐름 막대는 쌍이 생길 때마다
점선 너머로 **는다.**

화면에서 일어나는 일:

1. 위 전지(`3 V`, 긴 판 + 가 오른쪽)의 두 레일 사이에 같은 모양 막대 둘 — `금속` · `반도체`. 두 막대가
   같은 레일에 걸려 같은 전압을 받는다는 것이 배선 모양으로 보인다. 왼쪽 밖에 온도계(눈금 `20 °C` ·
   `220 °C` 둘뿐), 오른쪽 레일 너머에 막대마다 흐름 막대 `I` 와 차가울 때 길이의 점선 윤곽.
2. 막대 안에 격자 원자가 세 줄로 제자리에서 떤다. 금속은 원자 줄 사이 두 레인에 전자가 가득 흐르고
   (`e⁻ →`), 반도체에는 e⁻ 셋과 속 빈 h⁺ 셋만 서로 반대로 흐른다(`e⁻ →` · `h⁺ ←`).
3. 데움 — 온도계 수은이 오르고 두 막대의 원자 떨림이 함께 커진다. 금속 전자는 수가 그대로인 채 느려지고
   (꼬리가 짧아진다) 떨리는 격자에 부딪혀 위아래로 흔들린다. 반도체에는 격자 자리 하나에서 e⁻ · h⁺ 쌍이
   생겨 반대로 갈라져 흐른다. 금속 흐름 막대가 점선 밑으로 줄고, 반도체 흐름 막대는 쌍이 생길 때마다
   한 칸씩 점선 너머로 는다.
4. 뜨거움 — 수은이 `220 °C`. 금속 흐름 막대는 점선의 1/(1 + αΔT) ≈ 0.56, 반도체는 점선의 4 배(쌍 3 → 12).
5. 식힘 — 수은이 내려가고 떨림이 줄며 반도체 쌍이 생긴 역순으로 사라지고(재결합) 두 흐름 막대가 점선으로 돌아간다.

모든 자리는 (시드, 조각 시계)의 함수다 — 같은 시각은 언제나 같은 화면이다. 금속 전자가 흐른 거리는
빠르기 1/(1 + αΔT(t)) 의 시간 적분인데, 데움 · 식힘이 선형이라 로그의 닫힌 식으로 얻고 주기마다 한 주기 적분을
더해 주기 경계에서도 튀지 않는다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 두 막대를 한 전지의 두 레일에 나란히, 같은 모양 · 같은 온도계 | 「같은 전압 · 같은 온도, 다른 것은 재료뿐」 을 배선과 한 온도계로 보인다. 막대마다 온도계를 두면 「같은 온도인가」 를 읽어야 한다 |
| 전류는 **흐름 막대**(각 막대의 차가울 때 = 점선 길이) | 주장은 「오른다 · 내린다」 의 방향이다. 금속과 반도체의 실제 전류는 몇 자릿수 달라 한 잣대에 두면 반도체 막대가 보이지 않는다 — 막대마다 제 차가울 때에 견준다. 그래서 두 흐름 막대의 길이를 **서로** 견주지 않는다. 점선의 뜻은 뜨거움 캡션이 말한다 |
| 금속: 나르개 수 고정, 빠르기 ∝ 1/(1 + αΔT) | R(T) = R₀(1 + αΔT), 같은 전압 → I ∝ 1/R, 나르개 수가 같으니 빠르기가 그만큼 준다. α 는 구리 값 0.0039 /°C 를 스테이지 상수로 |
| 금속 전자의 위아래 흔들림(`wobbleRatio` × 떨림 폭) | 「더 자주 부딪힌다」 를 느려짐 하나로만 보이면 원인이 안 보인다. 실제 충돌 궤적(무작위 산란)은 나르개 수천 개의 통계라 흉내 내지 않고, 흔들림으로 「떨리는 격자에 막힌다」 만 암시한다 |
| 반도체: 빠르기 고정, 쌍 수 = n₀(n₁/n₀)^x (x = 데워진 정도) | 실제 반도체는 이동도도 온도에 따라 조금 준다. 그러나 나르개 수의 지수 증가가 압도하고, 빠르기까지 바꾸면 「수가 는다」 는 요점이 흐려진다. 쌍 수 3 → 12(4 배)는 표시값 — 실제 진성 농도비는 200 °C 올리면 수백~수천 배라 그대로면 막대가 나르개로 메워진다 |
| 쌍은 시드로 고른 격자 자리에서 **생겨** e⁻ 는 오른쪽, h⁺ 는 왼쪽 레인으로 갈라진다 | 「열이 원자에 묶인 전자를 풀어 준다」 를 생기는 순간의 모양으로 보인다. 쌍 k 가 생기는 시각은 x 가 문턱 x_k 를 넘는 순간이고, 데움 단계가 선형이라 `start('heat') + x_k · duration('heat')` 다 — 알갱이마다 다른 시각이라 단계로 풀 수 없다 ((c) 참고) |
| 전자 · 양공은 같은 primary, 채움(찬 점 · 속 빈 원) · 표식(`e⁻` · `h⁺`) · 흐르는 방향으로 가름 | 색으로 설명하지 않는다 (S-piece). 둘 다 「나르개」 라는 같은 역할이다 |
| 격자 원자는 muted medium, 나르개보다 크게 | 1 차 촬영에서 원자가 strong 4.5 px 라 나르개를 덮었다. 옅고 작게 하고 레인을 원자 줄 사이(원자 줄 간격 0.26, 레인 ±0.13)로 옮겼다 |
| 떨림 폭은 표시값(0.012 → 0.055 월드), 과장이다 | 실제 열진동 진폭은 원자 간격의 몇 % 이고 절대온도의 제곱근을 따라 293 K → 493 K 에서 1.3 배뿐이다. 차이를 **보이게** 하려고 차가울 때 · 데운 뒤 폭을 스테이지 상수로 선언했다. 화면에 과장을 알리지 않는다 — 떨림은 원인의 그림이지 잴 대상이 아니다 |
| 강조색 = 「지금 흐름」(흐름 막대) 한 뜻 | 온도계 수은은 secondary, 나르개 primary, 원자 muted |
| 캡션 값은 선언값을 state 로 옮겨 끼움 | `{v}` · `{tc}` · `{th}` — `initialState` 가 `String(값)` 으로 옮긴다(G133 우회). 온도계 눈금 이름표는 `'{t} °C'` 문안 키 + `vars` |
| 캡션은 단계의 일만 | 데움 · 식힘 캡션은 「데운다」 · 「식힌다」 만. 흐름이 줄고 느는 결과는 뜨거움 단계에서 건다. 1 차 촬영 뒤 뜨거움 캡션을 줄이고 `e⁻ · h⁺` 를 낱말 「전자 · 양공」 으로 바꿨다 — 캡션 글꼴에서 위첨자 기호 간격이 벌어졌다 |
| 두지 않은 것 | **저항 · 전류 수(Ω · A)** — 계산값이라 띄우면 유효숫자를 줄이게 되고, 방향이 요점이다. **α 값 · 식 `R = R₀(1 + αΔT)`** — 문단의 몫. **지금 온도 글자** — 수은 높이와 두 눈금이 말한다. 가운데 온도를 띄우면 계산값을 줄여야 한다. **띠 그림(가전자띠 · 전도띠)** — band-theory 의 몫. **전류계 바늘** — `scale` dial 이 값 글자를 늘 쓴다(G144). **`circuitElement`** — 전지 기호가 리드선과 떨어져 보인다(G178). **조작기 · 그리드** — 자동 진행으로 주장을 마친다 (`controllers.ts`). **길이 · 굵기 · 전압 바꾸기** — resistance-and-geometry · ohms-law 의 몫 |

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ temperature-and-resistance` — 라이트 · 다크 각 4 장. 두 번 찍었다
(1 차: 주장은 섰으나 격자 원자가 크고 짙어 나르개가 묻힘, 뜨거움 캡션이 길고 `e⁻ · h⁺` 위첨자 간격이 벌어짐 →
막대를 두껍게 · 원자를 작고 옅게 · 레인을 원자 줄 사이로, 흐름 막대 단위 0.8 → 0.65, 캡션을 줄이고 낱말로).

| t | 라이트 | 다크 |
|---|---|---|
| 1.0 | 전지 `3 V`, 막대 둘 `금속` · `반도체`, 온도계 수은이 `20 °C` 눈금. 금속 두 레인에 전자가 가득, 반도체에 e⁻ 셋 · 속 빈 h⁺ 셋. 흐름 막대 둘이 점선과 같은 길이. 캡션 「두 막대에 같은 3 V, 20 °C — …」 — 섬 | 같다. 막대 윤곽 · 전지 · 이름표가 흰색으로 뒤집혀 또렷, 수은은 밝은 파랑 — 섬 |
| 3.6 | 수은이 두 눈금 사이, 원자 떨림이 커짐. 금속 흐름 막대가 점선보다 짧고(≈ 0.72), 반도체에는 쌍이 여섯으로 늘어 흐름 막대가 점선의 두 배. 캡션 「두 막대를 20 °C 에서 220 °C 로 함께 데운다」 — 섬 | 같다 — 섬 |

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 가장 긴 흐름 막대(반도체 4 배)가 경계 안에 든다.
