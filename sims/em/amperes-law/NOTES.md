# amperes-law — 제작 기록

엔진 위에서 바로 만든 조각이다 — 자유 구현 원본이 없다. 자유 렌더(`Bundle.renderers`)를 쓰지 않는다.

## (a) 답하는 질문과 동사

**질문** — 전류를 감싸고 한 바퀴 돌면서 B 의 길 방향 몫을 모두 더하면 무엇이 남는가.

**주장** — 전류를 감싸는 닫힌 길을 따라 B 의 접선 몫을 모두 더하면 길의 모양과 상관없이 감싼 전류에만 비례한다(∮B·dl = μ₀I).
원과 찌그러진 고리는 같은 합에 닿고, 전류를 감싸지 않은 고리는 0 으로 돌아온다.

**동사: 걸으며 쌓은 막대가 모양이 달라도 같은 기준선에 닿고, 감싸지 않은 길에서는 올랐다가 0 으로 내려온다.** 화면에서 이렇게 일어난다.

- 왼쪽에 전선 ⊙(`I`, 화면 밖으로 흐른다). 오른쪽에 막대 셋과 기준선 둘(`0` 실선 · `μ₀I` 점선), 막대마다 아래에 어느 고리인지
  보이는 작은 그림(전선 점 + 고리).
- `walk-circle` — 원을 반시계로 걷는다. 걸어온 쪽이 굵어지고, 걷는 점(강조색)에서 B 화살표(`primary`)와 그 길 방향 몫(강조색,
  B 아래에 넓게 깔림)이 나온다. 원에서는 둘이 겹친다 — B 가 통째로 길 방향이다. 첫 막대 꼭대기에서 강조색 토막이 자라고, 다 자란
  토막은 같은 높이의 눈금으로 쌓인다.
- `close-circle` — 막대 꼭대기가 `μ₀I` 점선에 닿아 있다.
- `walk-squash` — 원은 옅게 남고 찌그러진 고리를 걷는다. 같은 길이의 토막인데 전선 가까운 토막은 크게, 먼 토막은 작게 쌓여
  눈금 간격이 고르지 않다. B 와 길 방향 몫이 어긋나 둘 사이에 점선 수선이 보인다.
- `close-squash` — 둘째 막대도 같은 `μ₀I` 점선에 닿는다.
- `walk-outside` — 전선 오른쪽의 감싸지 않은 고리를 아래에서 반시계로 걷는다. 바깥 변을 오르는 동안 쌓이고, 전선 쪽 변을 내려올
  때는 길 방향 몫이 걷는 쪽과 반대가 되어 막대가 줄어든다. 올랐던 최고치에서 지금 합까지는 빗금 칸(덜어진 몫)으로 남는다.
- `close-outside` · `hold` — 셋째 막대는 0 으로 돌아와 빗금 칸만 남았다. 세 막대가 나란히 — 둘은 같은 점선, 하나는 0.
- `fade` — 흐려진 뒤 새 주기.

합은 수치 적분이 아니라 B·dl = (μ₀I/2π) dφ 로 센다 — 걸어온 길의 합이 전선에서 본 방위각이 돈 양에 비례한다. 그래서 감싼 두
길의 막대가 기준선에 **정확히** 닿고 감싸지 않은 길은 정확히 0 이다(표본 오차가 막대 끝을 흔들지 않는다). 모든 모양은 시각과
스테이지 상수의 함수라 쌓는 상태가 없다(`step` 은 항등, state 는 비어 있다).

## (b) 화면 구성의 결정

**둔 것**

- **세 길을 차례로, 같은 시작점(맨 아래)에서 같은 방향(반시계)으로.** 비교가 주장이라 조건을 모양 하나만 다르게 둔다. 걷는 빠르기는
  길이 비율로 고르다 — 그래야 「가까이선 빨리 쌓인다」 가 B 의 크기로 읽힌다(점이 빨라서가 아니라).
- **막대는 토막으로 쌓인다.** 한 바퀴를 같은 길이 16 토막으로 나누고(`segments`), 고리 위에 경계 점을, 막대 안에 눈금을 둔다. 원은
  토막이 모두 같고 찌그러진 고리는 제각각인데 합은 같다 — 눈금 간격이 그 대비를 말한다.
- **B 와 그 길 방향 몫을 따로.** 몫(강조색, 넓게)을 B 아래에 깔고 B 끝에서 몫 끝으로 점선 수선을 내린다. 원에서는 둘이 겹쳐 수선이
  없고, 찌그러진 · 밖 고리에서는 갈라진다. 장부 G02 대로 짧은 화살표 촉이 약하다.
- **덜어진 몫을 빗금 칸으로 남긴다.** 첫 촬영에서 밖 고리의 덜어지는 토막이 3 px 로 보이지 않았다. 올랐던 최고치 ~ 지금 합을 빗금으로
  두니 「올랐다가 0 으로 돌아왔다」 가 끝난 뒤에도 읽힌다. 빗금은 `primary`(같은 양, 덜어진 것) — 강조색은 지금 토막 한 뜻에만.
- **막대 아래 작은 고리 그림** — 글자 이름표 대신. 어느 막대가 어느 길인지 모양으로 잇고, 걷는 고리의 그림만 짙다.
- 상수(전류 · 장 → 화살표 배율 · 합 → 막대 배율 · 토막 수 · 시작 각 · 고리 셋의 모양 11개)는 모두 `stages[].constants`. 표시 배율
  `fieldToLength` 는 상한이 없다 — 가장 가까운 자리(r ≈ 0.52)에서도 화살표가 1.1 월드를 넘지 않게 골라, 비례가 끊긴 화살표가 없다.
- 캔버스 400 px — 360 에서는 세로에 묶여 원 반지름이 78 px, 먼 자리 B 가 20 px 로 짧았다.

**두지 않은 것**

- **합 · B · r 의 수치, μ₀ 값, 식** — 캡션과 화면에 식을 쓰지 않는다(S-piece). 합은 막대 높이와 기준선으로만 말한다. `showMagnitude`
  를 켜지 않았다. 그래서 캡션에 끼울 값도 없어 `caption.vars` 를 쓰지 않았다.
- **장선(전선 둘레 동심원)** — 원 길과 모양이 같아 「길 = 장선」 으로 오독된다. B 의 방향은 걷는 점의 화살표가 보인다.
- **길을 거꾸로 도는 경우(합 −μ₀I) · 전류 둘** — 한 조각 한 주장. 방향 부호와 전류 합은 다른 조각의 몫이다.
- **조작기** — 세 모양을 자동 진행이 모두 걷는다. 고리를 끌게 하면 같은 비교를 손으로 한 번 더 하는 것이 된다.
- 그리드 · 카메라 단추(잴 것은 거리가 아니라 막대가 기준선에 닿는가).
- 이웃 `current-magnetic-field`(나침반 · 1/r)와 겹치지 않게 나침반 · 지구장을 두지 않았다. 이웃 `biot-savart-law` 가 머리-꼬리 사슬로
  **방향이 다른 몫의 합**을 보였다면, 이 조각은 **길을 따라 한 성분을 쌓은 합**을 막대로 보인다.
- 짝 조각 `gausss-law` 는 아직 스텁이라(이 조각을 만드는 동안 src · NOTES 가 비어 있었다) 모양을 맞춰 보지 못했다.

### 새 부족

없다. 닫힌 길 위 선적분의 누적은 조각의 물리 계산(방위각 풀기)이고, 쌓는 막대는 G84 · G197 이 적고 있는 모자람이다.

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ amperes-law` 로 찍은 라이트 · 다크를 직접 열어 보았다. 세 번 찍었다 —
첫 촬영은 그림이 작고 B 가 짧았고(가로 여백 축소 · 장 배율 2.2→3.4), 둘째는 세로에 묶였고 밖 고리의 덜어지는 토막이 보이지 않았다
(캔버스 400 · 세로 경계 축소 · 빗금 칸 추가). 아래는 셋째 촬영의 판정이다.

| `?t=` | 라이트 | 다크 | 판정 |
| --- | --- | --- | --- |
| 1.3 | 원의 왼쪽을 내려오는 중. 걸어온 쪽이 굵고 B 와 강조색 몫이 원에 접해 겹친다. 첫 막대가 고른 눈금으로 3/4 쯤, 꼭대기에 강조색 토막 | 같음. 막대 눈금이 밝은 선, 뒤집힘 없음 | 선다 |
| 3.8 | 원 한 바퀴 — 굵은 원, 첫 막대 꼭대기가 `μ₀I` 점선에 닿음. 캡션 「한 바퀴를 돌자」 | 같음 | 선다 |
| 7.8 | 찌그러진 고리 위쪽을 걷는 중, 원은 옅게. 둘째 막대 눈금 간격이 고르지 않고 강조색 토막이 크다. B 와 몫이 갈라져 수선이 보인다 | 같음 | 선다 |
| 17.4 | 밖 고리의 전선 쪽 변을 내려오는 중. 첫째 · 둘째 막대 모두 점선에, 셋째 막대는 낮은 막대 위에 빗금 칸 | 같음. 빗금 칸이 짙은 바탕에서도 보인다 | 선다 — 다만 B 가 짧아(약 20 px) 몫의 방향은 막대 쪽이 더 잘 말한다 |
| 21.8 | 세 막대 나란히 — 둘이 같은 점선, 셋째는 빗금 칸만(0). 고리 셋이 옅게 | 같음 | 선다 — 동사가 일어난다 |

글자가 화면 밖으로 나가거나 서로 겹치는 곳은 없다. 7.8 에서 `B` 이름표가 몫 화살표 가까이 붙어 작게 읽힌다(G17). 캡션 몇 글자가
옅게 찍힌 촬영본이 있다(라이트 17.4 · 다크 21.8) — 이웃 `biot-savart-law` 에도 적힌 것과 같은 모습이고 원인은 **미확인**이다.
