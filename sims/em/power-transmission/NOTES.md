# power-transmission — 송전

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다. 자유 렌더(`Bundle.renderers`)는 쓰지 않았다.

쓴 어휘 — `body`(발전소 · 마을 `custom` 외형, 변압기 기호 겹친 두 원 `fill: 'none'` · `outline: 'role'`) ·
`trajectory`(송전선 구간, 보낸 전력 기준 점선) · `particleSystem`(선 위 전자 알갱이) · `vector`(전류 화살표 `I` · 전자 방향 `e⁻`) ·
`stream`(선에서 오르는 열 김) · `region`(열 막대 · 마을 막대, `opaque`) · `lineSet`(막대 바닥) ·
`readout`(전압 `{v} kV` · `{p} kW` · 배수 `1/{n}` · 도식 이름) · `timeline` 7단계 · `caption` 슬롯(`vars`) · `startAt` ·
`drawOrder: 'scene'`.

## (a) 답하는 질문과 동사

**질문** — 같은 전력을 먼 마을로 보낼 때 왜 전압을 올리는가.

**주장** — 같은 전력(100 kW)을 같은 송전선(5 Ω)으로 보낼 때 전압을 1 kV 에서 10 kV 로 올리면 선의 전류가
1/10 이 되고, 선에서 열로 새는 전력은 1/100 로 줄어 마을에는 보낸 전력이 거의 그대로 닿는다.

**동사(「선에서 새는 열이 준다」)가 화면에서 일어나는 방식** — 발전소 → 긴 송전선 → 마을 을 위아래 두 줄로 둔다.
위 줄은 1 kV 그대로, 아래 줄은 승압 변압기로 10 kV 로 올려 보내고 마을 앞 강압 변압기로 내린다.

- 주기 내내 — 위 선에서는 강조색 열 김이 다섯 줄기로 쏟아지고, 아래 선에서는 김이 거의 오르지 않는다(김 빈도가
  선 손실에 비례해 1/100 이다 — 수십 초에 한 번 한 올). 위 선 전자 알갱이(`e⁻`)는 촘촘하고 아래 선은 열 배 성기다. 알갱이는 관례 전류 `I` 와 반대로 마을에서 발전소 쪽으로 간다.
1. `flow` — 두 줄이 흐른다. 막대 자리에는 바닥선과 `100 kW` 점선(보낸 전력)만 있다.
2. `current` — 아래 줄 짧은 `I` 화살표 곁에 `1/10` 이 스며든다. 위 `I` 는 열 배 길다.
3. `leak` — 두 줄의 열 막대가 차오른다. 위는 점선의 절반 높이까지, 아래는 바닥에 붙은 채다.
4. `leakNote` — 아래 열 막대 자리 위에 강조색 `1/100` 이 스며든다.
5. `arrive` — 마을 막대가 차오른다. 위는 열 막대와 같은 높이(보낸 전력의 절반), 아래는 점선에 거의 붙는다.
6. `hold` — 그대로 견준다.
7. `clear` — 막대 · 배수 글자가 걷히고 다음 주기로.

물리 — I(A) = P(kW)/V(kV), 선 손실(kW) = I²R/1000, 마을 = P − 손실. 위 100 A · 50 kW, 아래 10 A · 0.5 kW.
모든 것이 조각 시계의 닫힌 식이라 쌓는 상태가 없다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 두 줄을 위아래로 나란히, 전력 · 선 저항은 같게 | 바뀌는 것이 전압 하나뿐이어야 손실 차이가 전압 때문이라는 것이 선다. 전압을 끄는 조작기로 한 줄을 바꾸면 견줌이 움직임으로 바뀐다 |
| 위 줄 손실을 보낸 전력의 절반으로 크게 잡음(1 kV · 100 kW · 5 Ω) | 실제 배전보다 과장이다. 아래 줄 손실(0.5 %)과의 차이를 한 화면 배율로 보이려면 위가 커야 한다. 화면에 알리지 않는다 — 주장은 두 줄의 비다 |
| 열 막대와 마을 막대를 **같은 배율 · 같은 바닥**에, 보낸 전력 점선을 위에 | 「샌 것 + 닿은 것 = 보낸 것」 이 두 막대 높이의 합으로 보인다. 위 줄은 두 막대가 같은 높이라 「절반이 샜다」 가 말 없이 읽힌다 |
| 아래 줄 열 막대는 정직하게 0.5 kW 높이(1 px 미만) | 「거의 사라진다」 가 주장이다. 키우면 거짓말이다. 빈 자리가 빠진 것으로 읽히지 않게 막대 바닥선을 두고, 그 위에 `1/100` 을 띄운다 |
| 배수 글자 `1/10` · `1/100` 은 **표시 정박값 스테이지 상수**(`voltageFactor` · `lossDivisor`) | 계산한 비를 띄우지 않는다(S-piece 유효숫자). 전압 두 값과의 관계는 선언할 자리가 없다(G143) — 저작자가 전압만 바꾸면 글자가 어긋난다 |
| 전류 = 알갱이 **촘촘함** + `I` 화살표 길이, 알갱이 빠르기는 두 줄이 같다 | 정지 화면에서도 비가 읽히는 것은 촘촘함이다. 빠르기로 가르면 정지 화면에서 사라진다. 아래 `I` 화살표는 열 배 짧아 머리가 보이지 않는 짧은 획이 된다 — 짧다는 것 자체가 말이라 두었다 |
| 알갱이는 **전자**다 — 위 줄 선 위 마을 곁에 `e⁻` 방향 화살표 표식 한 번, 알갱이는 관례 전류 `I`(발전소 → 마을)와 반대로 마을 → 발전소 쪽으로 간다. 교류의 앞뒤 흔들림은 없다 | 도선 속 알갱이는 무엇인지 표식으로 밝힌다(지시서 전자기 줄). 처음에는 표식 없는 점을 `I` 방향으로 흘렸다가 rule-guard 사후 검증(S-piece, low)이 잡아 고쳤다 — 선례 electric-current · ohms-law 의 `e⁻ ←` · `→ I`. 표식은 한 번이다 — 두 줄의 알갱이가 같은 것이고, 아래 줄에 또 두면 성긴 알갱이 곁 글자가 알갱이보다 눈에 띈다. 주장은 전류의 크기(실효값)라 교류로 흔들면 촘촘함 비는 같고 화면만 어지럽다 |
| 열 = 강조색 한 뜻(김 · 열 막대 · `1/100`) | 전류는 primary, 발전소 · 마을 · 변압기 · 마을 막대는 먹색, 선 · 바닥 · 점선은 muted. 강조색을 다른 곳에 쓰지 않는다(G102) |
| 열 김(stream) 빈도 ∝ 선 손실 | 막대는 크기를, 김은 「지금 새고 있다」 를 보인다. 막대만 두면 수치 그래프가 된다 |
| 변압기는 겹친 두 원 기호 + `승압` · `강압` 이름 | 원리는 transformer 의 몫이라 코일 · 철심을 그리지 않았다 |
| 전류 · 손실 · 받은 전력의 **수치를 두지 않음** | 모두 계산값이라 띄우면 자릿수를 정해야 하고, 정박값으로 선언하면 이중 선언이 늘어난다(G143). 주장은 막대 높이와 배수 글자다. 식 `P = I²R` 은 문단의 몫 |
| 캡션은 화면 사실만 | 「전류가 1/10 이면 손실은 1/100」 같은 법칙 진술을 빼고 「아래 줄의 열 막대는 위의 1/100」 처럼 보이는 것을 말한다. 끼우는 값은 선언값을 state 로 옮긴 것(G133) |
| 캡션에서 `뺀` · `닿` 글자를 피함 | 다크 촬영에서 두 글자가 두 번 연달아 깨져 찍혔다(글꼴 부분 집합 문제로 보이나 미확인). 문장을 바꿔 피했다 |
| `startAt` = `flow` 에 1 초 들어간 자리 | 도착한 순간 이미 흐르고 김이 오른다 |
| 조작기 · 그리드 없음 | 자동 진행으로 주장을 마친다. 잴 거리가 없다 |

## (d) 주장이 화면에서 서는가

`pnpm -s piece:report --sims=http://localhost:5173/aperi21/ power-transmission` — 라이트 · 다크 각 5 장. 네 번 찍었다
(1 차: 열 김이 옅은 점선이라 「쏟아진다」 가 약함, `1/100` 이 마을 막대에 닿음 → 김 빈도 · 속력 · 굵기 상향, 막대 간격 벌림.
3 차: 다크 11.5 캡션에서 `뺀` · `닿` 이 두 번 깨짐 → 4 차에서 캡션을 화면 사실 문장으로 바꾸며 그 글자를 뺌).

| t | 라이트 | 다크 |
|---|---|---|
| 0.5 | 두 줄 발전소 → 선 → 마을, 아래 줄에만 변압기 둘 · `승압` `강압`. `1 kV` · `10 kV`. 위 선 알갱이 촘촘 · 아래 성김, 위 선에서만 김 다섯 줄기. 막대 비어 있고 `100 kW` 점선 둘. 캡션 「두 발전소가 같은 100 kW …」 — 섬 | 같다. 발전소 · 마을 흰색, 김 금빛 — 섬 |
| 3.0 | 위 `I` 긴 화살표, 아래 짧은 획 곁에 `1/10`. 캡션 「아래 선의 전류 화살표 I 는 위의 1/10 …」 — 섬 | 같다 — 섬 |
| 5.5 | 위 열 막대가 점선 절반을 향해 차오르는 중, 아래 열 막대 자리는 바닥뿐. 캡션 「위 선에서는 열이 쏟아지고 …」 — 섬 | 같다 — 섬 |
| 8.0 | 위 열 막대가 점선의 절반 높이. 아래 열 막대 자리 위에 강조색 `1/100`. 캡션 「아래 줄의 열 막대는 위의 1/100 …」 — 섬 | 같다 — 섬 |
| 11.5 | 위 줄 열 막대와 마을 막대가 같은 높이, 아래 줄 마을 막대가 `100 kW` 점선에 거의 붙음. 캡션 「마을이 받은 전력 …」 — 섬 | 같다. 마을 막대 흰색, 열 막대 금빛 — 섬 |

글자 겹침 · 화면 밖 넘침 · 다크 뒤집힘 없음. 아래 줄 김은 확률상 드물게 한 올 오를 수 있다(빈도가 위의 1/100) — 다섯 시각
촬영에서는 보이지 않았다. 움직이는 화면에서 김이 오르는 모양은 촬영으로는 미확인이다(stream 은 엔진 시계의 함수다).

rule-guard 사후 검증(알갱이 표식 없음) 뒤 두 번 더 찍었다(5 차: `e⁻` 글자가 화살표와 선 사이에 끼어 알갱이에 붙음 →
`labelSide: 'cw'` 로 화살표 위에 올림). 6 차 — 다섯 시각 모두 라이트 · 다크에서 위 줄 마을 곁에 `e⁻ ←` 표식이 선 위로 떨어져
읽히고, 알갱이가 마을 → 발전소로 간다(`I` 화살표는 발전소 → 마을 그대로). 겹침 · 다크 뒤집힘 없음 — 섬.
