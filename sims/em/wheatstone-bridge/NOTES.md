# wheatstone-bridge — 휘트스톤 브리지

엔진 위에서 바로 만든 조각이다. 자유 구현 원본이 없다.

## (a) 답하는 질문과 동사

**질문** — 모르는 저항을 전류 값을 읽지 않고 어떻게 재는가.

**주장** — 가변 저항 R₃ 를 돌려 두 가운데 마디 C · D 의 전위를 같게 맞추면 검류계로 전류가 흐르지 않아
바늘이 0 에 서고, 그 자리의 R₃ 로 모르는 저항 Rₓ 를 읽는다 (평형 조건 R₁/R₂ = R₃/Rₓ 는 문단의 몫이라
화면에 쓰지 않는다).

**동사** — R₃ 를 돌리는 동안 *D 의 높이가 C 에 다가가 겹치고, 검류계 바늘이 0 으로 돌아와 선다.*

화면에서 일어나는 일 (한 주기 16.8 초, `timeline` 6 단계):

1. `hold-low` (2.4 초) — R₃ = 75 Ω. 오른쪽 판에서 D 표식이 C 보다 높고 둘 사이에 강조색 막대. 검류계 바늘이
   오른쪽으로 크게 기울고(0 → 바늘 강조 부채꼴), 원 옆 전류 화살표 `I` 가 위(D → C)를 본다. Rₓ 자리는 `? Ω`.
2. `turn-up` (3 초, smooth) — R₃ 가 25 Ω 한 칸씩 딸깍 올라간다(75 → 150). 칸마다 D 표식이 내려와 C 에 다가가고,
   강조 막대 · 부채꼴 · 화살표가 줄어든다.
3. `hold-balance` (3.6 초) — R₃ = 150 Ω. C · D 가 같은 높이, 강조 막대 · 부채꼴 · 화살표가 모두 사라지고 바늘이
   0 눈금에 곧게 선다. Rₓ 자리에 선언값 `300 Ω` 이 드러난다.
4. `turn-over` (2.4 초, smooth) — 150 → 250 Ω. D 가 C 아래로 내려가 막대가 반대쪽에 자라고, 바늘이 왼쪽으로,
   화살표가 아래(C → D)로.
5. `hold-high` (2.4 초) — R₃ = 250 Ω. 반대쪽으로 기운 채 멈춰 있다.
6. `back` (3 초, smooth) — 250 → 75 Ω. 바늘이 0 을 지나 처음 쪽으로 넘어간다.

마디 전위는 `solveMna` 로 푼다(Q 가 0 V, 검류계는 내부 저항 `rg` 인 저항). R₃ 는 세 돌림 단계의 진행도(`at`)를
더해 얻는다(`r3Now`) — 단계 경계를 코드로 가르지 않는다. 쌓는 상태가 없어 같은 시각은 같은 화면이다.

## (b) 화면 구성의 결정

| 결정 | 이유 |
|---|---|
| 마름모 대신 **가로 사다리형** 브리지(위 가지 R₁ – C – R₂, 아래 가지 R₃ – D – Rₓ, 가운데 세로로 검류계) | plugin 저항 기호는 격자 회전(0 · 90 · 180 · 270)만 받아 마름모의 비스듬한 변에 놓을 수 없고, 세로로 두면 값 글자가 지그재그 위에 얹힌다(kirchhoffs-voltage-law 새 부족). 넷 모두 가로로 두면 값 글자가 제자리에 오고, C · D 가 한 세로줄에 서서 검류계가 그 사이에 곧게 들어간다 |
| 검류계를 **조립**(둘레 · 눈금 `lineSet` + 바늘 `lineSet` + 축 점 `body` + `G` 각인 `readout` + 강조 `sector`) | `scale` dial 은 지금 값 글자를 늘 쓰고 270° 판이다(G144). 멈춘 자리(75 · 250 Ω)의 전류는 계산값이라 값 글자를 띄우면 반올림한 수가 된다. 이 조각의 계기가 말할 것은 「0 에 선다」 하나라 수를 두지 않는다. 가운데 0 판, 0 눈금만 길게 |
| 오른쪽 **전위 판** — C · D 두 마디의 높이 표식을 나란히, 둘 사이 강조 막대 | 「바늘이 0 이 되는 까닭 = 두 마디의 전위가 같아서」 를 높이로 보인다. 검류계만 두면 바늘이 왜 서는지가 수수께끼로 남는다 |
| 판은 **3 ~ 5 V 창**(`panelVMin` · `panelVMax`, 스테이지 상수) | 첫 촬영은 0 ~ 6 V 전체를 판 높이로 폈더니 검류계 부하로 좁혀진 두 마디의 차(0.1 ~ 0.5 V)가 몇 px 뿐이라 보이지 않았다. 두 전위가 3.5 ~ 4.7 V 안에서만 움직여 창을 좁혔고, 창 두 끝 전위를 `{v} V` 로 적어 0 에서 시작하지 않는 축임을 밝힌다 |
| 검류계 내부 저항 `rg` 200 Ω | 50 Ω 이면 검류계가 두 마디를 서로 끌어당겨 판의 어긋남이 더 작아졌다(첫 촬영). 평형 자리는 `rg` 와 무관하다 — 벗어났을 때의 크기만 바뀐다 |
| R₃ 는 **25 Ω 격자** 위에서만(`r3Low + k·r3Step`) | 가변 저항 값 글자가 늘 선언한 격자 값이게(S-piece 유효숫자). 연속으로 돌리면 `118.4 Ω` 같은 계산값이 뜬다. 딸깍 넘어가는 칸이 「한 칸씩 맞춰 간다」 는 측정 동작과도 맞는다. 평형 자리 `rx·r1/r2` 가 격자 위에 있어야 한다(G143) |
| R₃ · Rₓ 값은 plugin 값 글자 대신 `readout` `{r} Ω` | `circuitElement.value` 에 격자 값(계산 결과)을 넣지 않는다는 지시를 따랐다. R₁ · R₂ 는 선언값 그대로라 plugin 값 글자를 쓴다(글자 크기가 R₃ · Rₓ 와 조금 다르다 — 아래 새 부족) |
| Rₓ 는 평형 단계에서만 선언값 `300 Ω`, 나머지는 `? Ω` | 「평형으로 잰다」 — 값은 평형에서 읽혀 나오는 것이다. 단계 id(`hold-balance`)로 가른다. 값은 스테이지 상수 `rx` 그대로 |
| 강조색은 **「C 와 D 의 전위가 어긋나 있다」 한 뜻** | 판의 차이 막대와 검류계 0 → 바늘 부채꼴에만. 평형에서 둘 다 사라진다. 차이 막대는 길이가 0 이면 두지 않는다 — 두면 둥근 끝이 점으로 남아 「아직 어긋나 있다」 로 읽혔다(첫 촬영) |
| 전류 방향은 화살표 `I` 의 위 · 아래 | 색으로 방향을 가르지 않는다. 길이는 전류에 비례(`arrowPerMilliamp`), 상한 `arrowMax` 0.8 에서 비례가 끊긴다 — 기본 상수로는 가장 큰 전류(2.45 mA → 0.73)가 상한 아래라 끊기지 않는다 |
| 표시 배율 — 바늘 22°/mA, 끝 70° | 평형 한 칸 옆(125 · 175 Ω, 0.56 ~ 0.66 mA)에서도 바늘이 12 ~ 15° 기울어 눈에 보이게. 끝 70° 에 닿으면 비례가 끊기나 기본 상수로는 최대 54° 라 닿지 않는다. 배율은 화면에 알리지 않는다 — 바늘의 수가 아니라 0 이냐 아니냐가 주장이다 |
| 두지 않은 것 | 검류계 전류 값 · 마디 전위 값 — 계산값이고 수가 아니라 바늘의 0 과 높이의 같음이 주장이다. 판 눈금 사이 숫자 — 같은 이유. 평형 조건식 · 비 `R₂/R₁` — 문단의 몫. 전지 쪽 전류 · 저항 전압 — 다른 주장. 마디 P · Q 이름표 — 판이 두 끝 전위를 쓰지 않아 이을 곳이 없다. 그리드 · 카메라 단추 — 잴 거리가 없다 |
| 조작기 없음 | 자동 진행이 평형 앞 · 평형 · 평형 너머를 모두 보인다. R₃ 를 끄는 조작기를 두면 격자 · 정박 되돌림이 필요하고 시간표와 겹친다 — 독자가 직접 해 봐야 새로 알게 되는 것이 없다. 저항값 · 범위는 저작자가 스테이지 상수로 바꾼다 |
| 캡션 | 지금 화면의 일만. 돌림 단계는 「한 칸씩 키운다 — D 가 내려가 C 에 다가가고 바늘이 0 쪽으로」, 평형은 「높이가 같아졌다 — 바늘이 0 에 선다, 이 R₃ 에서 모르는 저항의 값을 읽는다」. 값(150 Ω · 두 배)을 문안에 박지 않는다. 캡션 글꼴에 `ₓ` 글리프가 없어 `R ₓ` 로 벌어져(두 번째 촬영 전) 캡션에서는 Rₓ 를 「모르는 저항」 으로 풀었다 |

| G144 | `scale` dial 이 지금 값 글자를 늘 쓰고 270° 판이다 — 가운데 0 검류계를 `lineSet` 둘레 · 눈금 · 바늘 + `body` 축 + `sector` 부채꼴 + `readout` 각인으로 조립 | 근사 |

| G143 | 스테이지 상수 사이 관계를 선언할 자리가 없다 — 평형 자리 `rx·r1/r2` 가 R₃ 격자(`r3Low + k·r3Step`) 위 · 범위 안이어야 하고, 두 마디 전위가 판 창(`panelVMin` ~ `panelVMax`) 안이어야 한다. 어기면 경고 없이 바늘이 0 에 서지 않거나 표식이 판 밖으로 나간다 | 근사 |
| G13 | 시간표 단계에 값을 실을 수 없다 — 돌림 단계마다 어느 R₃ 에서 어느 R₃ 로 가는지를 단계 이름과 `r3Now` 식으로 잇는다(처음 → 평형 → 끝 → 처음의 순서가 코드에 있다) | 근사 |

새 부족:

| 부족 | 영향 |
|---|---|
| plugin-circuit `circuitElement` 의 값 글자는 크기 · 글꼴이 렌더러에 고정(소자 아래 14 px, 작은 글자)이라, 같은 도식에서 `readout` 으로 단 R₃ · Rₓ 값 글자와 크기가 맞지 않는다. 계산값을 넣을 수 없는 소자(가변 저항)는 `readout` 으로 갈 수밖에 없어 네 저항의 값 글자가 두 모양으로 갈린다 | 근사 |
